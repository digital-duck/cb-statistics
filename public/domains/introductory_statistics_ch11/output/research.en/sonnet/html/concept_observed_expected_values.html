Observed Expected Values

Definition. Let $X$ be a discrete random variable with sample space $\Omega = \{x_1, x_2, \ldots, x_k\}$ and probability mass function $P(X = x_i) = p_i$. The expected value (or expectation) of $X$ is the probability-weighted average of its possible outcomes:

$$E[X] = \sum_{i=1}^{k} x_i \, p_i.$$

For a continuous random variable with probability density function $f(x)$, the analogous definition is $E[X] = \int_{-\infty}^{\infty} x \, f(x) \, dx$, provided the integral converges absolutely.

The observed expected value refers to the empirical counterpart: given $n$ independent observations $\{x^{(1)}, x^{(2)}, \ldots, x^{(n)}\}$ drawn from the distribution of $X$, the sample mean

$$\bar{x} = \frac{1}{n} \sum_{j=1}^{n} x^{(j)}$$

serves as an estimate of $E[X]$. The distinction between $E[X]$ (a population parameter) and $\bar{x}$ (a statistic computed from data) is fundamental in inferential statistics.

Worked Example. A fair six-sided die has outcomes $\{1, 2, 3, 4, 5, 6\}$, each with probability $\frac{1}{6}$. The theoretical expected value is

$$E[X] = \frac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = \frac{21}{6} = 3.5.$$

If the die is rolled $n = 5$ times and yields observations $\{2, 5, 3, 6, 1\}$, the observed expected value is $\bar{x} = \frac{17}{5} = 3.4$, which approximates but need not equal 3.5 for any finite sample.

Key Theorem (Law of Large Numbers). Let $X_1, X_2, \ldots$ be independent and identically distributed random variables with finite mean $\mu = E[X]$. Then the sample mean converges in probability to $\mu$:

$$\bar{X}_n = \frac{1}{n}\sum_{j=1}^{n} X_j \xrightarrow{P} \mu \quad \text{as } n \to \infty.$$

Proof sketch. By Chebyshev's inequality, $P(|\bar{X}_n - \mu| \geq \varepsilon) \leq \frac{\operatorname{Var}(X)}{n\varepsilon^2}$, which tends to zero as $n \to \infty$ whenever $\operatorname{Var}(X) < \infty$.

from sympy import Rational, symbols, summation

# Theoretical expected value of a fair die
i = symbols('i')
E_X = summation(i * Rational(1, 6), (i, 1, 6))
print("E[X] =", E_X)          # 7/2

# Observed expected value from a sample
observations = [2, 5, 3, 6, 1]
x_bar = Rational(sum(observations), len(observations))
print("x̄   =", x_bar)         # 17/5
