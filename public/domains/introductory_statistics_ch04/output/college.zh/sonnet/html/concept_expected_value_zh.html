Expected Value

定义

设 $X$ 为定义在样本空间 $\Omega$ 上的随机变量。若 $X$ 为离散型，其期望值（Expected Value）定义为

$$E[X] = \sum_{x} x \cdot P(X = x),$$

前提是该级数绝对收敛。若 $X$ 为连续型，其概率密度函数为 $f(x)$，则

$$E[X] = \int_{-\infty}^{+\infty} x \, f(x) \, dx,$$

同样要求积分绝对收敛。期望值刻画了随机变量取值的"重心"，是分布的一阶矩。

例题

掷一枚均匀六面骰子，点数记为随机变量 $X$，则 $P(X = k) = \tfrac{1}{6}$，$k = 1, 2, \ldots, 6$。按定义计算：

$$E[X] = \sum_{k=1}^{6} k \cdot \frac{1}{6} = \frac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = \frac{21}{6} = 3.5.$$

注意 $3.5$ 并非骰子的任何一个可能取值，这说明期望值是长期平均的理论极限，而非单次试验的必然结果。

关键定理：期望值的线性性

设 $X$、$Y$ 为定义在同一概率空间上的随机变量，$a, b, c \in \mathbb{R}$，则

$$E[aX + bY + c] = a\,E[X] + b\,E[Y] + c.$$

此性质对任意随机变量成立，无需 $X$ 与 $Y$ 相互独立。证明思路：对离散情形，将求和式展开后逐项整理；对连续情形，利用积分的线性性即可完成。线性性是期望值最核心的运算性质，贯穿概率论与统计学的始终。

实验单元（SymPy）

from sympy import symbols, Rational, summation

k = symbols('k', integer=True)
# 骰子期望：离散均匀分布
E_die = summation(k * Rational(1, 6), (k, 1, 6))
print("骰子期望值:", E_die)   # 输出：7/2

# 线性组合：Y = 2X + 1
E_Y = 2 * E_die + 1
print("E[2X+1] =", E_Y)       # 输出：8

运行上述代码，验证 $E[X] = \tfrac{7}{2}$ 与 $E[2X+1] = 2 \cdot \tfrac{7}{2} + 1 = 8$，从而在具体实例中确认期望值的线性性。
