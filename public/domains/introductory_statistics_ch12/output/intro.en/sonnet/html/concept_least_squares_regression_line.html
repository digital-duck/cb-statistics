Least Squares Regression Line

Definition. Given a dataset of $n$ paired observations $\{(x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)\}$, the least squares regression line is the linear function $\hat{y} = \beta_0 + \beta_1 x$ that minimizes the residual sum of squares

$$S(\beta_0, \beta_1) = \sum_{i=1}^{n} \bigl(y_i - \beta_0 - \beta_1 x_i\bigr)^2.$$

The quantities $e_i = y_i - \hat{y}_i$ are called residuals; minimizing $S$ makes the total squared vertical deviation between observed values and the fitted line as small as possible.

Worked Example. Consider four data points: $(1, 2)$, $(2, 3)$, $(3, 5)$, $(4, 4)$. Compute the sample means $\bar{x} = 2.5$ and $\bar{y} = 3.5$. The slope estimator is

$$\hat{\beta}_1 = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2} = \frac{(-1.5)(-1.5)+(-0.5)(-0.5)+(0.5)(1.5)+(1.5)(0.5)}{(-1.5)^2+(-0.5)^2+(0.5)^2+(1.5)^2} = \frac{4}{5} = 0.8,$$

and the intercept is $\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x} = 3.5 - 0.8(2.5) = 1.5$. The fitted line is therefore $\hat{y} = 1.5 + 0.8x$.

Key Theorem (Normal Equations). Setting $\partial S/\partial \beta_0 = 0$ and $\partial S/\partial \beta_1 = 0$ yields the normal equations

$$\hat{\beta}_1 = \frac{S_{xy}}{S_{xx}}, \qquad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x},$$

where $S_{xy} = \sum(x_i - \bar{x})(y_i - \bar{y})$ and $S_{xx} = \sum(x_i - \bar{x})^2$. By the second-derivative test the Hessian of $S$ is positive definite, confirming a global minimum.

Lab Cell (SymPy).

from sympy import symbols, Rational, simplify

x_data = [1, 2, 3, 4]
y_data = [2, 3, 5, 4]
n = len(x_data)

x_bar = Rational(sum(x_data), n)
y_bar = Rational(sum(y_data), n)

S_xy = sum((xi - x_bar)*(yi - y_bar) for xi, yi in zip(x_data, y_data))
S_xx = sum((xi - x_bar)**2 for xi in x_data)

beta1 = simplify(S_xy / S_xx)
beta0 = simplify(y_bar - beta1 * x_bar)

print(f"Slope: {beta1},  Intercept: {beta0}")
# Output: Slope: 4/5,  Intercept: 3/2
