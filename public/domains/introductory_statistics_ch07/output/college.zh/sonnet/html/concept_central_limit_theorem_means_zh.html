Central Limit Theorem Means

定义。 设 $X_1, X_2, \ldots, X_n$ 为独立同分布（i.i.d.）的随机变量，其总体均值为 $\mu$，总体方差为 $\sigma^2 < \infty$。定义样本均值为

$$\bar{X}_n = \frac{1}{n} \sum_{i=1}^{n} X_i.$$

均值的中心极限定理断言：当 $n \to \infty$ 时，标准化后的样本均值

$$Z_n = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}}$$

依分布收敛于标准正态分布 $\mathcal{N}(0, 1)$，即对任意实数 $z$，

$$\lim_{n \to \infty} P\!\left(Z_n \leq z\right) = \Phi(z),$$

其中 $\Phi$ 为标准正态分布函数。换言之，无论原始总体服从何种分布，只要样本量足够大，样本均值的抽样分布均近似为正态分布 $\mathcal{N}(\mu,\, \sigma^2/n)$。

证明思路（特征函数方法）。 令 $Y_i = (X_i - \mu)/\sigma$，则 $\mathbb{E}[Y_i]=0$，$\text{Var}(Y_i)=1$。$Z_n = \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i$ 的特征函数为 $\varphi_{Z_n}(t) = \left[\varphi_Y\!\left(t/\sqrt{n}\right)\right]^n$。对 $\varphi_Y$ 在 $t=0$ 处作泰勒展开：$\varphi_Y(s) = 1 - \frac{s^2}{2} + o(s^2)$，代入后取极限得 $\varphi_{Z_n}(t) \to e^{-t^2/2}$，此即标准正态分布的特征函数，定理由此得证。

具体示例。 设总体服从均匀分布 $U(0,1)$，则 $\mu = 0.5$，$\sigma^2 = 1/12$。取样本量 $n = 40$，则 $\bar{X}_{40}$ 近似服从 $\mathcal{N}(0.5,\, 1/480)$。若要计算 $P(\bar{X}_{40} \geq 0.52)$，先标准化：

$$z = \frac{0.52 - 0.5}{\sqrt{1/480}} \approx \frac{0.02}{0.0456} \approx 0.439,$$

故 $P(\bar{X}_{40} \geq 0.52) \approx 1 - \Phi(0.439) \approx 0.330$。

关键定理（Berry–Esseen 界）。 若 $\mathbb{E}[|X_i|^3] = \rho < \infty$，则近似误差有上界：

$$\sup_z \left|P(Z_n \leq z) - \Phi(z)\right| \leq \frac{C\,\rho}{\sigma^3 \sqrt{n}},$$

其中常数 $C \leq 0.4748$。该定理给出了有限样本下正态近似的定量精度保证。

实验单元（SymPy）。

import numpy as np
from scipy import stats
import sympy as sp

n, mu, sigma2 = 40, sp.Rational(1,2), sp.Rational(1,12)
se = sp.sqrt(sigma2 / n)
z = (sp.Rational(52,100) - mu) / se
prob = 1 - sp.Float(stats.norm.cdf(float(z)))
sp.pprint(sp.Eq(sp.Symbol('P'), prob.evalf(4)))
