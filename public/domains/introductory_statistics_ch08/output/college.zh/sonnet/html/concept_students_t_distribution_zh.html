Students T Distribution

定义

设 $X_1, X_2, \ldots, X_n$ 为来自正态总体 $\mathcal{N}(\mu, \sigma^2)$ 的随机样本，样本均值为 $\bar{X}$，样本方差为 $S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$。当总体标准差 $\sigma$ 未知时，统计量

$$T = \frac{\bar{X} - \mu}{S / \sqrt{n}}$$

服从自由度为 $\nu = n - 1$ 的 Student $t$ 分布，记作 $T \sim t(\nu)$。其概率密度函数为

$$f(t;\nu) = \frac{\Gamma\!\left(\frac{\nu+1}{2}\right)}{\sqrt{\nu\pi}\,\Gamma\!\left(\frac{\nu}{2}\right)} \left(1 + \frac{t^2}{\nu}\right)^{-\frac{\nu+1}{2}}, \quad t \in \mathbb{R}.$$

与标准正态分布相比，$t$ 分布具有更厚的尾部；当 $\nu \to \infty$ 时，$t(\nu)$ 收敛于 $\mathcal{N}(0,1)$。

具体例子

某班级随机抽取 $n = 10$ 名学生测量身高（单位：cm），得 $\bar{x} = 172.3$，$s = 5.8$。假设身高服从正态分布，检验总体均值是否为 $\mu_0 = 170$。

计算检验统计量：

$$t = \frac{172.3 - 170}{5.8 / \sqrt{10}} = \frac{2.3}{1.834} \approx 1.254.$$

自由度 $\nu = 9$，查 $t$ 分布表得双侧临界值 $t_{0.025}(9) = 2.262$。由于 $|t| = 1.254 < 2.262$，在显著性水平 $\alpha = 0.05$ 下不能拒绝原假设，即无充分证据表明总体均值偏离 170 cm。

关键定理

定理（$t$ 统计量的分布推导）：若 $Z \sim \mathcal{N}(0,1)$ 与 $V \sim \chi^2(\nu)$ 相互独立，则

$$T = \frac{Z}{\sqrt{V/\nu}} \sim t(\nu).$$

对于正态样本，$Z = \frac{\bar{X}-\mu}{\sigma/\sqrt{n}}$ 与 $V = \frac{(n-1)S^2}{\sigma^2}$ 正交独立（由 Cochran 定理保证），代入即得 $T \sim t(n-1)$。

实验单元（SymPy）

from sympy import symbols, sqrt, simplify
from sympy.stats import StudentT, density, cdf, P, Lt, Gt

nu = 9
T = StudentT('T', nu)

# 计算 P(T > 1.254)（单侧 p 值）
p_value = P(Gt(T, 1.254))
print("单侧 p 值:", float(p_value.evalf()))

# 输出自由度 9 的密度函数
t = symbols('t')
f = density(T)(t)
print("密度函数:", simplify(f))

运行上述代码可直接验证例题中的 $p$ 值，并观察 $t(9)$ 的解析密度表达式，加深对厚尾性质的直觉理解。
