What Randomized Experimentation Achieves

A randomized experiment is a study design in which each unit $i$ from a finite population $\mathcal{U} = \{1, \dots, N\}$ is assigned to treatment ($T_i = 1$) or control ($T_i = 0$) by an explicit, known probability mechanism—typically independent Bernoulli draws with $P(T_i = 1) = p$, or a balanced permutation so that exactly $n_t$ units are treated. The defining property is that assignment is statistically independent of all pre-treatment covariates, observed or latent:

$$T_i \perp\!\!\!\perp \bigl(Y_i(0),\, Y_i(1),\, X_i\bigr),$$

where $Y_i(0)$ and $Y_i(1)$ are the potential outcomes under control and treatment respectively. This independence is not assumed from subject-matter knowledge—it is manufactured by the randomization itself.

Worked example. Suppose a university recruits $N = 200$ students and assigns $n_t = 100$ to a new tutoring program by drawing 100 names from a hat. Let $Y_i$ be end-of-semester exam score. Because assignment is random, the difference-in-means estimator

$$\hat{\tau} = \bar{Y}_t - \bar{Y}_c$$

is unbiased for the average treatment effect $\tau = \mathbb{E}[Y_i(1) - Y_i(0)]$ without any covariate adjustment. One can verify: $\mathbb{E}[\hat{\tau}] = \tau$ follows directly from $\mathbb{E}[Y_i \mid T_i = 1] = \mathbb{E}[Y_i(1)]$ under independence.

Key theorem (Fisher's Randomization Theorem). Under the sharp null hypothesis $H_0: Y_i(1) = Y_i(0)$ for all $i$, the exact distribution of $\hat{\tau}$ over all $\binom{N}{n_t}$ equally likely assignments is known without any distributional assumption on $Y$. A valid $p$-value is therefore obtainable by permutation, making inference assumption-free.

import numpy as np
from scipy.stats import permutation_test

rng = np.random.default_rng(42)
Y = rng.normal(loc=[70]*100 + [75]*100, scale=10)
T = np.array([0]*100 + [1]*100)

def statistic(a, b):
    return np.mean(b) - np.mean(a)

result = permutation_test(
    (Y[T == 0], Y[T == 1]),
    statistic, permutation_type='samples', n_resamples=9999
)
print(f"Observed τ̂ = {result.statistic:.3f}, p = {result.pvalue:.4f}")

Connection to Research Ethics and the IRB

Randomized experiments are precisely the designs that trigger—and justify—formal Institutional Review Board (IRB) oversight. Because randomization deliberately withholds a potentially beneficial treatment from the control group, it raises the ethical question of equipoise: the community must genuinely be uncertain which arm is superior before randomization is permissible. The IRB framework operationalizes this by requiring investigators to demonstrate prior evidence of equipoise, obtain informed consent, pre-register the randomization procedure, and specify stopping rules. Each of these requirements maps directly onto a statistical property of the randomized design: pre-registration guards the Type I error rate; stopping rules control sequential familywise error; informed consent preserves the independence assumption by preventing selective non-compliance.

The connection runs deeper still. Randomization yields the only study design for which causal claims are licensed by design rather than by modeling assumptions, which is exactly why regulators (FDA, EMA) demand randomized controlled trials for drug approval and why IRBs apply heightened scrutiny to any deviation from full randomization. Understanding randomized experiments is therefore not merely a statistical skill—it is a prerequisite for ethical practice in empirical research.
