Lurking Variable

定义。 设 $X$、$Y$ 为两个可观测变量，$Z$ 为一个未被纳入研究的变量。若 $Z$ 同时影响 $X$ 与 $Y$，且在统计分析中未加以控制，则称 $Z$ 为潜伏变量（lurking variable）。潜伏变量的存在会使研究者错误地将 $X$ 与 $Y$ 之间的相关性解释为因果关系，从而导致混淆偏差（confounding bias）。

形式地，设真实数据生成过程为

$$Y = \alpha Z + \varepsilon_Y, \quad X = \beta Z + \varepsilon_X,$$

其中 $\varepsilon_X, \varepsilon_Y$ 相互独立，$\alpha, \beta \neq 0$。若忽略 $Z$，对 $X$ 与 $Y$ 做简单线性回归，所估计的斜率为

$$\hat{b} = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)} = \frac{\alpha\beta\operatorname{Var}(Z)}{\beta^2\operatorname{Var}(Z)+\operatorname{Var}(\varepsilon_X)},$$

此值一般不为零，即便 $X$ 对 $Y$ 不存在直接因果效应。

例题。 某城市数据显示，冰淇淋日销售量 $X$（万份）与溺水事故数 $Y$（起）之间存在强正相关，皮尔逊相关系数 $r \approx 0.85$。若据此推断"食用冰淇淋导致溺水"，则犯了混淆推断的错误。实际上，气温 $Z$ 既促使居民购买冰淇淋，又增加游泳人数从而提高溺水风险。$Z$ 是此处的潜伏变量；控制 $Z$（例如在相同气温层内分析）后，$X$ 与 $Y$ 的偏相关系数接近于零。

关键定理（Frisch–Waugh–Lovell，简化版）。 设多元线性模型为 $Y = \beta_1 X + \beta_2 Z + \varepsilon$。若在回归中遗漏 $Z$，则 $\hat{\beta}_1^{\text{短}}$ 的期望值为

$$\mathbb{E}[\hat{\beta}_1^{\text{短}}] = \beta_1 + \beta_2 \delta_{XZ},$$

其中 $\delta_{XZ}$ 是将 $Z$ 对 $X$ 回归所得斜率。偏差项 $\beta_2\delta_{XZ}$ 称为遗漏变量偏差，仅当 $\beta_2 = 0$（$Z$ 与 $Y$ 无关）或 $\delta_{XZ} = 0$（$Z$ 与 $X$ 无关）时消失。

实验单元（SymPy）。

import sympy as sp

# 定义符号
b1, b2, d = sp.symbols('beta_1 beta_2 delta')

# 遗漏变量偏差公式
bias = b2 * d
sp.pprint(sp.Eq(sp.Symbol('E[hat_beta_1_short]'), b1 + bias))

# 数值示例：b1=0, b2=2, d=0.5 → 偏差 = 1
print("偏差 =", bias.subs([(b2, 2), (d, sp.Rational(1,2))]))

运行结果表明：即使 $\beta_1 = 0$（$X$ 对 $Y$ 无直接影响），遗漏 $Z$ 后估计值仍为 $1$，与真实值相差整整一个单位，印证了潜伏变量对推断的严重干扰。
