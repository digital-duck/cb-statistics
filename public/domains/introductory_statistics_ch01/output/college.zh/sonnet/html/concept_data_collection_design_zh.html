数据收集设计

定义。 数据收集设计（Data Collection Design）是指在统计推断开始之前，系统地规划观测单元、测量变量、抽样框架与误差控制策略的过程。形式上，设总体为 $\mathcal{U} = \{u_1, u_2, \ldots, u_N\}$，研究者从中依概率机制 $\pi$ 抽取样本 $\mathcal{S} \subseteq \mathcal{U}$，使得每个单元 $u_i$ 被选入的概率为 $\pi_i = \Pr(u_i \in \mathcal{S}) > 0$。设计的核心目标是在给定资源约束 $C$ 的前提下，最小化目标估计量 $\hat{\theta}$ 的均方误差：

$$\mathrm{MSE}(\hat{\theta}) = \mathrm{Var}(\hat{\theta}) + \left[\mathrm{Bias}(\hat{\theta})\right]^2.$$

具体示例。 某校希望估计全体学生的平均每周自习时长 $\mu$。总体规模 $N = 2000$，预算仅允许调查 $n = 100$ 人。若采用简单随机抽样（SRS），每人被选概率均为 $\pi_i = n/N = 1/20$。样本均值 $\bar{X} = \frac{1}{n}\sum_{i \in \mathcal{S}} X_i$ 是 $\mu$ 的无偏估计，其方差为

$$\mathrm{Var}(\bar{X}) = \frac{\sigma^2}{n}\left(1 - \frac{n}{N}\right),$$

其中 $\left(1 - n/N\right)$ 称为有限总体校正因子（finite population correction）。若已知男女生自习时长差异显著，则改用分层抽样可进一步降低 $\mathrm{Var}(\bar{X})$，体现设计优化的实际价值。

核心定理（Neyman 最优分配）。 在分层抽样中，设第 $h$ 层总体规模为 $N_h$、标准差为 $\sigma_h$，总样本量为 $n$。Neyman（1934）证明，使总体方差估计量最小的各层样本量分配为

$$n_h = n \cdot \frac{N_h \sigma_h}{\sum_{k} N_k \sigma_k}.$$

该定理表明：规模大、离散程度高的层应分配更多样本，是设计效率优化的理论基础。

实验室代码（SymPy）。

from sympy import symbols, Rational, simplify

N, n, sigma = symbols('N n sigma', positive=True)
# 有限总体校正后的 SRS 方差
var_srs = (sigma**2 / n) * (1 - n / N)
print("SRS 方差:", simplify(var_srs))

# Neyman 分配示例：两层
N1, N2, s1, s2 = 1200, 800, 3, 5
n_total = 100
n1 = round(n_total * (N1*s1) / (N1*s1 + N2*s2))
n2 = n_total - n1
print(f"第1层分配: {n1}, 第2层分配: {n2}")
