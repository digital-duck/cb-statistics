Probability Density Function

定义。 设 $X$ 为连续型随机变量。若存在非负可积函数 $f: \mathbb{R} \to [0, +\infty)$，使得对任意实数 $a \leq b$，均有

$$P(a \leq X \leq b) = \int_a^b f(x)\, dx,$$

则称 $f(x)$ 为 $X$ 的概率密度函数（Probability Density Function，简称 PDF）。概率密度函数须满足归一化条件：

$$\int_{-\infty}^{+\infty} f(x)\, dx = 1.$$

需要特别注意的是，$f(x)$ 本身并非概率，而是概率关于区间长度的密度；单点处的概率 $P(X = x_0) = 0$ 恒成立。

例题。 设随机变量 $X$ 的概率密度函数为

$$f(x) = \begin{cases} c\,x^2, & 0 \leq x \leq 3, \\ 0, & \text{其他.} \end{cases}$$

第一步：确定常数 $c$。 由归一化条件，

$$\int_0^3 c\,x^2\, dx = c \cdot \frac{x^3}{3}\Big|_0^3 = c \cdot 9 = 1 \implies c = \frac{1}{9}.$$

第二步：计算概率。 求 $P(1 \leq X \leq 2)$：

$$P(1 \leq X \leq 2) = \int_1^2 \frac{x^2}{9}\, dx = \frac{1}{9} \cdot \frac{x^3}{3}\Big|_1^2 = \frac{1}{27}(8 - 1) = \frac{7}{27} \approx 0.259.$$

关键定理（累积分布函数与 PDF 的关系）。 若 $X$ 的概率密度函数为 $f(x)$，则其累积分布函数（CDF）定义为

$$F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t)\, dt.$$

由微积分基本定理，在 $f$ 连续处有 $F'(x) = f(x)$。这一关系揭示了 PDF 与 CDF 之间的微分—积分对偶性，是连续概率论的核心结构。

实验单元（SymPy）。

from sympy import *
x = symbols('x')
f = x**2 / 9
# 验证归一化
print(integrate(f, (x, 0, 3)))          # 输出：1
# 计算区间概率
print(integrate(f, (x, 1, 2)))          # 输出：7/27
# 求累积分布函数
F = integrate(f, (x, 0, x))
print(F)                                 # 输出：x**3/27
