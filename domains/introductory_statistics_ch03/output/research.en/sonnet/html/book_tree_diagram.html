Concept Book: Tree Diagram

Introductory Statistics Ch03 · Generated by SPL

Payoff

A tree diagram is a rooted, directed acyclic graph $T = (V, E)$ in which every vertex $v \in V$ except the root has exactly one parent, and each directed edge $(u, v)$ carries a label — typically a probability, a choice, or a generated symbol. The root represents the initial state of a process; every path from the root to a leaf encodes one complete outcome of that process. Formally, if the depth of $T$ is $d$ and each internal node has branching factor $b$, the set of leaves $\mathcal{L}(T)$ satisfies $|\mathcal{L}(T)| \leq b^{d}$, with equality when $T$ is a complete $b$-ary tree.

Worked example. A fair coin is tossed twice. Construct $T$ with root $r$; from $r$ draw edges labelled $H$ and $T$, each with probability $\tfrac{1}{2}$. From each child draw two further edges, again labelled $H$ and $T$. The four leaves are $HH, HT, TH, TT$. The probability of any leaf $\ell$ is the product of edge weights along the unique root-to-$\ell$ path: $P(HH) = \tfrac{1}{2}\cdot\tfrac{1}{2} = \tfrac{1}{4}$. Summing all leaf probabilities gives $\sum_{\ell \in \mathcal{L}} P(\ell) = 1$, confirming that the leaves form a partition of the sample space.

Key theorem (Multiplication Rule). Let $e_1, e_2, \ldots, e_d$ be the edges on a root-to-leaf path in a probability tree, with conditional probabilities $p_1, p_2, \ldots, p_d$ respectively. Then the probability of the corresponding outcome is

$$P(\text{outcome}) = \prod_{k=1}^{d} p_k.$$

This follows directly from the chain rule of conditional probability: $P(A_1 \cap A_2 \cap \cdots \cap A_d) = P(A_1)\,P(A_2 \mid A_1)\cdots P(A_d \mid A_1,\ldots,A_{d-1})$, where each factor corresponds to exactly one edge weight.

Lab cell (SymPy).

from sympy import Rational, prod

# Edge weights along one path: H then H
edge_weights = [Rational(1, 2), Rational(1, 2)]
leaf_prob = prod(edge_weights)
print(leaf_prob)   # 1/4

The tree diagram is the natural endpoint of this textbook because every concept encountered along the way — set theory, conditional probability, combinatorial counting — finds a home in its structure. Counting paths through $T$ answers combinatorial questions; weighting those paths answers probabilistic ones; pruning branches models decisions under uncertainty.
