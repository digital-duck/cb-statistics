Concept Book: Venn Diagram

Introductory Statistics Ch03 · Generated by SPL

Payoff

Throughout this text, we have built set theory from first principles—union, intersection, complement, and the algebra that governs them. The Venn diagram is not merely a picture; it is a faithful geometric model of Boolean set algebra, one in which every region corresponds to a logically distinct proposition about membership. Having mastered the underlying theory, we are now in a position to see why this representation is the natural endpoint of our journey and what doors it opens.

Definition. Let $U$ be a universal set and $A_1, A_2, \ldots, A_n \subseteq U$. A Venn diagram for these $n$ sets is a planar figure consisting of $n$ closed, simply connected regions inside a rectangle representing $U$, arranged so that every non-empty subset $S \subseteq \{1, \ldots, n\}$ corresponds to exactly one bounded region equal to $\bigcap_{i \in S} A_i \setminus \bigcup_{j \notin S} A_j$. For $n$ sets the diagram partitions $U$ into at most $2^n$ non-overlapping atomic regions.

Worked Example. Suppose $U = \{1,2,\ldots,10\}$, $A = \{1,2,3,4,5\}$, and $B = \{4,5,6,7\}$. The intersection $A \cap B = \{4,5\}$ occupies the lens region; $A \setminus B = \{1,2,3\}$ fills the left crescent; $B \setminus A = \{6,7\}$ the right crescent; and $U \setminus (A \cup B) = \{8,9,10\}$ fills the exterior. Every element of $U$ lands in exactly one atomic region, confirming the partition property.

Key Theorem (Inclusion–Exclusion). For finite sets $A$ and $B$,

$$|A \cup B| = |A| + |B| - |A \cap B|.$$

The Venn diagram makes this self-evident: summing $|A|$ and $|B|$ counts the intersection region twice, so we subtract $|A \cap B|$ once to recover the true cardinality of the union. The generalisation to $n$ sets,

$$\left|\bigcup_{i=1}^n A_i\right| = \sum_{|S|\geq 1}(-1)^{|S|+1}\left|\bigcap_{i\in S}A_i\right|,$$

follows by induction and is rendered immediately plausible by the $2^n$-region structure.

Lab Cell (SymPy).

from sympy import FiniteSet
U = FiniteSet(*range(1, 11))
A = FiniteSet(1, 2, 3, 4, 5)
B = FiniteSet(4, 5, 6, 7)
print("A ∩ B =", A & B)
print("A ∪ B =", A | B)
print("|A ∪ B| via inclusion–exclusion =", len(A) + len(B) - len(A & B))

The Venn diagram is the natural endpoint because it collapses abstract set identities into spatially verifiable facts: a student who can draw and read the diagram correctly has internalised the full Boolean lattice of subsets. From here, every quantitative discipline that asks "what belongs to which category?" becomes accessible—probability theory (events as regions, measure as area), database query optimisation (JOIN and INTERSECT as geometric overlap), formal logic (propositional models as region colouring), and survey analysis (cross-tabulation as region counting).

Set the coordinates, measure the area, and the rest of the theory follows.
