Complement Event

Definition. Let $S$ denote the sample space of an experiment — the set of all possible outcomes. For any event $A \subseteq S$, the complement of $A$, written $A^c$ (or $\bar{A}$), is the set of all outcomes in $S$ that do not belong to $A$:

$$A^c = S \setminus A = \{\omega \in S : \omega \notin A\}$$

Because every outcome either belongs to $A$ or does not, the events $A$ and $A^c$ share no outcomes and together account for everything in $S$: $A \cap A^c = \emptyset$ and $A \cup A^c = S$.

Worked Example. Roll a fair six-sided die, so $S = \{1, 2, 3, 4, 5, 6\}$. Define $A$ as the event "the result is even":

$$A = \{2, 4, 6\}$$

Then $A^c$ is the event "the result is odd":

$$A^c = \{1, 3, 5\}$$

Assigning uniform probabilities, $P(A) = 3/6 = 1/2$. Since $A \cup A^c = S$ and $A \cap A^c = \emptyset$, the probability axioms give $P(A) + P(A^c) = P(S) = 1$, so $P(A^c) = 1/2$. This confirms the result directly.

Key Theorem (Complement Rule). For any event $A$:

$$P(A^c) = 1 - P(A)$$

Proof sketch. By the axioms of probability, $P(S) = 1$. Since $A$ and $A^c$ are disjoint with $A \cup A^c = S$, the additivity axiom yields $P(A) + P(A^c) = 1$, from which the result follows immediately. $\square$

The complement rule is especially powerful when computing $P(A)$ directly is difficult but $P(A^c)$ is straightforward — a strategy sometimes called the indirect method.

Lab Cell (SymPy).

from sympy import Rational

# P(A) for rolling an even number on a fair die
p_A = Rational(3, 6)          # three even faces out of six
p_Ac = 1 - p_A                # complement rule
print(f"P(A)  = {p_A}")       # 1/2
print(f"P(Ac) = {p_Ac}")      # 1/2

# Verify: P(A) + P(Ac) == 1
assert p_A + p_Ac == 1, "Complement rule violated"
print("Complement rule verified:", p_A + p_Ac)
