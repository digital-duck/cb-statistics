Or Event

Definition. Let $(\Omega, \mathcal{F}, P)$ be a probability space. Given two events $A, B \in \mathcal{F}$, the or event (also called the union event) is the event $A \cup B$, defined as the set of all outcomes belonging to at least one of $A$ or $B$:

$$A \cup B = \{\omega \in \Omega : \omega \in A \text{ or } \omega \in B\}.$$

The probability of $A \cup B$ is governed by the Addition Rule:

$$P(A \cup B) = P(A) + P(B) - P(A \cap B).$$

The subtraction of $P(A \cap B)$ corrects for double-counting outcomes that lie in both events simultaneously. When $A$ and $B$ are mutually exclusive — that is, $A \cap B = \emptyset$ — the rule simplifies to $P(A \cup B) = P(A) + P(B)$.

Worked Example. A single fair die is rolled once, so $\Omega = \{1, 2, 3, 4, 5, 6\}$ with each outcome equally likely. Define:

$$A = \{\text{outcome is even}\} = \{2, 4, 6\}, \qquad B = \{\text{outcome is greater than 4}\} = \{5, 6\}.$$

Then $A \cap B = \{6\}$, and by the Addition Rule:

$$P(A \cup B) = \frac{3}{6} + \frac{2}{6} - \frac{1}{6} = \frac{4}{6} = \frac{2}{3}.$$

Direct verification: $A \cup B = \{2, 4, 5, 6\}$ contains four outcomes, confirming $P(A \cup B) = \tfrac{4}{6}$.

Key Theorem (Inclusion–Exclusion Principle). For any finite collection of events $A_1, A_2, \ldots, A_n \in \mathcal{F}$:

$$P\!\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i} P(A_i) - \sum_{i < j} P(A_i \cap A_j) + \sum_{i < j < k} P(A_i \cap A_j \cap A_k) - \cdots$$

This generalises the two-event Addition Rule by alternately adding and subtracting intersection probabilities to achieve exact counting.

from sympy import Rational, symbols
