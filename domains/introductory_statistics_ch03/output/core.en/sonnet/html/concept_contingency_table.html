Contingency Table

Definition. A contingency table (also called a cross-tabulation or two-way frequency table) is a rectangular array that displays the joint frequency distribution of two categorical variables. Given a sample of $n$ observations, each classified according to a row variable $X$ taking values $\{x_1, \ldots, x_r\}$ and a column variable $Y$ taking values $\{y_1, \ldots, y_c\}$, the contingency table records counts $n_{ij}$, where $n_{ij}$ denotes the number of observations in category $x_i$ of $X$ and category $y_j$ of $Y$. The marginal totals are $n_{i\cdot} = \sum_j n_{ij}$ and $n_{\cdot j} = \sum_i n_{ij}$, with grand total $n = \sum_i n_{i\cdot} = \sum_j n_{\cdot j}$.

Worked Example. A researcher surveys 200 university students, recording gender ($X$: Female, Male) and preferred study mode ($Y$: Solo, Group). The observed counts are:

| | Solo | Group | Total | |---------|------|-------|-------| | Female | 60 | 40 | 100 | | Male | 50 | 50 | 100 | | Total | 110 | 90 | 200 |

The expected count under independence of $X$ and $Y$ is $e_{ij} = \dfrac{n_{i\cdot}\, n_{\cdot j}}{n}$. For the Female–Solo cell: $e_{11} = \dfrac{100 \times 110}{200} = 55$.

Key Theorem (Pearson $\chi^2$ Test). Under the null hypothesis $H_0$ that $X$ and $Y$ are independent, the statistic

$$\chi^2 = \sum_{i=1}^{r}\sum_{j=1}^{c} \frac{(n_{ij} - e_{ij})^2}{e_{ij}}$$

converges in distribution to $\chi^2_{(r-1)(c-1)}$ as $n \to \infty$, provided all $e_{ij} \geq 5$. For the $2\times 2$ table above, the degrees of freedom equal $(2-1)(2-1)=1$. Computing all four terms gives $\chi^2 \approx 1.01$; since this falls below the critical value $\chi^2_{1,\,0.05} = 3.841$, we fail to reject $H_0$ at the 5% level.

from sympy.stats import ChiSquared, cdf
from sympy import Matrix, Rational, N

obs = Matrix([[60, 40], [50, 50]])
n = 200
row_totals = [100, 100]
col_totals = [110, 90]

expected = Matrix([[Rational(r*c, n) for c in col_totals] for r in row_totals])
chi2_stat = sum(
    (obs[i,j] - expected[i,j])**2 / expected[i,j]
    for i in range(2) for j in range(2)
)
print("chi2 =", N(chi2_stat, 4))   # 1.010
