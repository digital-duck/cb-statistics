相依事件

定义。 设 $(\Omega, \mathcal{F}, P)$ 为概率空间，$A, B \in \mathcal{F}$ 为两个事件。若

$$P(A \mid B) \neq P(A),$$

则称 $A$ 与 $B$ 为相依事件（dependent events）。等价地，$A$ 与 $B$ 相依当且仅当

$$P(A \cap B) \neq P(A)\,P(B).$$

直觉上，相依意味着事件 $B$ 的发生改变了我们对 $A$ 发生可能性的判断：知道 $B$ 已发生，为 $A$ 提供了额外的信息。

例题。 一个不透明袋中装有 $3$ 枚红球与 $2$ 枚蓝球，不放回地依次取出两球。设

$$A = \{\text{第二次取出红球}\}, \quad B = \{\text{第一次取出红球}\}.$$

计算 $P(A \mid B)$ 与 $P(A)$，并判断相依性。

解。 取球后不放回，故两次取球的结果相互影响。

$$P(B) = \frac{3}{5}.$$

在 $B$ 已发生的条件下，袋中剩余 $4$ 球（$2$ 红、$2$ 蓝），故

$$P(A \mid B) = \frac{2}{4} = \frac{1}{2}.$$

若 $B$ 未发生（第一次取蓝），袋中剩余 $3$ 红、$1$ 蓝，故

$$P(A \mid B^c) = \frac{3}{4}.$$

由全概率公式：

$$P(A) = P(A \mid B)\,P(B) + P(A \mid B^c)\,P(B^c) = \frac{1}{2}\cdot\frac{3}{5} + \frac{3}{4}\cdot\frac{2}{5} = \frac{3}{10} + \frac{3}{10} = \frac{3}{5}.$$

因 $P(A \mid B) = \dfrac{1}{2} \neq \dfrac{3}{5} = P(A)$，故 $A$ 与 $B$ 相依。

关键定理（乘法公式）。 对任意事件 $A, B$，只要 $P(B) > 0$，有

$$P(A \cap B) = P(B)\,P(A \mid B).$$

当 $A, B$ 相依时，此式不可化简为 $P(A)\,P(B)$；独立性恰好是相依性的特殊退化情形。

实验单元（SymPy）。

from fractions import Fraction

P_B  = Fraction(3, 5)
P_A_given_B  = Fraction(2, 4)
P_A_given_Bc = Fraction(3, 4)

P_A = P_A_given_B * P_B + P_A_given_Bc * (1 - P_B)
P_AB = P_B * P_A_given_B

print("P(A) =", P_A)          # 3/5
print("P(A∩B) =", P_AB)       # 3/10
print("P(A)·P(B) =", P_A * P_B)  # 9/25
print("相依？", P_AB != P_A * P_B)  # True

运行结果确认 $P(A \cap B) = \dfrac{3}{10} \neq \dfrac{9}{25} = P(A)\,P(B)$，从而验证了两事件的相依性。
