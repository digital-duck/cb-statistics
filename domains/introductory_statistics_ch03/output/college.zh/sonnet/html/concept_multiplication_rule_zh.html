乘法规则

定义。 设 $A$ 与 $B$ 为同一样本空间 $\Omega$ 上的两个事件，且 $P(B) > 0$。乘法规则（multiplication rule）将两事件的联合概率分解为条件概率与边际概率的乘积：

$$P(A \cap B) = P(B) \cdot P(A \mid B).$$

对称地，若 $P(A) > 0$，则同样有

$$P(A \cap B) = P(A) \cdot P(B \mid A).$$

该公式直接来自条件概率的定义 $P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}$，两边同乘 $P(B)$ 即得。对于三个事件 $A_1, A_2, A_3$，规则可链式推广：

$$P(A_1 \cap A_2 \cap A_3) = P(A_1) \cdot P(A_2 \mid A_1) \cdot P(A_3 \mid A_1 \cap A_2).$$

例题。 一个袋中装有 5 个红球与 3 个蓝球，共 8 个球。不放回地依次摸取两球，求两球均为红球的概率。

设 $A = \{\text{第一次取红球}\}$，$B = \{\text{第二次取红球}\}$。则

$$P(A) = \frac{5}{8}, \qquad P(B \mid A) = \frac{4}{7}.$$

由乘法规则，

$$P(A \cap B) = \frac{5}{8} \times \frac{4}{7} = \frac{20}{56} = \frac{5}{14} \approx 0.357.$$

关键定理（独立事件的化简）。 若 $A$ 与 $B$ 相互独立，则 $P(A \mid B) = P(A)$，乘法规则化简为

$$P(A \cap B) = P(A) \cdot P(B).$$

注意：独立性与互斥性不同。两个概率均为正的互斥事件 $A \cap B = \varnothing$ 必然不独立，因为 $P(A \cap B) = 0 \neq P(A)P(B)$。

实验单元（SymPy）。

from fractions import Fraction

p_A  = Fraction(5, 8)          # P(第一次红球)
p_B_given_A = Fraction(4, 7)   # P(第二次红球 | 第一次红球)
p_AB = p_A * p_B_given_A       # 乘法规则
print(f"P(A ∩ B) = {p_AB}")    # 输出：5/14

运行上述代码可精确验证分数运算，避免浮点误差。将初始红球数改为变量，即可探究样本量对联合概率的影响。
