韦恩图的本质

韦恩图（Venn Diagram）是集合论在视觉语言中的忠实翻译：给定全集 $U$ 及其子集 $A_1, A_2, \ldots, A_n \subseteq U$，韦恩图以平面区域表示每个集合，区域的交叠精确对应集合的交集 $A_i \cap A_j$，区域的并集对应 $A_i \cup A_j$，补集 $A_i^c = U \setminus A_i$ 则以区域外部呈现。韦恩图之所以成为本书的终点，正因为它将本书前各章所积累的符号运算——交、并、补、差——压缩为一幅可直觉检验的图像，使抽象定义获得几何直观的支撑。

具体示例

设全集为一个班级的 30 名学生，$A$ = 选修数学的学生，$B$ = 选修物理的学生。已知 $|A| = 18$，$|B| = 14$，$|A \cap B| = 7$。由容斥原理：

$$|A \cup B| = |A| + |B| - |A \cap B| = 18 + 14 - 7 = 25.$$

只选数学（不选物理）的学生数为 $|A \setminus B| = 11$，只选物理的为 $|B \setminus A| = 7$，两者皆不选的为 $|U| - |A \cup B| = 5$。将这四个数字填入韦恩图的四个互不重叠的区域，验证之和恰为 30——图形本身充当了计算的自检机制。

实验室代码（SymPy）

from sympy import FiniteSet

U = FiniteSet(*range(1, 31))
A = FiniteSet(*range(1, 19))
B = FiniteSet(*range(12, 26))

print("A ∪ B =", len(A + B))
print("A ∩ B =", len(A * B))
print("A \\ B =", len(A - B))
print("容斥验证:", len(A) + len(B) - len(A * B) == len(A + B))
