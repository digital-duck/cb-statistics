条件概率

定义。 设 $(\Omega, \mathcal{F}, P)$ 为概率空间，$A, B \in \mathcal{F}$ 且 $P(B) > 0$。在事件 $B$ 已发生的条件下，事件 $A$ 发生的条件概率定义为

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}.$$

直觉上，条件概率将样本空间从 $\Omega$ 收缩至 $B$，并在新空间上重新归一化。可验证 $P(\cdot \mid B)$ 本身满足 Kolmogorov 公理，故构成合法的概率测度。

例题。 掷一枚均匀六面骰子一次，$\Omega = \{1,2,3,4,5,6\}$，各基本事件概率均为 $\tfrac{1}{6}$。令

$$A = \{\text{点数为偶数}\} = \{2,4,6\}, \quad B = \{\text{点数大于 3}\} = \{4,5,6\}.$$

则 $A \cap B = \{4,6\}$，故

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{2/6}{3/6} = \frac{2}{3}.$$

这说明：若已知点数大于 3，则为偶数的概率由原来的 $\tfrac{1}{2}$ 上升至 $\tfrac{2}{3}$——信息改变了我们对随机结果的信念。

关键定理（乘法公式与全概率公式）。 由定义直接得到乘法公式：

$$P(A \cap B) = P(A \mid B)\,P(B).$$

推广至有限划分 $\{B_1, B_2, \ldots, B_n\}$（两两不相交且并为 $\Omega$）时，得全概率公式：

$$P(A) = \sum_{i=1}^{n} P(A \mid B_i)\,P(B_i).$$

该公式将复杂事件 $A$ 的概率分解为在各"情景" $B_i$ 下的加权平均，是贝叶斯推断的基础。

实验单元（SymPy）。

from sympy import Rational, symbols

# 定义概率
P_B  = Rational(3, 6)          # P(B) = 1/2
P_AB = Rational(2, 6)          # P(A∩B) = 1/3

P_A_given_B = P_AB / P_B
print("P(A|B) =", P_A_given_B)  # 输出 2/3

# 全概率公式验证
P_A_given_Bc = Rational(1, 3)   # 点数<=3时偶数概率 P(A|B^c)
P_Bc = 1 - P_B
P_A = P_A_given_B * P_B + P_A_given_Bc * P_Bc
print("P(A) =", P_A)            # 输出 1/2，与直接计算一致
