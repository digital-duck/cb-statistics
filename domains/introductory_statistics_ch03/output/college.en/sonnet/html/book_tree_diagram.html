Concept Book: Tree Diagram

Introductory Statistics Ch03 · Generated by SPL

Payoff

Throughout this text, each concept has built on the last — sets gave us a language for collections, functions gave us maps between them, and recursive structures gave us the machinery to describe self-similar patterns. The tree diagram is where these threads converge. It is not merely a drawing aid; it is a combinatorial object that encodes the complete sample space of a sequential process, making every branch a claim about conditional structure and every leaf a fully-specified outcome.

What a tree diagram achieves. Given a multi-stage experiment with stages $S_1, S_2, \ldots, S_k$, where stage $i$ has $n_i$ outcomes, the associated tree has depth $k$ and at most $n_1 \cdot n_2 \cdots n_k$ leaves. Each root-to-leaf path $\omega = (s_1, s_2, \ldots, s_k)$ is a sample point, and the probability assigned to that path is the product of the conditional probabilities along each edge:

$$P(\omega) = P(s_1)\cdot P(s_2 \mid s_1)\cdots P(s_k \mid s_1, \ldots, s_{k-1}).$$

This multiplicative structure is not a convention — it is a direct consequence of the chain rule of probability, so the tree is a geometric proof that the formula holds.

Worked example. A bag contains two red and one blue marble. Draw without replacement twice. The tree has three branches at depth one ($R_1, R_2, B$) and two branches at depth two from each node, yielding six leaves. The leaf $(R_1, B)$ carries probability $\frac{2}{3} \cdot \frac{1}{2} = \frac{1}{3}$. Summing all six leaf probabilities gives exactly $1$, confirming the tree partitions the sample space.

Key theorem (Partition of unity). For any finite sequential experiment, the sum of probabilities across all leaves of the associated tree diagram equals $1$.

Proof sketch. At each internal node, the outgoing edge probabilities are conditional probabilities that sum to $1$. The total probability of all leaves is therefore the product of finitely many such sums, each equal to $1$, so the total is $1$. $\square$

from sympy import Rational, symbols
from sympy.combinatorics import Permutation

# Enumerate leaves of a two-draw without-replacement tree
bag = {'R1': Rational(2,3), 'B': Rational(1,3)}
second = {'R1_then_R2': Rational(1,2), 'R1_then_B': Rational(1,2),
          'B_then_R':  Rational(1,1)}   # only one outcome remains

leaves = {
    ('R', 'R'): Rational(2,3) * Rational(1,2),
    ('R', 'B'): Rational(2,3) * Rational(1,2),
    ('B', 'R'): Rational(1,3) * Rational(1,1),
}
assert sum(leaves.values()) == 1, "Partition of unity violated"
print(leaves)

The tree diagram is the natural endpoint of this book because it transforms the abstract axioms of probability — sample space, event, measure — into a concrete, traversable structure. Every algorithm that enumerates possibilities (minimax in game trees, CYK parsing in linguistics, branch-and-bound in optimisation) is, at its core, walking a tree diagram. You now possess the conceptual vocabulary to read those algorithms not as opaque procedures but as principled explorations of a structured sample space. Choose any one of these domains — decision theory, natural language parsing, or combinatorial optimisation — and carry the tree further; the path from this chapter's definition to a publishable result is shorter than it appears.
