Concept Book: Venn Diagram

Introductory Statistics Ch03 · Generated by SPL

Payoff

Throughout this text, we have built the machinery of sets piece by piece: membership, union, intersection, complement, and the algebra that governs them. The Venn diagram is not merely a picture—it is the natural geometric realization of that algebra, a coordinate system for set-theoretic reasoning in which every region corresponds to a logically distinct combination of membership predicates.

Definition. Let $U$ be a universal set and $A_1, A_2, \ldots, A_n \subseteq U$. A Venn diagram for these $n$ sets is a partition of a planar region representing $U$ into exactly $2^n$ cells, where each cell corresponds to one of the $2^n$ possible intersection types $X_1 \cap X_2 \cap \cdots \cap X_n$ with $X_i \in \{A_i,\, A_i^c\}$. A cell is shaded or labeled to indicate whether it is empty or populated.

Worked Example. Consider $U = \{1, 2, \ldots, 10\}$, $A = \{2,4,6,8,10\}$ (even numbers), and $B = \{3,6,9\}$ (multiples of three). The four cells of the two-set Venn diagram are: $A \cap B = \{6\}$, $A \setminus B = \{2,4,8,10\}$, $B \setminus A = \{3,9\}$, and $(A \cup B)^c = \{1,5,7\}$. Reading the diagram immediately yields $|A \cup B| = 1 + 4 + 2 = 7$, confirming the inclusion-exclusion identity $|A \cup B| = |A| + |B| - |A \cap B| = 5 + 3 - 1 = 7$.

Key Theorem (Inclusion-Exclusion). For finite sets $A_1, \ldots, A_n$,

The Venn diagram thus closes the conceptual arc of this book: it translates abstract set algebra into a spatial grammar that makes logical relationships visible, countable, and computable. You now have every prerequisite to pursue one of the richest downstream topics—probability theory, where each Venn-diagram cell becomes an event whose measure obeys the very inclusion-exclusion law you have just proved.
