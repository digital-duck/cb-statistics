What the Simulation Achieves

A cookie-recipe simulation is a discrete, state-space model in which each recipe $r \in \mathcal{R}$ is represented as a vector of ingredient quantities $\mathbf{q}_r \in \mathbb{R}_{\geq 0}^n$, a set of procedural steps $S_r = (s_1, s_2, \ldots, s_k)$, and a scalar outcome measure $\phi: \mathbb{R}^n \times S \to \mathbb{R}$ (e.g., texture score, yield, cost). The simulation advances through each step, updating an internal state $\sigma_t$ according to a transition function $\delta(\sigma_t, s_{t+1})$, until a terminal state $\sigma_T$ is reached and $\phi$ is evaluated. Formally, the simulation defines a function

$$\text{Sim}: \mathcal{R} \times \Omega \to \mathbb{R},$$

where $\Omega$ is a probability space encoding measurement noise and ingredient variability.

This construction is the natural endpoint of the book because it unifies every prior concept — combinatorial enumeration (the recipe space $\mathcal{R}$), stochastic modelling (the noise $\Omega$), and numerical optimisation (maximising $\phi$) — into a single executable object. The student moves from studying these tools in isolation to wielding them in concert.

Worked Example

Suppose $n = 3$ ingredients: flour ($x_1$ g), sugar ($x_2$ g), butter ($x_3$ g). A recipe is feasible when $x_1 + x_2 + x_3 \leq B$ for a fixed budget $B = 300$ g. Define the quality score

$$\phi(x_1, x_2, x_3) = 2\sqrt{x_1} + \ln(1 + x_2) - \tfrac{1}{50}(x_3 - 80)^2.$$

Running the simulation over a uniform grid of 1 000 feasible recipes identifies the maximiser near $(x_1, x_2, x_3) \approx (160, 90, 50)$ with $\phi^* \approx 30.4$. The simulation also computes the empirical variance of $\phi$ under $\pm 5\%$ ingredient noise, revealing that the optimum is robust: $\operatorname{Var}[\phi] < 0.8$ across 10 000 Monte Carlo draws.

Key Theorem

Theorem (Convergence of Monte Carlo estimate). Let $\hat{\phi}_N = N^{-1}\sum_{i=1}^N \phi(\mathbf{q} + \boldsymbol{\varepsilon}_i)$, where $\boldsymbol{\varepsilon}_i \sim \mathcal{N}(\mathbf{0}, \sigma^2 I)$. If $\phi$ is Lipschitz with constant $L$, then

$$\mathbb{E}[|\hat{\phi}_N - \mathbb{E}[\phi]|] \leq \frac{L\sigma\sqrt{n}}{\sqrt{N}}.$$

Proof sketch. Apply the Cauchy–Schwarz inequality to the mean-squared error, then invoke the Lipschitz bound on $\phi$ to replace gradient terms with $L^2 \sigma^2 n$. Taking square roots yields the stated rate.

The theorem tells the practitioner exactly how many simulation runs are needed to achieve a desired estimation accuracy, making the framework both theoretically grounded and practically actionable.

Lab Cell

import sympy as sp

x1, x2, x3 = sp.symbols('x1 x2 x3', positive=True)
phi = 2*sp.sqrt(x1) + sp.ln(1 + x2) - (x3 - 80)**2 / 50

# Partial derivatives — first-order optimality conditions
grad = [sp.diff(phi, v) for v in (x1, x2, x3)]
sp.pprint(grad)

# Critical point along x3 axis (unconstrained)
x3_star = sp.solve(grad[2], x3)
print("Optimal butter:", x3_star)

Running this cell confirms $x_3^* = 80$ analytically, matching the numerical optimum and illustrating how symbolic computation can validate simulation output at zero additional cost.

The framework developed here extends far beyond baking. The same trio of state-space enumeration, stochastic perturbation, and gradient analysis governs supply-chain optimisation, pharmacological dosing, and reinforcement-learning reward shaping. Choose one of these domains that excites you, re-parameterise $\phi$ for its context, and carry the simulation forward — the machinery is already in your hands.
