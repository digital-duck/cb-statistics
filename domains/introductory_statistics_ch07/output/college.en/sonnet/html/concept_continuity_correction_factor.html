Continuity Correction Factor

Definition. Let $X$ be a discrete random variable taking integer values, and let $Z \sim \mathcal{N}(\mu, \sigma^2)$ be the normal approximation to its distribution. The continuity correction factor is an adjustment applied when approximating a probability involving $X$ by a corresponding probability involving $Z$, replacing each integer value $k$ by the interval $[k - \tfrac{1}{2},\, k + \tfrac{1}{2}]$. Formally, for integers $a \leq b$:

$$P(a \leq X \leq b) \approx P\!\left(a - \tfrac{1}{2} \leq Z \leq b + \tfrac{1}{2}\right).$$

The correction accounts for the fact that the normal distribution is continuous while $X$ is not: each integer $k$ has positive probability mass, which the continuous density "misses" unless we spread $k$ across its surrounding unit interval.

Worked Example. Suppose $X \sim \mathrm{Binomial}(n=100,\, p=0.4)$, so $\mu = np = 40$ and $\sigma = \sqrt{np(1-p)} = \sqrt{24} \approx 4.899$. We wish to compute $P(X \leq 45)$.

Without correction:

$$P(X \leq 45) \approx P\!\left(Z \leq \frac{45 - 40}{4.899}\right) = P(Z \leq 1.021) \approx 0.8465.$$

With continuity correction:

$$P(X \leq 45) \approx P\!\left(Z \leq \frac{45.5 - 40}{4.899}\right) = P(Z \leq 1.122) \approx 0.8691.$$

The exact binomial value is $0.8720$, so the corrected approximation reduces the absolute error from $0.0255$ to $0.0029$.

Key Theorem. (Berry–Esseen, applied.) For $X \sim \mathrm{Binomial}(n, p)$ with $q = 1-p$, the normal approximation error satisfies

$$\sup_{x \in \mathbb{R}} \left|P(X \leq x) - \Phi\!\left(\frac{x + \tfrac{1}{2} - np}{\sqrt{npq}}\right)\right| = O\!\left(\frac{1}{\sqrt{n}}\right),$$

where $\Phi$ is the standard normal CDF. The $+\tfrac{1}{2}$ term is precisely the continuity correction, and its inclusion reduces the leading-order error constant substantially.

Lab Cell.

from sympy import symbols, binomial, summation, N
from sympy.stats import Normal, cdf

n, p = 100, 0.4
mu, sigma = n*p, (n*p*(1-p))**0.5
Z = Normal('Z', 0, 1)

exact     = sum(float(binomial(n,k)) * p**k * (1-p)**(n-k) for k in range(46))
no_corr   = float(cdf(Z)((45   - mu)/sigma))
with_corr = float(cdf(Z)((45.5 - mu)/sigma))

print(f"Exact:            {exact:.6f}")
print(f"No correction:    {no_corr:.6f}")
print(f"With correction:  {with_corr:.6f}")
