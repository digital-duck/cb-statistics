Concept Book: Pocket Change Simulation

Introductory Statistics Ch07 · Generated by SPL

Payoff

Throughout this text, we have built a ladder of ideas: discrete probability spaces, generating functions, recurrence relations, and Monte Carlo estimation. The concept of pocket change simulation stands at the top of that ladder, because it forces every rung to bear weight simultaneously. Understanding it fully means you can count, compute, and verify—three distinct epistemic acts—within a single coherent model.

Definition. Let $C = \{c_1, c_2, \ldots, c_k\}$ be a finite set of coin denominations with $c_i \in \mathbb{Z}_{>0}$. A pocket change configuration for target value $n$ is a tuple $(x_1, x_2, \ldots, x_k) \in \mathbb{Z}_{\geq 0}^k$ satisfying $\sum_{i=1}^{k} c_i x_i = n$. The pocket change simulation draws configurations uniformly at random from this solution set and aggregates statistics over $N$ independent trials.

Worked Example. Take $C = \{1, 5, 10, 25\}$ (US coins) and $n = 30$ cents. The generating function for the number of configurations is the coefficient of $z^{30}$ in

$$ G(z) = \frac{1}{(1-z)(1-z^5)(1-z^{10})(1-z^{25})}. $$

Expanding via partial fractions or direct polynomial multiplication yields $[z^{30}]\,G(z) = 18$. A simulation drawing $N = 10{,}000$ configurations and computing the sample mean number of coins per configuration will converge to the true expectation $\mu$ with standard error $\sigma/\sqrt{N}$, where $\sigma^2$ is the variance of coin count across all 18 configurations.

Key Theorem (Law of Large Numbers, discrete form). If $X_1, X_2, \ldots$ are i.i.d. random variables with $\mathbb{E}[X_1] = \mu < \infty$, then

$$ \bar{X}_N = \frac{1}{N}\sum_{i=1}^{N} X_i \xrightarrow{a.s.} \mu \quad \text{as } N \to \infty. $$

The simulation is not mere computation—it is a constructive proof that the empirical distribution concentrates around the theoretical one.

Lab Cell (SymPy).

from sympy import symbols, Poly, prod, Rational
z = symbols('z')
denoms = [1, 5, 10, 25]
G = prod(1 / (1 - z**d) for d in denoms)
coeffs = Poly(G.series(z, 0, 31).removeO(), z).nth(30)
print(coeffs)   # expects 18

The pocket change problem is, at its core, a microcosm of constrained resource allocation: the same generating-function machinery governs inventory partitioning, RNA secondary-structure counting, and knapsack variants in operations research. Each domain simply relabels $c_i$ and $n$. We invite you to take the knapsack interpretation—where $c_i$ are item weights and $n$ is a capacity—and derive the expected weight utilization under a uniform draw of feasible packings. The tools are already in your hands.
