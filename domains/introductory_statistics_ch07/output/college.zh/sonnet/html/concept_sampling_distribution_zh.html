抽样分布

定义。 设总体 $X$ 具有分布函数 $F(x)$，从中抽取容量为 $n$ 的简单随机样本 $(X_1, X_2, \ldots, X_n)$。由样本构造的统计量 $T = g(X_1, X_2, \ldots, X_n)$ 本身是一个随机变量，其概率分布称为该统计量的抽样分布（sampling distribution）。抽样分布刻画了在重复抽样过程中统计量取值的随机变动规律，是统计推断的理论基础。

具体示例。 设总体服从正态分布 $X \sim \mathcal{N}(\mu, \sigma^2)$，取样本量 $n = 4$，考察样本均值

$$\bar{X} = \frac{1}{4}(X_1 + X_2 + X_3 + X_4).$$

由正态分布的再生性，$\bar{X}$ 仍服从正态分布。其期望为

$$\mathbb{E}[\bar{X}] = \mu,$$

方差为

$$\operatorname{Var}(\bar{X}) = \frac{\sigma^2}{4}.$$

因此 $\bar{X} \sim \mathcal{N}\!\left(\mu,\, \dfrac{\sigma^2}{4}\right)$。若取 $\mu = 10,\, \sigma^2 = 16$，则 $\bar{X} \sim \mathcal{N}(10, 4)$，即均值的标准差（称为标准误差，standard error）为 $\sigma/\sqrt{n} = 2$，远小于总体标准差 $4$，体现了平均化对波动的压缩效果。

核心定理（中心极限定理）。 设 $X_1, X_2, \ldots, X_n$ 为来自均值 $\mu$、方差 $\sigma^2 < \infty$ 的任意总体的独立同分布样本，则当 $n \to \infty$ 时，

$$\frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} \mathcal{N}(0, 1).$$

此定理表明，无论总体分布形态如何，样本量足够大时，标准化样本均值的抽样分布均趋近于标准正态分布，这为大样本统计推断提供了普适性工具。

实验单元（SymPy）。

from sympy import symbols, sqrt, stats, simplify
from sympy.stats import Normal, E, variance

mu, sigma, n = symbols('mu sigma n', positive=True)
X_bar = Normal('X_bar', mu, sigma / sqrt(n))

print("期望:", E(X_bar))          # mu
print("方差:", simplify(variance(X_bar)))  # sigma**2 / n

运行上述代码，可验证 $\mathbb{E}[\bar{X}] = \mu$ 及 $\operatorname{Var}(\bar{X}) = \sigma^2/n$，直观确认抽样分布的两个基本性质。
