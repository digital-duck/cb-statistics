Cookie Recipes Simulation

定义

曲奇食谱仿真（Cookie Recipes Simulation）是一种离散概率模型，用于描述在给定原材料约束和配方参数下，随机生成可行食谱的过程。设原材料集合为 $\mathcal{I} = \{i_1, i_2, \ldots, i_n\}$，每种原材料的用量 $x_j \in [0, M_j]$（其中 $M_j$ 为上限），配方向量定义为 $\mathbf{x} = (x_1, x_2, \ldots, x_n)^{\top} \in \mathbb{R}^n$。一个可行配方须满足线性约束系统：

$$A\mathbf{x} \leq \mathbf{b}, \quad \mathbf{x} \geq \mathbf{0}$$

其中矩阵 $A \in \mathbb{R}^{m \times n}$ 编码营养或口味约束，向量 $\mathbf{b} \in \mathbb{R}^m$ 为对应上界。仿真的目标是在可行域 $\mathcal{F} = \{\mathbf{x} : A\mathbf{x} \leq \mathbf{b},\ \mathbf{x} \geq \mathbf{0}\}$ 上按某一目标分布 $\pi(\mathbf{x})$ 进行采样。

例题

设有两种原材料：面粉 $x_1$（克）与糖 $x_2$（克），约束条件为

$$x_1 + x_2 \leq 200, \quad x_1 \geq 50, \quad x_2 \geq 30$$

可行域为凸多边形，顶点为 $(50,\,30)$，$(170,\,30)$，$(50,\,150)$。若目标函数为甜度得分 $f(\mathbf{x}) = 0.3x_1 + 0.7x_2$，则最优配方在顶点 $(50,\,150)$ 处取得最大值 $f^* = 0.3(50) + 0.7(150) = 120$。

核心定理

定理（可行域采样收敛性）：设 $\mathcal{F}$ 为非空有界凸多面体，$\pi(\mathbf{x})$ 为 $\mathcal{F}$ 上的连续概率密度函数。以 Hit-and-Run 马尔可夫链蒙特卡洛（MCMC）方法在 $\mathcal{F}$ 内采样，经 $T$ 步后，样本分布 $\mu_T$ 满足：

$$\|\mu_T - \pi\|_{\mathrm{TV}} \leq C \cdot \rho^T$$

其中 $C > 0$ 为常数，$0 < \rho < 1$ 为混合率，$\|\cdot\|_{\mathrm{TV}}$ 为全变差距离。该定理保证算法以指数速度收敛至目标分布。

实验单元（SymPy）

from sympy import symbols, linsolve, Matrix

x1, x2 = symbols('x1 x2', nonneg=True)
A = Matrix([[1, 1]])
b = Matrix([200])
# 求顶点：x1 + x2 = 200, x1 = 50
sol = linsolve([x1 + x2 - 200, x1 - 50], (x1, x2))
print(sol)  # {(50, 150)}

通过本节可见，曲奇食谱仿真将直觉上的"选材调配"问题严格化为凸优化与随机采样问题，为食品工程与组合优化提供了统一的数学框架。
