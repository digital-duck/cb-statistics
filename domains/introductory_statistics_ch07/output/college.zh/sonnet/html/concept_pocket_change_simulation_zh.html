Pocket Change Simulation

定义

零钱模拟是一类离散随机过程，用于描述从有限面值集合中随机抽取硬币、逐步累积总金额的动态行为。设硬币面值集合为 $C = \{c_1, c_2, \ldots, c_k\}$，每枚硬币以概率分布 $\mathbf{p} = (p_1, p_2, \ldots, p_k)$ 被选取，其中 $\sum_{i=1}^k p_i = 1$。经过 $n$ 次独立投取后，累积金额为随机变量

$$S_n = \sum_{j=1}^{n} X_j,$$

其中各 $X_j$ 独立同分布，$P(X_j = c_i) = p_i$。此模型是经典复合随机游走的离散特例，广泛应用于排队论、密码学货币协议及组合计数。

例题

设 $C = \{1, 5, 10\}$（单位：分），对应概率 $\mathbf{p} = (0.5,\ 0.3,\ 0.2)$。

  • 单次期望值：$\mu = 1 \times 0.5 + 5 \times 0.3 + 10 \times 0.2 = 0.5 + 1.5 + 2.0 = 4.0$（分）。
  • 单次方差：$\sigma^2 = E[X^2] - \mu^2$，其中 $E[X^2] = 1^2(0.5)+5^2(0.3)+10^2(0.2) = 0.5+7.5+20 = 28$，故 $\sigma^2 = 28 - 16 = 12$。
  • 经过 $n = 25$ 次投取后，$E[S_{25}] = 25 \times 4 = 100$（分），$\operatorname{Var}(S_{25}) = 25 \times 12 = 300$。

    • 关键定理（中心极限定理的应用）

    定理：设 $\mu = E[X_j]$，$\sigma^2 = \operatorname{Var}(X_j) < \infty$。则当 $n \to \infty$ 时，

    $$\frac{S_n - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1).$$

    证明梗概：由于各 $X_j$ 独立同分布且方差有限，Lindeberg 条件自动满足，经典中心极限定理直接适用。$\square$

    该定理保证：即使面值分布高度不对称，累积金额的标准化形式在样本量充分大时均趋近正态分布，为蒙特卡洛置信区间的构造提供理论基础。

    实验单元（SymPy / NumPy）

    import numpy as np
from sympy import symbols, Rational, simplify

# 符号计算期望与方差
c = [1, 5, 10]
p = [Rational(1,2), Rational(3,10), Rational(1,5)]
mu    = sum(ci*pi for ci, pi in zip(c, p))
E_X2  = sum(ci**2 * pi for ci, pi in zip(c, p))
var   = simplify(E_X2 - mu**2)
print(f"μ = {mu}, σ² = {var}")

# 蒙特卡洛模拟（n=25, 重复10000次）
rng = np.random.default_rng(42)
samples = rng.choice(c, size=(10_000, 25), p=[0.5, 0.3, 0.2])
S = samples.sum(axis=1)
print(f"模拟均值 ≈ {S.mean():.2f}, 模拟标准差 ≈ {S.std():.2f}")
