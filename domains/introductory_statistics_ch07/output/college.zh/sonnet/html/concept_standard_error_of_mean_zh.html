Standard Error Of Mean

定义。 设 $X_1, X_2, \ldots, X_n$ 为独立同分布的随机变量，均值为 $\mu$，方差为 $\sigma^2$。样本均值定义为

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i.$$

均值的标准误差（Standard Error of the Mean，简称 SEM）是 $\bar{X}_n$ 作为随机变量的标准差，记作

$$\mathrm{SE}(\bar{X}_n) = \frac{\sigma}{\sqrt{n}}.$$

当总体标准差 $\sigma$ 未知时，用样本标准差 $s = \sqrt{\frac{1}{n-1}\sum_{i=1}^n(X_i - \bar{X}_n)^2}$ 代替，得到估计量 $\widehat{\mathrm{SE}} = s/\sqrt{n}$。

概念辨析。 标准误差与标准差 $\sigma$ 有本质区别：$\sigma$ 刻画单个观测值的离散程度，而 $\mathrm{SE}$ 刻画样本均值在重复抽样中的波动幅度。样本量 $n$ 越大，$\mathrm{SE}$ 越小，均值估计越精确——这正是大样本优势的数学根源。

例题。 某班级数学成绩服从均值 $\mu = 75$、标准差 $\sigma = 12$ 的正态分布。现随机抽取 $n = 36$ 名学生。

  • 计算 SEM：$\mathrm{SE} = 12/\sqrt{36} = 2$。
  • 由中心极限定理，$\bar{X}_{36} \sim \mathcal{N}(75,\, 4)$（方差为 $\mathrm{SE}^2 = 4$）。
  • 样本均值落在 $[73, 77]$ 的概率为 $P(|\bar{X}-75| \le 2) = P(|Z| \le 1) \approx 68.3\%$，其中 $Z$ 为标准正态变量。

    • 关键定理（中心极限定理的推论）。 若 $\sigma^2 < \infty$，则当 $n \to \infty$ 时，

    $$\frac{\bar{X}_n - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1).$$

    这保证了无论总体分布如何，只要样本量足够大，$\bar{X}_n$ 的抽样分布均近似正态，SEM 成为构造置信区间的核心参数。

    实验单元（SymPy）。

    import numpy as np
from sympy import symbols, sqrt, N

sigma, n = symbols('sigma n', positive=True)
SEM = sigma / sqrt(n)

# 数值示例：sigma=12, n=36
print("SEM =", N(SEM.subs({sigma: 12, n: 36})))

# 模拟验证
rng = np.random.default_rng(42)
means = [rng.normal(75, 12, 36).mean() for _ in range(10_000)]
print(f"模拟 SEM ≈ {np.std(means):.4f}，理论值 = 2.0000")

    运行结果应给出模拟 SEM 约为 $2.00$，与理论值吻合，直观验证了公式 $\sigma/\sqrt{n}$ 的正确性。
