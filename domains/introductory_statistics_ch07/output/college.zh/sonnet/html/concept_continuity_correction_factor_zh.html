连续性修正因子

定义。 设离散随机变量 $X$ 服从二项分布 $B(n, p)$，其均值 $\mu = np$，方差 $\sigma^2 = np(1-p)$。当 $n$ 充分大时，正态近似给出

$$P(X \leq k) \approx \Phi\!\left(\frac{k - \mu}{\sigma}\right),$$

其中 $\Phi$ 为标准正态分布函数。然而，由于二项分布取整数值，而正态分布在实数轴上连续，直接代入整数 $k$ 会引入系统误差。连续性修正因子（continuity correction factor）通过将离散点 $k$ 替换为区间 $[k-\tfrac{1}{2},\, k+\tfrac{1}{2}]$ 来弥补这一误差，从而得到修正后的近似：

$$P(X \leq k) \approx \Phi\!\left(\frac{k + \tfrac{1}{2} - \mu}{\sigma}\right).$$

类似地，$P(X \geq k) \approx 1 - \Phi\!\left(\dfrac{k - \tfrac{1}{2} - \mu}{\sigma}\right)$。

例题。 设 $X \sim B(100,\, 0.4)$，求 $P(X \leq 35)$。

此时 $\mu = 40$，$\sigma = \sqrt{24} \approx 4.899$。

未修正：$\displaystyle\Phi\!\left(\frac{35 - 40}{4.899}\right) = \Phi(-1.021) \approx 0.1537$。

加入连续性修正：$\displaystyle\Phi\!\left(\frac{35.5 - 40}{4.899}\right) = \Phi(-0.919) \approx 0.1792$。

二项分布精确值为 $P(X \leq 35) \approx 0.1795$，修正后误差从 $0.026$ 缩小至 $0.0003$，精度提升约一个数量级。

关键定理（Berry–Esseen 界）。 设 $X_1, \ldots, X_n$ 独立同分布，均值 $\mu$，方差 $\sigma^2$，三阶绝对矩 $\rho = E|X_i - \mu|^3 < \infty$。令 $S_n = \sum_{i=1}^n X_i$，则对所有 $x$ 一致成立

$$\sup_{x \in \mathbb{R}}\left|P\!\left(\frac{S_n - n\mu}{\sigma\sqrt{n}} \leq x\right) - \Phi(x)\right| \leq \frac{C\rho}{\sigma^3 \sqrt{n}},$$

其中常数 $C < 0.4748$。连续性修正将上界中的主项从 $O(n^{-1/2})$ 降低至 $O(n^{-1})$，这正是其精度改善的理论根据。

实验单元（SymPy）

from sympy import symbols, binomial, Rational, N
from sympy.stats import Binomial, P, Normal, cdf

n, p, k = 100, Rational(2, 5), 35
X = Binomial('X', n, p)
exact = P(X <= k)

Z = Normal('Z', 0, 1)
mu, sigma = n*p, (n*p*(1-p))**Rational(1,2)
approx_raw = cdf(Z)((k - mu)/sigma)
approx_cc  = cdf(Z)((k + Rational(1,2) - mu)/sigma)

print("精确值:  ", N(exact, 6))
print("无修正:  ", N(approx_raw, 6))
print("有修正:  ", N(approx_cc,  6))
