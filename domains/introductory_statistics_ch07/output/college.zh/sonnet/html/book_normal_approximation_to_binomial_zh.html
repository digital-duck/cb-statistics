Concept Book: Normal Approximation To Binomial

收益

定义与核心成就

二项分布的正态近似，正式表述为：若随机变量 $X \sim \text{Binomial}(n, p)$，则当 $n$ 足够大时，

$$Z = \frac{X - np}{\sqrt{np(1-p)}} \xrightarrow{d} \mathcal{N}(0,1)$$

以分布收敛的方式成立。这一结论是中心极限定理在离散情形下的具体体现：无数个独立伯努利试验的累积效应，必然涌现出钟形曲线。它之所以是本书的自然终点，恰在于此——从单次"成功/失败"的最简模型出发，经过期望、方差、矩母函数、大数定律的层层铺垫，最终抵达连续概率论的核心地带。离散与连续在此握手言和。

具体计算示例

设某产品的次品率 $p = 0.04$，抽检 $n = 200$ 件，求次品数 $X \leq 12$ 的概率。精确计算需对二项分布求和，涉及大量组合数。利用正态近似：

$$\mu = np = 8, \quad \sigma = \sqrt{np(1-p)} = \sqrt{7.68} \approx 2.77$$

施加连续性修正后：

$$P(X \leq 12) \approx P\!\left(Z \leq \frac{12.5 - 8}{2.77}\right) = \Phi(1.625) \approx 0.9479$$

精确值为 $0.9471$，误差不足 $0.1\%$，计算量却从数十项求和压缩为查一次标准正态表。

核心定理

定理（误差界，Berry–Esseen）：存在绝对常数 $C \leq 0.4748$，使得

$$\sup_x \left|P\!\left(\frac{X-np}{\sqrt{npq}} \leq x\right) - \Phi(x)\right| \leq \frac{C}{\sqrt{n}} \cdot \frac{p^2 + q^2}{\sqrt{pq}}$$

这给出了近似精度随 $n$ 增大而以 $O(n^{-1/2})$ 速率改善的严格保证，而非仅凭直觉的经验法则。

实验室代码（SymPy）

from sympy import symbols, binomial, Rational, N
from sympy.stats import Binomial, Normal, P, cdf

n_val, p_val = 200, Rational(4, 100)
X = Binomial('X', n_val, p_val)
Z = Normal('Z', 0, 1)

exact   = sum(P(X <= k) for k in [12])          # 精确值
approx  = float(cdf(Z)((12.5 - 8) / 2.77))     # 正态近似
print(f"精确: {N(exact, 6)},  近似: {approx:.6f}")

深入探索的邀请

正态近似打开了统计推断的大门：置信区间的构造、假设检验的 $p$ 值、质量控制中的控制图，无不以此为基石。若你对工业质量控制——如何用抽样数据判断一条生产线是否失控——感到好奇，不妨以本节的次品率例子为起点，深入探究 Shewhart 控制图背后的数学原理，你将发现正态近似在那里以最优雅的方式大显身手。
