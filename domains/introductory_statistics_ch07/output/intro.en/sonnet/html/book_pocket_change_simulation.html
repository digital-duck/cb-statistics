What the Simulation Achieves

Throughout this text, we have built a rigorous vocabulary for discrete probability: sample spaces, expectation, variance, the Law of Large Numbers, and the Central Limit Theorem. The pocket_change_simulation is not merely a charming application; it is the natural stress test of every concept introduced, assembled into a single executable model.

Formally, the simulation models the stochastic process $\{X_n\}_{n \geq 0}$, where each $X_n$ is a random variable representing the total value (in cents) of a pocket after $n$ independent transactions. Each transaction draws a denomination $d_k$ from a finite set $\mathcal{D} = \{1, 5, 10, 25, 50, 100\}$ with associated probability mass function $p : \mathcal{D} \to [0,1]$, $\sum_{d \in \mathcal{D}} p(d) = 1$. The accumulated value after $n$ steps is

$$S_n = \sum_{k=1}^{n} D_k, \qquad D_k \overset{\text{i.i.d.}}{\sim} p,$$

a classical compound discrete random walk.

Worked Example. Let $\mathcal{D} = \{1, 5, 10, 25\}$ with uniform probabilities $p(d) = \tfrac{1}{4}$. The expected value of a single draw is

$$\mathbb{E}[D] = \frac{1 + 5 + 10 + 25}{4} = 10.25 \text{ cents},$$

with variance

$$\text{Var}(D) = \mathbb{E}[D^2] - (\mathbb{E}[D])^2 = \frac{1 + 25 + 100 + 625}{4} - (10.25)^2 \approx 87.69 \text{ cents}^2.$$

After $n = 400$ draws, the CLT predicts $S_{400} \approx \mathcal{N}(4100,\, 35076)$, so roughly 95% of simulated totals lie within $\pm 2\sqrt{35076} \approx \pm 374$ cents of the mean. Running the simulation empirically confirms this interval, closing the loop between theory and experiment.

Key Theorem (Convergence in Distribution). Under the conditions above, the standardized partial sum

$$Z_n = \frac{S_n - n\,\mathbb{E}[D]}{\sqrt{n\,\text{Var}(D)}} \xrightarrow{d} \mathcal{N}(0,1) \quad \text{as } n \to \infty.$$

This is an immediate consequence of the Lindeberg–Lévy CLT, since $\{D_k\}$ are i.i.d. with finite second moment.

Lab Cell

import sympy as sp
from sympy.stats import DiscreteUniform, E, variance, sample

D = DiscreteUniform('D', [1, 5, 10, 25])
mu  = E(D)          # exact expected value
sig2 = variance(D)  # exact variance
print(f"E[D] = {mu},  Var(D) = {sig2}")

# Monte Carlo confirmation
import random
trials = 10_000
n      = 400
means  = [sum(random.choice([1,5,10,25]) for _ in range(n)) for _ in range(trials)]
import statistics
print(f"Simulated mean ≈ {statistics.mean(means):.1f}  (theory: {float(mu)*n:.1f})")
print(f"Simulated std  ≈ {statistics.stdev(means):.1f}  (theory: {float(sig2*n)**0.5:.1f})")

Invitation

The pocket-change model is structurally identical to problems that appear across quantitative fields: a quantum system hopping between energy levels, an insurance portfolio accumulating small claims, a language model sampling tokens. Each substitutes a different $\mathcal{D}$ and $p$, but the mathematics — expectation, variance, convergence — remains unchanged. Choose one of these domains and derive its analogue of the CLT bound above; you will find that every proof step mirrors what you have just done here, and that the simulation code requires only a single line to change.
