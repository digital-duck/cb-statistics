Concept Book: Cookie Recipes Simulation

Payoff

A cookie-recipes simulation is a discrete, parameterized generative model in which each recipe $r$ is a vector $\mathbf{x}_r \in \mathbb{R}^n$ of ingredient quantities, and a simulation run samples a batch process $\mathcal{B}: \mathbb{R}^n \times \Omega \to \mathcal{Y}$ that maps the recipe vector and a random seed $\omega \in \Omega$ to an observable outcome $y \in \mathcal{Y}$ (texture, rise, browning index, or any measurable quality metric). Formally, the simulation constitutes a stochastic program:

$$ \hat{y} = \mathcal{B}(\mathbf{x}_r, \omega), \qquad \omega \sim P_\Omega, $$

where $P_\Omega$ encodes physical uncertainty — oven temperature variance, humidity, ingredient heterogeneity — and the expected outcome $\mathbb{E}_\omega[\hat{y}]$ is the object of systematic study.

Worked example. Suppose a recipe has two free parameters: flour mass $x_1 \in [200, 300]\,\text{g}$ and butter mass $x_2 \in [80, 160]\,\text{g}$. A texture score $T$ is modelled as

$$ T(x_1, x_2, \omega) = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_{12} x_1 x_2 + \varepsilon(\omega), $$

with $\varepsilon \sim \mathcal{N}(0, \sigma^2)$. Running $N = 10{,}000$ Monte Carlo trials at a grid of design points and computing $\hat{\mu}_{ij} = N^{-1}\sum_k T(x_1^{(i)}, x_2^{(j)}, \omega_k)$ yields a response surface from which the optimal recipe is read off as $\mathbf{x}^* = \arg\max \hat{\mu}$.

Key theorem (Law of Large Numbers for simulation estimators). If $\hat{y}_1, \hat{y}_2, \ldots$ are i.i.d. draws from $\mathcal{B}(\mathbf{x}, \cdot)$ with finite variance $\sigma^2 < \infty$, then the Monte Carlo estimator $\bar{y}_N = N^{-1}\sum_{k=1}^N \hat{y}_k$ satisfies

$$ \bar{y}_N \xrightarrow{a.s.} \mathbb{E}[\hat{y}] \quad \text{as } N \to \infty, $$

with mean-squared error $\mathrm{MSE}(\bar{y}_N) = \sigma^2 / N$, confirming that precision scales as $\mathcal{O}(N^{-1/2})$ regardless of the dimension of $\mathbf{x}$.

# Lab cell — run in SymPy / NumPy
import numpy as np
from sympy import symbols, lambdify, expand

x1, x2 = symbols('x1 x2')
T_expr = 0.5 + 0.003*x1 + 0.004*x2 - 0.00001*x1*x2
T_func = lambdify((x1, x2), T_expr, 'numpy')

rng = np.random.default_rng(42)
X1 = rng.uniform(200, 300, 10_000)
X2 = rng.uniform(80,  160, 10_000)
scores = T_func(X1, X2) + rng.normal(0, 0.05, 10_000)
best = np.argmax(scores)
print(f"Best trial: x1={X1[best]:.1f} g, x2={X2[best]:.1f} g, T={scores[best]:.3f}")

This capstone is the natural endpoint of the book because every tool introduced earlier — algebraic modelling, probability spaces, numerical optimisation, and symbolic computation — converges here into a single executable workflow. The simulation is not an end in itself; it is a laboratory in software, reproducible and interrogable in ways that a physical kitchen never can be.
