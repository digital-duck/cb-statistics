Independence Lab

Definition. Two events $A$ and $B$ defined on a probability space $(\Omega, \mathcal{F}, P)$ are statistically independent if and only if

$$P(A \cap B) = P(A) \cdot P(B).$$

Equivalently, knowing that $B$ occurred does not alter the probability of $A$: $P(A \mid B) = P(A)$ whenever $P(B) > 0$. This multiplicative criterion extends naturally to a finite collection $\{A_1, A_2, \ldots, A_n\}$, which is called mutually independent when the product rule holds for every sub-collection, not merely pairwise.

Worked Example. Roll a fair six-sided die once. Define $A = \{\text{outcome is even}\}$ and $B = \{\text{outcome is at most 4}\}$. Then

$$P(A) = \tfrac{3}{6} = \tfrac{1}{2}, \quad P(B) = \tfrac{4}{6} = \tfrac{2}{3}, \quad A \cap B = \{2, 4\} \Rightarrow P(A \cap B) = \tfrac{2}{6} = \tfrac{1}{3}.$$

Since $P(A) \cdot P(B) = \tfrac{1}{2} \cdot \tfrac{2}{3} = \tfrac{1}{3} = P(A \cap B)$, the events are independent. Contrast this with $C = \{\text{outcome is at least 5}\}$: $P(A \cap C) = P(\{6\}) = \tfrac{1}{6}$, while $P(A) \cdot P(C) = \tfrac{1}{2} \cdot \tfrac{1}{3} = \tfrac{1}{6}$. Independence holds again — a reminder that independence is an algebraic property, not an intuitive one.

Key Theorem (Independence and Complements). If $A$ and $B$ are independent, then so are the pairs $(A, B^c)$, $(A^c, B)$, and $(A^c, B^c)$.

Proof sketch. Because $A = (A \cap B) \cup (A \cap B^c)$ is a disjoint union,

$$P(A \cap B^c) = P(A) - P(A \cap B) = P(A) - P(A)P(B) = P(A)(1 - P(B)) = P(A)P(B^c).$$

The remaining cases follow by symmetry and a second application of the same argument to $A^c$.

Lab Cell.

from sympy import Rational, symbols, simplify

# Represent probabilities as exact fractions
PA  = Rational(1, 2)   # P(A): even face
PB  = Rational(2, 3)   # P(B): face ≤ 4
PAB = Rational(1, 3)   # P(A ∩ B): even and ≤ 4

independent = simplify(PA * PB - PAB) == 0
print("Independent?", independent)          # True

# Complement check: P(A ∩ B^c)
PBc  = 1 - PB
PABc = PA - PAB
print("P(A)·P(B^c) == P(A∩B^c)?", simplify(PA * PBc - PABc) == 0)  # True

Running this cell confirms both independence and the complement theorem using exact rational arithmetic, eliminating floating-point ambiguity.
