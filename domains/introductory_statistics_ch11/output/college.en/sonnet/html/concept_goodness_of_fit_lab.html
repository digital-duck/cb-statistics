Goodness Of Fit Lab

Definition. A goodness-of-fit test is a statistical procedure that assesses whether observed data are consistent with a hypothesized probability distribution. Given a discrete random variable taking values in $\{v_1, v_2, \ldots, v_k\}$, let $O_i$ denote the observed frequency of outcome $v_i$ in a sample of size $n$, and let $E_i = n p_i$ denote the expected frequency under the null hypothesis $H_0: P(X = v_i) = p_i$. The Pearson chi-squared statistic is

$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}.$$

Under $H_0$, this statistic converges in distribution to $\chi^2(k-1)$ as $n \to \infty$, provided $E_i \geq 5$ for all $i$. We reject $H_0$ at significance level $\alpha$ when $\chi^2 > \chi^2_{\alpha,\, k-1}$, the upper-$\alpha$ critical value of the chi-squared distribution with $k-1$ degrees of freedom.

Worked Example. A fair six-sided die is rolled 120 times. Under $H_0$ (fair die), each face has probability $\frac{1}{6}$, giving $E_i = 20$ for $i = 1, \ldots, 6$. Suppose the observed counts are $\{25, 17, 15, 23, 19, 21\}$. Then

$$\chi^2 = \frac{(25-20)^2}{20} + \frac{(17-20)^2}{20} + \frac{(15-20)^2}{20} + \frac{(23-20)^2}{20} + \frac{(19-20)^2}{20} + \frac{(21-20)^2}{20} = \frac{25+9+25+9+1+1}{20} = 3.50.$$

At $\alpha = 0.05$ with $k - 1 = 5$ degrees of freedom, the critical value is $\chi^2_{0.05,5} \approx 11.07$. Since $3.50 < 11.07$, we fail to reject $H_0$; the data are consistent with a fair die.

Key Theorem (Pearson, 1900). If $O_1, \ldots, O_k$ are multinomial with parameters $n$ and $p_1, \ldots, p_k$, then

$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - n p_i)^2}{n p_i} \xrightarrow{d} \chi^2(k-1) \quad \text{as } n \to \infty.$$

The reduction from $k$ to $k-1$ degrees of freedom reflects the single linear constraint $\sum_i p_i = 1$.

Lab Cell.

from scipy.stats import chisquare
import sympy as sp

observed = [25, 17, 15, 23, 19, 21]
stat, p_value = chisquare(observed)          # uniform expected by default
print(f"chi2 = {stat:.4f},  p = {p_value:.4f}")

# Symbolic verification
O = sp.Matrix(observed)
E = sp.Rational(120, 6)
chi2_sym = sum((o - E)**2 / E for o in O)
sp.pprint(sp.simplify(chi2_sym))             # should yield 7/2

Running this cell confirms $\chi^2 = 3.5$ and returns $p \approx 0.623$, well above $0.05$, corroborating the manual calculation.
