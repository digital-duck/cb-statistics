Standard Normal Variable

Definition. A standard normal variable is a continuous random variable $Z$ whose probability density function is

$$f(z) = \frac{1}{\sqrt{2\pi}}\,e^{-z^2/2}, \qquad z \in \mathbb{R}.$$

We write $Z \sim \mathcal{N}(0,1)$, indicating mean $\mu = 0$ and variance $\sigma^2 = 1$. The corresponding cumulative distribution function is

$$\Phi(z) = \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}}\,e^{-t^2/2}\,dt,$$

which has no closed form in elementary functions but is tabulated and available in every numerical library. The density $f$ is symmetric about zero, bell-shaped, and decays super-exponentially in the tails.

Worked Example. Suppose $Z \sim \mathcal{N}(0,1)$. Find $P(-1 \le Z \le 2)$.

Using the CDF,

$$P(-1 \le Z \le 2) = \Phi(2) - \Phi(-1).$$

By symmetry, $\Phi(-1) = 1 - \Phi(1)$. From standard tables, $\Phi(2) \approx 0.9772$ and $\Phi(1) \approx 0.8413$, so $\Phi(-1) \approx 0.1587$. Therefore

$$P(-1 \le Z \le 2) \approx 0.9772 - 0.1587 = 0.8185.$$

Roughly $82\%$ of the probability mass lies in the interval $[-1, 2]$.

Key Theorem (Standardisation). If $X \sim \mathcal{N}(\mu, \sigma^2)$ with $\sigma > 0$, then

$$Z = \frac{X - \mu}{\sigma} \sim \mathcal{N}(0,1).$$

Proof sketch. Let $F_X$ be the CDF of $X$. For any $z$,

$$P(Z \le z) = P\!\left(X \le \mu + \sigma z\right) = F_X(\mu + \sigma z).$$

Differentiating with respect to $z$ via the chain rule yields the density $f(z) = \frac{1}{\sqrt{2\pi}}e^{-z^2/2}$. $\square$

This theorem reduces every normal probability calculation to a single universal table or function call.

Lab Cell.

from sympy import symbols, exp, pi, sqrt, integrate, oo, erf, simplify

z = symbols('z', real=True)
f = exp(-z**2 / 2) / sqrt(2 * pi)

# Verify the density integrates to 1
total_mass = integrate(f, (z, -oo, oo))
print("Total mass:", simplify(total_mass))   # 1

# CDF expressed via the error function
from sympy import erfc
Phi = integrate(f, (z, -oo, z))
print("Phi(z) =", Phi)                       # (1 + erf(z/sqrt(2))) / 2

Running this cell confirms that $f$ is a valid density and expresses $\Phi$ in terms of the error function $\operatorname{erf}$, which satisfies $\Phi(z) = \tfrac{1}{2}\!\left[1 + \operatorname{erf}\!\left(\tfrac{z}{\sqrt{2}}\right)\right]$.
