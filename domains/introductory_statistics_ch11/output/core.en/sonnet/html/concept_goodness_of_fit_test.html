Goodness Of Fit Test

Definition. A goodness-of-fit test is a statistical hypothesis test that assesses whether observed categorical data are consistent with a hypothesized probability distribution. Given $k$ categories with observed counts $O_1, O_2, \ldots, O_k$ and a null hypothesis specifying probabilities $p_1, p_2, \ldots, p_k$ (with $\sum_{i=1}^k p_i = 1$), the expected count in category $i$ for a sample of size $n$ is $E_i = n p_i$. The Pearson test statistic is

$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}.$$

Under $H_0$, this statistic follows approximately a chi-squared distribution with $\nu = k - 1$ degrees of freedom, provided $E_i \geq 5$ for all $i$.

Worked Example. A six-sided die is rolled 120 times. Under $H_0$ (fair die), each face has probability $\tfrac{1}{6}$, so $E_i = 20$ for all $i$. Suppose the observed counts are $\{25, 17, 22, 18, 24, 14\}$. Then

$$\chi^2 = \frac{(25-20)^2}{20} + \frac{(17-20)^2}{20} + \frac{(22-20)^2}{20} + \frac{(18-20)^2}{20} + \frac{(24-20)^2}{20} + \frac{(14-20)^2}{20}$$ $$= \frac{25 + 9 + 4 + 4 + 16 + 36}{20} = \frac{94}{20} = 4.70.$$

With $\nu = 5$ degrees of freedom and $\alpha = 0.05$, the critical value is $\chi^2_{0.05,5} \approx 11.07$. Since $4.70 < 11.07$, we fail to reject $H_0$: the data are consistent with a fair die.

Key Theorem (Pearson, 1900). Let $O_1, \ldots, O_k$ be multinomial counts with parameters $n$ and $p_1, \ldots, p_k$. As $n \to \infty$, the statistic $\chi^2 = \sum_{i=1}^k (O_i - E_i)^2 / E_i$ converges in distribution to $\chi^2_{k-1}$. If $m$ parameters are estimated from the data, the degrees of freedom reduce to $k - 1 - m$.

Lab Cell.

from scipy.stats import chisquare

observed = [25, 17, 22, 18, 24, 14]
stat, p_value = chisquare(f_obs=observed)   # uniform H0 by default
print(f"chi2 = {stat:.4f},  p = {p_value:.4f}")

Running this cell confirms $\chi^2 = 4.70$ and $p \approx 0.454$. The single new primitive here is chisquare, which accepts the observed counts and, when no expected frequencies are specified, assumes the uniform distribution. The returned $p$-value is the probability of observing a statistic at least as large as $4.70$ under $H_0$; because $0.454 \gg 0.05$, we retain the null hypothesis and conclude that the die shows no significant departure from fairness.
