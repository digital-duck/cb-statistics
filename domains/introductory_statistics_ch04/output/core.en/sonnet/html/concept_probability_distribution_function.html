Probability Distribution Function

Definition. Let $X$ be a real-valued random variable defined on a probability space $(\Omega, \mathcal{F}, P)$. The probability distribution function (PDF) of $X$, also called the probability density function when $X$ is continuous, is a non-negative measurable function $f_X : \mathbb{R} \to [0, \infty)$ satisfying

$$P(a \leq X \leq b) = \int_a^b f_X(x)\, dx, \qquad \text{for all } a \leq b \in \mathbb{R},$$

with the normalization condition

$$\int_{-\infty}^{\infty} f_X(x)\, dx = 1.$$

The PDF describes how probability mass is spread over the real line; $f_X(x)$ itself is not a probability but a density—probability is recovered only by integration over an interval.

Worked Example. Consider the exponential distribution with rate parameter $\lambda > 0$, defined by

$$f_X(x) = \begin{cases} \lambda e^{-\lambda x} & x \geq 0, \\ 0 & x < 0. \end{cases}$$

Verify normalization: $\int_0^{\infty} \lambda e^{-\lambda x}\, dx = \left[-e^{-\lambda x}\right]_0^{\infty} = 0 - (-1) = 1.$ To find the probability that $X$ falls in $[1, 3]$ with $\lambda = 0.5$:

$$P(1 \leq X \leq 3) = \int_1^3 0.5\, e^{-0.5x}\, dx = \left[-e^{-0.5x}\right]_1^3 = e^{-0.5} - e^{-1.5} \approx 0.3834.$$

Key Theorem (Non-negativity and Normalization are Sufficient). A function $f : \mathbb{R} \to \mathbb{R}$ is the PDF of some random variable if and only if $f(x) \geq 0$ for all $x$ and $\int_{-\infty}^{\infty} f(x)\, dx = 1$. This characterization allows one to construct valid distributions by specifying any non-negative integrable function and rescaling by its total integral.

Lab Cell.

from sympy import symbols, exp, integrate, oo, Float

x, lam = symbols('x lambda', positive=True)

f = lam * exp(-lam * x)

# Verify normalization
norm = integrate(f, (x, 0, oo))
print("Normalization:", norm)          # Expected: 1

# P(1 <= X <= 3) with lambda = 0.5
prob = integrate(f.subs(lam, Float('0.5')), (x, 1, 3))
print("P(1 ≤ X ≤ 3):", float(prob))   # Expected: ≈ 0.3834
