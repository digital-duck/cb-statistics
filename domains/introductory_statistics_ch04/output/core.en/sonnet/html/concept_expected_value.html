Expected Value

Definition. Let $X$ be a discrete random variable taking values $x_1, x_2, \ldots, x_n$ with corresponding probabilities $p_1, p_2, \ldots, p_n$, where $\sum_{i=1}^n p_i = 1$. The expected value (or expectation) of $X$ is defined as

$$E[X] = \sum_{i=1}^{n} x_i \, p_i.$$

For a continuous random variable with probability density function $f(x)$, the definition extends to

$$E[X] = \int_{-\infty}^{\infty} x \, f(x) \, dx,$$

provided this integral converges absolutely. Intuitively, $E[X]$ is a probability-weighted average: outcomes that occur more frequently exert greater influence on the result. Note that $E[X]$ need not itself be a value that $X$ can attain.

Worked Example. A fair six-sided die produces each face $\{1, 2, 3, 4, 5, 6\}$ with probability $\tfrac{1}{6}$. The expected value of a single roll is

$$E[X] = \frac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = \frac{21}{6} = 3.5.$$

Although 3.5 is never an observable outcome, it is the long-run average score per roll. If you rolled the die 600 times, the total score would be close to $600 \times 3.5 = 2100$; this is the predictive power of the expectation.

Theorem (Linearity of Expectation). For any random variables $X$ and $Y$ defined on the same probability space and any constants $a, b \in \mathbb{R}$,

$$E[aX + bY] = a\,E[X] + b\,E[Y].$$

Proof sketch. Substituting the definition and rearranging the finite sum (or integral) shows that the weighted-average operation distributes over addition and pulls constants outside the sum. Crucially, linearity holds even when $X$ and $Y$ are dependent, making it one of the most broadly applicable tools in probability theory.

Lab Cell.

from sympy import symbols, Rational, summation

i = symbols('i')
# Expected value of a fair six-sided die
E_die = summation(i * Rational(1, 6), (i, 1, 6))
print("E[X] =", E_die)   # 7/2

# Linearity check: E[2X + 3] where X ~ die
E_linear = 2 * E_die + 3
print("E[2X + 3] =", E_linear)  # 10

Running this cell confirms $E[X] = \tfrac{7}{2}$ and demonstrates linearity: $E[2X + 3] = 2 \cdot \tfrac{7}{2} + 3 = 10$.
