Discrete Random Variable

Definition. A discrete random variable is a function $X : \Omega \to \mathbb{R}$ defined on a probability space $(\Omega, \mathcal{F}, P)$ whose range is a finite or countably infinite subset of $\mathbb{R}$. For each value $x$ in the range of $X$, the probability mass function (PMF) is

$$p_X(x) = P(\{\omega \in \Omega : X(\omega) = x\}) = P(X = x).$$

A valid PMF satisfies two conditions: $p_X(x) \geq 0$ for all $x$, and $\sum_{x} p_X(x) = 1$, where the sum runs over all values in the range of $X$. The expected value (mean) and variance are defined as

$$\mu = E[X] = \sum_{x} x\, p_X(x), \qquad \sigma^2 = \operatorname{Var}(X) = E[(X - \mu)^2] = \sum_{x} (x - \mu)^2\, p_X(x).$$

Worked Example. A fair six-sided die is rolled once. Define $X$ as the number shown. The sample space is $\Omega = \{1, 2, 3, 4, 5, 6\}$, and $p_X(k) = \tfrac{1}{6}$ for $k = 1, \ldots, 6$.

The expected value is $E[X] = \frac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = \frac{21}{6} = 3.5$.

The variance is $\operatorname{Var}(X) = \frac{1}{6}\sum_{k=1}^{6}(k - 3.5)^2 = \frac{1}{6}(6.25 + 2.25 + 0.25 + 0.25 + 2.25 + 6.25) = \frac{17.5}{6} \approx 2.917$.

Key Theorem (Law of the Unconscious Statistician). If $g : \mathbb{R} \to \mathbb{R}$ is any function, then

$$E[g(X)] = \sum_{x} g(x)\, p_X(x),$$

provided the sum converges absolutely. This eliminates the need to derive the distribution of $g(X)$ before computing its expectation—a significant computational simplification.

Lab Cell (SymPy).

from sympy import Rational, symbols, summation, S
from sympy.stats import Die, E, variance

X = Die('X', 6)                      # fair six-sided die
mu  = E(X)                           # expected value
var = variance(X)                    # variance
print(f"E[X] = {mu}, Var(X) = {var}")
# E[X] = 7/2, Var(X) = 35/12

Running this cell confirms the analytic results above and illustrates how SymPy's stats module represents discrete random variables symbolically, enabling exact rational arithmetic rather than floating-point approximation.
