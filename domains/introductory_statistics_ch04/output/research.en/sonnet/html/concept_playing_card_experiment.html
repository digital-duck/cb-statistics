Playing Card Experiment

Definition. A playing card experiment is a probability space $(\Omega, \mathcal{F}, P)$ in which the sample space $\Omega$ consists of the 52 cards of a standard deck. Each card is uniquely identified by a suit $s \in \{\clubsuit, \diamondsuit, \heartsuit, \spadesuit\}$ and a rank $r \in \{A, 2, 3, \ldots, 10, J, Q, K\}$, giving $|\Omega| = 4 \times 13 = 52$. Under the uniform (or equiprobable) assumption, every elementary event $\{\omega\}$ is assigned probability

$$P(\{\omega\}) = \frac{1}{52}.$$

For any event $E \subseteq \Omega$, the classical probability formula yields

$$P(E) = \frac{|E|}{52}.$$

Worked Example. Suppose a single card is drawn at random. Let $E$ be the event "the card is a face card" (Jack, Queen, or King). Each suit contributes exactly 3 face cards, so $|E| = 4 \times 3 = 12$. Therefore

$$P(E) = \frac{12}{52} = \frac{3}{13} \approx 0.2308.$$

Now let $F$ be the event "the card is a heart." Then $|F| = 13$ and $|E \cap F| = 3$ (the Jack, Queen, and King of hearts). By the inclusion–exclusion principle,

$$P(E \cup F) = P(E) + P(F) - P(E \cap F) = \frac{12}{52} + \frac{13}{52} - \frac{3}{52} = \frac{22}{52} = \frac{11}{26}.$$

Key Theorem (Conditional Probability). If $P(F) > 0$, the conditional probability of $E$ given $F$ is

$$P(E \mid F) = \frac{P(E \cap F)}{P(F)}.$$

In the example above, $P(E \mid F) = \dfrac{3/52}{13/52} = \dfrac{3}{13}$, which equals $P(E)$. This demonstrates that $E$ and $F$ are independent events: knowledge that the drawn card is a heart provides no information about whether it is a face card.

Lab Cell (SymPy).

from sympy import Rational, symbols

total = 52
face_cards = 12      # J, Q, K across 4 suits
hearts     = 13
face_hearts = 3      # J♥, Q♥, K♥

P_E   = Rational(face_cards, total)
P_F   = Rational(hearts, total)
P_EF  = Rational(face_hearts, total)

print("P(E)       =", P_E)           # 3/13
print("P(F)       =", P_F)           # 1/4
print("P(E∪F)     =", P_E + P_F - P_EF)  # 11/26
print("P(E|F)     =", P_EF / P_F)   # 3/13  (== P(E): independent)
print("Independent?", P_EF == P_E * P_F)  # True

Running this cell confirms both the numerical results and the independence criterion $P(E \cap F) = P(E)\,P(F)$, a pattern that recurs throughout discrete probability theory.
