大数定律

定义

设 $X_1, X_2, \ldots, X_n$ 为一列独立同分布（i.i.d.）的随机变量，具有有限期望值 $\mu = \mathbb{E}[X_i]$ 及有限方差 $\sigma^2 = \mathrm{Var}(X_i) < \infty$。定义样本均值为

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i.$$

弱大数定律（Weak Law of Large Numbers）断言：对任意 $\varepsilon > 0$，

$$\lim_{n \to \infty} P\!\left(|\bar{X}_n - \mu| > \varepsilon\right) = 0.$$

即样本均值依概率收敛于总体期望 $\mu$。强大数定律进一步保证几乎处处收敛：$P\!\left(\lim_{n\to\infty}\bar{X}_n = \mu\right) = 1$。

具体例子

掷一枚均匀硬币，正面记为 $X_i = 1$，反面记为 $X_i = 0$，则 $\mu = 1/2$。设 $n = 1000$，样本均值 $\bar{X}_{1000}$ 的期望仍为 $1/2$，标准差为

$$\mathrm{SD}(\bar{X}_n) = \frac{\sigma}{\sqrt{n}} = \frac{1/2}{\sqrt{1000}} \approx 0.0158.$$

由此可见，当 $n$ 增大时，$\bar{X}_n$ 的波动范围迅速收窄，集中于 $\mu = 0.5$ 附近。

关键定理（弱大数定律的证明思路）

利用切比雪夫不等式：对任意随机变量 $Y$ 及 $\varepsilon > 0$，

$$P(|Y - \mathbb{E}[Y]| > \varepsilon) \leq \frac{\mathrm{Var}(Y)}{\varepsilon^2}.$$

将 $Y = \bar{X}_n$ 代入，注意到 $\mathbb{E}[\bar{X}_n] = \mu$ 且 $\mathrm{Var}(\bar{X}_n) = \sigma^2/n$，得

$$P(|\bar{X}_n - \mu| > \varepsilon) \leq \frac{\sigma^2}{n\varepsilon^2} \xrightarrow{n\to\infty} 0.$$

故弱大数定律成立。$\blacksquare$

实验单元（SymPy / Python）

import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
n_max = 2000
flips = rng.integers(0, 2, size=n_max)          # 0 或 1
running_mean = np.cumsum(flips) / np.arange(1, n_max + 1)

plt.plot(running_mean, label=r"$\bar{X}_n$")
plt.axhline(0.5, color="red", linestyle="--", label=r"$\mu = 0.5$")
plt.xlabel("$n$"); plt.ylabel("样本均值")
plt.title("大数定律：样本均值收敛于总体期望")
plt.legend(); plt.tight_layout(); plt.show()

运行上述代码，可直观观察到随着 $n$ 增大，样本均值曲线逐渐稳定并趋近于红色虚线 $\mu = 0.5$，从而验证大数定律的结论。
