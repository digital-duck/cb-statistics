Probability Distribution Function

定义。 设 $X$ 为定义在样本空间 $\Omega$ 上的随机变量。$X$ 的概率分布函数（Probability Distribution Function，简称 PDF，亦称概率密度函数）是一个可测函数 $f_X : \mathbb{R} \to [0, +\infty)$，满足以下两个条件：

$$ f_X(x) \geq 0, \quad \forall x \in \mathbb{R}, $$ $$ \int_{-\infty}^{+\infty} f_X(x)\, dx = 1. $$

对于任意区间 $[a, b] \subseteq \mathbb{R}$，随机变量 $X$ 落在该区间内的概率由积分给出：

$$ P(a \leq X \leq b) = \int_a^b f_X(x)\, dx. $$

需要特别注意，$f_X(x)$ 本身并非概率值，而是概率在该点处的密度；单个点的概率恒为零，即 $P(X = x_0) = 0$。

例题。 设随机变量 $X$ 服从正态分布 $\mathcal{N}(\mu, \sigma^2)$，其概率密度函数为：

$$ f_X(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right). $$

取 $\mu = 0,\ \sigma = 1$（标准正态分布），计算 $P(-1 \leq X \leq 1)$：

$$ P(-1 \leq X \leq 1) = \int_{-1}^{1} \frac{1}{\sqrt{2\pi}} e^{-x^2/2}\, dx \approx 0.6827. $$

这一结果即统计学中著名的"68–95–99.7 法则"的第一项：约 68.27\% 的观测值落在均值一个标准差的范围内。

关键定理（非负性与归一化的等价性）。 若函数 $g : \mathbb{R} \to [0,+\infty)$ 满足 $\int_{-\infty}^{+\infty} g(x)\, dx = c \in (0, +\infty)$，则 $f_X(x) = g(x)/c$ 是合法的概率密度函数。证明思路：令 $f_X = g/c$，则 $f_X \geq 0$ 显然成立，且 $\int f_X\, dx = (1/c)\int g\, dx = 1$，两个条件均满足。

实验单元（SymPy）。

from sympy import *

x, mu, sigma = symbols('x mu sigma', real=True)
sigma_pos = symbols('sigma', positive=True)

f = 1 / (sigma_pos * sqrt(2*pi)) * exp(-(x - mu)**2 / (2 * sigma_pos**2))

# 验证归一化条件
norm = integrate(f.subs([(mu, 0), (sigma_pos, 1)]), (x, -oo, oo))
print("归一化验证：", simplify(norm))  # 输出 1

# 计算 P(-1 ≤ X ≤ 1)
prob = integrate(f.subs([(mu, 0), (sigma_pos, 1)]), (x, -1, 1))
print("P(-1 ≤ X ≤ 1) =", float(prob.evalf()))
