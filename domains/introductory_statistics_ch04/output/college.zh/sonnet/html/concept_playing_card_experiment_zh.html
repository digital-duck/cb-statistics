Playing Card Experiment

定义。 扑克牌实验是概率论中最经典的有限样本空间模型之一。一副标准扑克牌由 $52$ 张牌组成，分为四种花色（黑桃、红心、方块、梅花），每种花色各含 $13$ 个面值（$2, 3, \ldots, 10, J, Q, K, A$）。从这副牌中随机抽取一张或若干张牌所构成的随机过程，称为扑克牌实验（Playing Card Experiment）。其样本空间为

$$\Omega = \{\omega \mid \omega \text{ 为牌组中的一张牌}\}, \quad |\Omega| = 52.$$

在等可能性假设下，每张牌被抽到的概率为 $P(\{\omega\}) = \dfrac{1}{52}$。

定义事件。 设 $A$ 为"抽到红心"，则 $A$ 包含 $13$ 个基本结果，故

$$P(A) = \frac{|A|}{|\Omega|} = \frac{13}{52} = \frac{1}{4}.$$

设 $B$ 为"抽到人头牌"（$J, Q, K$），则 $|B| = 12$，$P(B) = \dfrac{12}{52} = \dfrac{3}{13}$。

例题。 从一副完整的 $52$ 张牌中不放回地连续抽取两张牌。求：两张牌均为 $A$（Ace）的概率。

解： 第一张为 $A$ 的概率为 $\dfrac{4}{52}$。在第一张已为 $A$ 的条件下，剩余 $51$ 张牌中有 $3$ 张 $A$，故第二张为 $A$ 的条件概率为 $\dfrac{3}{51}$。由乘法规则：

$$P(\text{两张均为 } A) = \frac{4}{52} \cdot \frac{3}{51} = \frac{12}{2652} = \frac{1}{221} \approx 0.00452.$$

关键定理（古典概型）。 设样本空间 $\Omega$ 为有限集且各基本事件等可能，则对任意事件 $A \subseteq \Omega$，

$$P(A) = \frac{|A|}{|\Omega|}.$$

该公式在扑克牌实验中成立，其前提是每次抽取满足随机性，即每张牌被选中的机会完全相等。

实验室代码（SymPy）。

from sympy import Rational, binomial

# 不放回抽取两张 Ace 的概率
p = Rational(4, 52) * Rational(3, 51)
print("P(两张均为 Ace) =", p)  # 输出 1/221

# 用组合数验证
p2 = binomial(4, 2) / binomial(52, 2)
print("组合数方法 =", p2)       # 输出 1/221

两种方法均给出 $P = \dfrac{1}{221}$，验证了古典概型公式的一致性。扑克牌实验是理解条件概率与组合计数相互联系的理想起点。
