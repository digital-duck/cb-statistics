概念的归宿

经过前几章对样本空间、事件代数、概率公理以及随机变量分布的系统建构，掷骰子实验（dice\_experiment）作为本教材的核心范例，并非偶然的选择，而是一切基础概念汇聚的自然终点。它提供了一个有限、均匀、可精确枚举的概率空间，使抽象定义得以在具体数字上完整展开，从而构成严格推理与直观感知之间的完美桥梁。

设掷一枚标准六面骰子，样本空间为 $\Omega = \{1, 2, 3, 4, 5, 6\}$，每一结果的概率均为 $P(\{\omega\}) = \tfrac{1}{6}$。定义随机变量 $X: \Omega \to \mathbb{R}$，$X(\omega) = \omega$，则其期望值为

$$\mathbb{E}[X] = \sum_{k=1}^{6} k \cdot \frac{1}{6} = \frac{21}{6} = 3.5,$$

方差为

$$\mathrm{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = \frac{91}{6} - \frac{441}{36} = \frac{35}{12} \approx 2.917.$$

这两个量——期望与方差——不仅描述了单次投掷的统计性质，更是一切后续应用的起点。

关键定理（大数定律的离散实例）：设 $X_1, X_2, \ldots, X_n$ 为独立同分布的骰子随机变量，样本均值为 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$。则对任意 $\varepsilon > 0$，

$$P\!\left(|\bar{X}_n - 3.5| > \varepsilon\right) \leq \frac{\mathrm{Var}(X)}{n\varepsilon^2} = \frac{35}{12 n \varepsilon^2} \xrightarrow{n\to\infty} 0.$$

此不等式正是切比雪夫不等式的直接应用，揭示了随机性如何在重复中趋于规律。

实验室代码单元（SymPy）

from sympy import Rational, summation, symbols, simplify

k = symbols('k', integer=True)
E_X  = summation(k * Rational(1, 6), (k, 1, 6))
E_X2 = summation(k**2 * Rational(1, 6), (k, 1, 6))
Var_X = simplify(E_X2 - E_X**2)
print(f"期望 E[X] = {E_X},  方差 Var(X) = {Var_X}")

运行上述代码，即可在符号层面验证前述计算，感受从公理到数值的完整推导链条。
