离散随机变量

定义。 设 $(\Omega, \mathcal{F}, P)$ 为一个概率空间。若函数 $X: \Omega \to \mathbb{R}$ 的值域 $\text{Im}(X) = \{x_1, x_2, x_3, \ldots\}$ 为有限集或可数无限集，则称 $X$ 为离散随机变量。其概率质量函数（PMF）定义为

$$p_X(x_k) = P(X = x_k) = P\!\left(\{\omega \in \Omega : X(\omega) = x_k\}\right), \quad k = 1, 2, 3, \ldots$$

合法的 PMF 须满足两个条件：$p_X(x_k) \geq 0$ 对所有 $k$ 成立，且 $\displaystyle\sum_{k} p_X(x_k) = 1$。

例题。 掷一枚均匀六面骰子，令 $X$ 表示点数。则 $\text{Im}(X) = \{1,2,3,4,5,6\}$，且

$$p_X(k) = \frac{1}{6}, \quad k \in \{1,2,3,4,5,6\}.$$

求 $X$ 的期望值（均值）：

$$\mathbb{E}[X] = \sum_{k=1}^{6} k \cdot \frac{1}{6} = \frac{1+2+3+4+5+6}{6} = \frac{21}{6} = 3.5.$$

求方差：

$$\operatorname{Var}(X) = \mathbb{E}[X^2] - \left(\mathbb{E}[X]\right)^2 = \frac{1^2+2^2+\cdots+6^2}{6} - 3.5^2 = \frac{91}{6} - 12.25 = \frac{35}{12} \approx 2.917.$$

关键定理（期望的线性性）。 设 $X, Y$ 为同一概率空间上的离散随机变量，$a, b \in \mathbb{R}$，则

$$\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y].$$

证明思路： 由期望定义，$\mathbb{E}[aX+bY] = \sum_\omega (aX(\omega)+bY(\omega))\,P(\{\omega\})$，利用求和的分配律即得结论，无需 $X$ 与 $Y$ 独立。$\blacksquare$

实验单元（SymPy）。

from sympy import Rational, summation, symbols

k = symbols('k', integer=True)
pmf = Rational(1, 6)

E_X  = summation(k * pmf, (k, 1, 6))
E_X2 = summation(k**2 * pmf, (k, 1, 6))
Var_X = E_X2 - E_X**2

print(f"E[X]   = {E_X}")      # 7/2
print(f"Var(X) = {Var_X}")    # 35/12

运行以上代码，可验证 $\mathbb{E}[X] = \tfrac{7}{2}$，$\operatorname{Var}(X) = \tfrac{35}{12}$，与手算结果完全一致。离散随机变量的核心在于：一切统计量均由 PMF 完全决定，掌握 PMF 即掌握该变量的全部概率行为。
