Dice Experiment

定义

骰子实验（dice experiment）是概率论中最基本的随机实验之一。设一枚均匀的六面骰子，其样本空间为

$$\Omega = \{1, 2, 3, 4, 5, 6\},$$

每个基本事件 $\omega_i = \{i\}$ 的概率满足均匀分布条件：

$$P(\{\omega_i\}) = \frac{1}{6}, \quad i = 1, 2, \ldots, 6.$$

对于任意事件 $A \subseteq \Omega$，其概率由古典概型公式给出：

$$P(A) = \frac{|A|}{|\Omega|} = \frac{|A|}{6},$$

其中 $|A|$ 表示事件 $A$ 所含基本事件的个数。骰子实验是有限等可能样本空间的典范模型，为学习随机变量、期望与方差奠定基础。

例题

掷一枚均匀骰子，设事件 $A$ 为"点数为偶数"，事件 $B$ 为"点数大于 $4$"。

  • $A = \{2, 4, 6\}$，故 $P(A) = \dfrac{3}{6} = \dfrac{1}{2}$。
  • $B = \{5, 6\}$，故 $P(B) = \dfrac{2}{6} = \dfrac{1}{3}$。
  • $A \cap B = \{6\}$，故 $P(A \cap B) = \dfrac{1}{6}$。

    • 验证加法公式：

    $$P(A \cup B) = P(A) + P(B) - P(A \cap B) = \frac{1}{2} + \frac{1}{3} - \frac{1}{6} = \frac{2}{3}.$$

    关键定理

    定理（有限等可能概率空间的期望公式）：设离散随机变量 $X$ 在 $\Omega = \{1,2,3,4,5,6\}$ 上取值，且各值等概，则其期望为

    $$E[X] = \sum_{i=1}^{6} i \cdot \frac{1}{6} = \frac{1+2+3+4+5+6}{6} = \frac{21}{6} = 3.5,$$

    方差为

    $$\text{Var}(X) = E[X^2] - (E[X])^2 = \frac{91}{6} - \frac{441}{36} = \frac{35}{12} \approx 2.917.$$

    证明要点：利用 $E[X^2] = \sum_{i=1}^{6} i^2 \cdot \frac{1}{6} = \frac{1^2+2^2+\cdots+6^2}{6} = \frac{91}{6}$，代入方差定义即得。

    实验单元（SymPy）

    from sympy import Rational, summation, symbols

i = symbols('i', integer=True)
# 期望
E_X = summation(i * Rational(1, 6), (i, 1, 6))
# 二阶矩
E_X2 = summation(i**2 * Rational(1, 6), (i, 1, 6))
Var_X = E_X2 - E_X**2

print(f"E[X]     = {E_X}")      # 7/2
print(f"Var(X)   = {Var_X}")    # 35/12

    运行上述代码，SymPy 将以精确有理数形式输出 $E[X] = \dfrac{7}{2}$ 与 $\text{Var}(X) = \dfrac{35}{12}$，验证手算结果无误。
