Concept Book: Two Sample Test Classification

Introductory Statistics Ch10 · Generated by SPL

Payoff

The journey through this textbook has built, layer by layer, the machinery needed to answer one of the most fundamental questions in empirical science: are these two groups genuinely different, or does chance alone explain what we observe? The concept of two-sample test classification is the natural endpoint of that journey because it transforms a vague intuition about difference into a rigorous, reproducible decision procedure.

What it achieves. Given two independent samples $\mathbf{x} = (x_1, \ldots, x_m)$ and $\mathbf{y} = (y_1, \ldots, y_n)$ drawn from distributions $F$ and $G$ respectively, two-sample test classification selects—from a family of candidate tests $\mathcal{T} = \{T_1, T_2, \ldots\}$—the procedure $T^*$ that is optimal under the assumptions warranted by the data. Formally, the classifier maps observable data characteristics (sample sizes, estimated skewness, variance ratio, and distributional shape) to a test statistic and its null distribution:

$$\Phi: \bigl(m,\, n,\, \hat{\kappa},\, \hat{\sigma}_x^2 / \hat{\sigma}_y^2,\, \hat{F}\bigr) \;\longmapsto\; T^* \in \mathcal{T}.$$

The guarantee is that $T^*$ controls the Type I error rate at the nominal level $\alpha$ while maximising power against the relevant alternative $H_1: F \neq G$.

Worked example. Suppose $m = 30$, $n = 45$, the Levene test rejects equal variances ($p = 0.02$), and a Shapiro–Wilk test fails to reject normality for both groups ($p > 0.10$). The classifier routes to Welch's $t$-test rather than Student's pooled $t$-test, computing

$$t = \frac{\bar{x} - \bar{y}}{\sqrt{s_x^2/m + s_y^2/n}},$$

with Satterthwaite degrees of freedom $\nu \approx 58.3$. Had normality been rejected, the classifier would instead select the Mann–Whitney $U$ statistic, which ranks all $m + n$ observations jointly and is asymptotically distribution-free.

Key theorem (Neyman–Pearson optimality within class). For each leaf of the classification tree, the selected test is the uniformly most powerful unbiased (UMPU) test within the parametric family implied by the diagnostic checks. No other test at level $\alpha$ achieves strictly higher power against all alternatives in that family.

Lab cell.

from sympy.stats import Normal, sample_stochastic_process
import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
x = rng.normal(loc=5.0, scale=1.0, size=30)
y = rng.normal(loc=5.4, scale=1.6, size=45)

_, p_levene = stats.levene(x, y)
_, p_shapiro_x = stats.shapiro(x)
_, p_shapiro_y = stats.shapiro(y)

equal_var = p_levene > 0.05
normal = (p_shapiro_x > 0.05) and (p_shapiro_y > 0.05)

if normal:
    stat, p = stats.ttest_ind(x, y, equal_var=equal_var)
    test_name = "Student t" if equal_var else "Welch t"
else:
    stat, p = stats.mannwhitneyu(x, y, alternative='two-sided')
    test_name = "Mann–Whitney U"

print(f"Test selected: {test_name},  statistic = {stat:.4f},  p = {p:.4f}")

Connection to applications. The framework of two-sample test classification is the engine behind every domain studied in this book's companion applications chapter. In clinical trials, it decides whether a treatment arm differs from a control arm under realistic variance heterogeneity. In educational assessment, it determines whether two pedagogical interventions produce measurably different learning outcomes across classrooms of unequal size. In environmental monitoring, it identifies whether pollutant concentrations upstream and downstream of a discharge point belong to the same distribution—even when heavy-tailed contamination violates normality. In each case, the classifier absorbs the messiness of real data and returns a principled, auditable choice.

The invitation now is to take one of these domains and follow it all the way through: collect data, run the diagnostics, let the classifier speak, and interpret the result in the language of the field. The next chapter does exactly that for real-world two-group comparisons in educational equity research—the setting where getting the test wrong does not merely cost statistical power, but can misguide policy affecting thousands of students.
