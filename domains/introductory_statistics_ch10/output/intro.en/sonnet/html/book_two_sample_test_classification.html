What Two-Sample Test Classification Achieves

Throughout this text we have built, layer by layer, the machinery of statistical inference: probability distributions, sampling variability, the null hypothesis framework, and the geometry of test statistics. Two-sample test classification is the point at which all of these threads converge into a single, decision-theoretic act. Given two independent samples $X_1, \ldots, X_m \sim F$ and $Y_1, \ldots, Y_n \sim G$, we must choose among a structured family of tests — $z$-test, Welch's $t$-test, Mann–Whitney $U$-test, permutation test — and commit to one. That choice is not arbitrary: it is a classification problem in its own right, governed by the observable features of the data (sample sizes, estimated variances, distributional shape) and the inferential guarantees each test provides.

Formally, let $\mathcal{T} = \{T_1, T_2, \ldots, T_k\}$ be a catalogue of valid two-sample procedures. A classifier $\phi : \mathcal{D} \to \mathcal{T}$, mapping observed data summaries to a test, is optimal when it minimises expected Type I error inflation under the true but unknown $F$ and $G$. The practical value of this framing is substantial: it transforms test selection from a lookup table into a principled, automatable decision, one that can be audited, learned, and improved as new data arrive.

Connection to Real-World Two-Group Comparisons

Every domain in which two populations must be distinguished reduces, at the inferential core, to this classification problem.

Clinical trials. Does the treated cohort differ from the control? If patient counts are small and variance heterogeneity is suspected, $\phi$ selects Welch's $t$-test; with severely skewed biomarker distributions, it selects Mann–Whitney. The classifier encodes the regulatory requirement that the chosen test be pre-specified and justified.

A/B experimentation (technology). Web-scale experiments supply large $m$ and $n$, making the $z$-test asymptotically valid. Here $\phi$ fires rapidly on the grounds of sample size alone — a branch that dominates in practice and that illustrates how classifier logic compresses to a single feature when that feature is decisive.

Educational assessment. Comparing exam score distributions between two instructional cohorts often violates normality. $\phi$ then branches toward the permutation test, which respects the finite-population structure of a classroom and requires no parametric assumption.

Genomics and expression profiling. High-dimensional two-group comparisons (treatment vs. control across thousands of genes) demand that $\phi$ operate at scale, applying false-discovery-rate corrections after each individual test is selected — an extension of classification from a single decision to a vectorised one.

# Lab cell — classify and execute a two-sample test
import numpy as np
from scipy import stats

def classify_and_test(x, y, alpha=0.05):
    m, n = len(x), len(y)
    _, p_levene = stats.levene(x, y)
    _, p_normal_x = stats.shapiro(x)
    _, p_normal_y = stats.shapiro(y)
    both_normal = (p_normal_x > 0.05) and (p_normal_y > 0.05)
    equal_var    = p_levene > 0.05
    large_sample = (m >= 30) and (n >= 30)

    if large_sample or both_normal:
        test_name = "z-test" if large_sample else (
            "Student t" if equal_var else "Welch t"
        )
        stat, p = stats.ttest_ind(x, y, equal_var=equal_var)
    else:
        test_name = "Mann-Whitney U"
        stat, p = stats.mannwhitneyu(x, y, alternative="two-sided")

    return {"test": test_name, "statistic": stat, "p_value": p,
            "reject_H0": p < alpha}

rng = np.random.default_rng(42)
x = rng.normal(loc=5.0, scale=1.2, size=25)
y = rng.normal(loc=5.8, scale=1.5, size=30)
print(classify_and_test(x, y))
