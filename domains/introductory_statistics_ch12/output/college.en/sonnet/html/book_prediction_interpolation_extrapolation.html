Concept Book: Prediction Interpolation Extrapolation

Introductory Statistics Ch12 · Generated by SPL

Payoff

What the concept achieves. Throughout this text, we have built the machinery of function approximation piece by piece: polynomial bases, least-squares fitting, error bounds, and the distinction between estimating values inside a known data range versus projecting beyond it. The concept of prediction, interpolation, and extrapolation is the synthesis that ties every strand together. It answers the practical question that motivates all of applied mathematics: given a finite set of observations $\{(x_i, y_i)\}_{i=0}^{n}$, what can we say about $f(x)$ at an arbitrary point $x$?

Interpolation recovers $f(x)$ for $x \in [x_0, x_n]$ by constructing a surrogate $p(x)$ that passes through, or approximates, the data. The Lagrange form guarantees existence and uniqueness among polynomials of degree at most $n$; the error is bounded by

$$|f(x) - p(x)| \leq \frac{M_{n+1}}{(n+1)!}\prod_{i=0}^{n}|x - x_i|,$$

where $M_{n+1} = \max_{\xi}|f^{(n+1)}(\xi)|$. Extrapolation applies the same surrogate outside $[x_0, x_n]$, where no data constrain the fit; the bound above grows unboundedly, which is why extrapolation demands both domain knowledge and explicit uncertainty quantification. Prediction is the umbrella term: a statistical or machine-learning model generalises the same idea to noisy, high-dimensional settings by replacing $p$ with a learned map $\hat{f}$ and attaching a confidence interval or posterior distribution.

Worked example. Suppose hourly temperature readings $(t_i, T_i)$ are collected for $t \in [0, 23]$ hours. A cubic spline interpolant reproduces the diurnal curve faithfully at any quarter-hour within the day. Forecasting tomorrow's noon temperature requires extrapolation: the spline is no longer anchored by data, so a practitioner augments it with a physics-informed prior or a recurrent neural network trained on seasonal patterns.

Key theorem (Weierstrass Approximation). For any continuous $f$ on $[a,b]$ and any $\varepsilon > 0$, there exists a polynomial $p$ such that $\|f - p\|_\infty < \varepsilon$. This guarantees that polynomial-based interpolants can achieve arbitrary accuracy inside the data interval, provided enough nodes and sufficient smoothness.

Lab cell.

import numpy as np
from sympy import symbols, interpolate, Rational, latex

x = symbols('x')
data = [(0, 1), (1, 3), (2, 2), (3, 5)]
p = interpolate(data, x)
print(latex(p))          # inspect the Lagrange polynomial
print(float(p.subs(x, 2.5)))   # interpolated value
print(float(p.subs(x, 4.0)))   # extrapolated value — handle with care
