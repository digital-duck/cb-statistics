Independent Dependent Variables

Definition. Given a relation $f : X \to Y$, we call $x \in X$ the independent variable and $y \in Y$ the dependent variable. The independent variable is the quantity chosen freely by the investigator; the dependent variable is determined by $f$ once $x$ is fixed. Formally, $y$ is dependent on $x$ if there exists a well-defined rule such that for each admissible value of $x$, exactly one value $y = f(x)$ is produced. The domain $X$ is the set of all permissible values of the independent variable, and the codomain $Y$ contains all possible outputs.

This distinction is not merely notational. It encodes a causal or functional direction: changing $x$ induces a change in $y$, but not conversely. When multiple independent variables are present, we write $z = f(x, y)$, where $x$ and $y$ are jointly independent and $z$ is the single dependent variable.

Worked Example. A projectile is launched vertically with initial velocity $v_0 = 20\ \text{m s}^{-1}$. Its height is modeled by

$$h(t) = v_0 t - \tfrac{1}{2}g t^2, \qquad g = 9.8\ \text{m s}^{-2}.$$

Here $t \geq 0$ (time elapsed, in seconds) is the independent variable; $h$ (height, in meters) is the dependent variable. At $t = 1\ \text{s}$:

$$h(1) = 20(1) - \tfrac{1}{2}(9.8)(1)^2 = 20 - 4.9 = 15.1\ \text{m}.$$

The experimenter controls $t$ by reading a clock; $h$ responds accordingly. Reversing the labeling—treating $h$ as given and asking for $t$—requires solving a quadratic and yields two solutions in general, illustrating that the inverse relation need not be a function on the full range.

Key Theorem (Implicit Function Theorem — introductory form). Let $F(x, y)$ be continuously differentiable near a point $(x_0, y_0)$ satisfying $F(x_0, y_0) = 0$. If $\partial F / \partial y \neq 0$ at $(x_0, y_0)$, then in a neighborhood of $x_0$ there exists a unique differentiable function $y = g(x)$ such that $F(x, g(x)) = 0$. In this neighborhood, $x$ is the independent variable and $y$ the dependent one.

Lab Cell (SymPy).

import sympy as sp

t = sp.Symbol('t', nonneg=True)
v0, g = 20, sp.Rational(49, 10)       # g = 4.9 * 2 = 9.8
h = v0*t - sp.Rational(1,2)*g*t**2

print("h(t) =", h)
print("h(1) =", h.subs(t, 1))         # 15.1 m
print("Max height at t =", sp.solve(sp.diff(h, t), t))   # [200/98]

Running this cell confirms $h(1) = 15.1$ and locates the peak at $t = v_0/g \approx 2.04\ \text{s}$, a value derived by treating the derivative $dh/dt$ as a function of the same independent variable $t$.
