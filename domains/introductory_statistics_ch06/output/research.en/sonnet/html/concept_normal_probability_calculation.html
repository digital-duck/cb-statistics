Normal Probability Calculation

Definition

The normal distribution (also called the Gaussian distribution) is a continuous probability distribution characterized by its bell-shaped density curve. A random variable $X$ follows a normal distribution with mean $\mu$ and variance $\sigma^2$, written $X \sim \mathcal{N}(\mu, \sigma^2)$, if its probability density function is

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \quad x \in \mathbb{R}.$$

The probability that $X$ falls in the interval $[a, b]$ is the definite integral $\int_a^b f(x)\,dx$. Because this integral has no elementary closed form, calculations are expressed using the cumulative distribution function $\Phi(z) = \int_{-\infty}^{z} \phi(t)\,dt$, where $\phi$ denotes the standard normal density. Standardizing via $Z = (X - \mu)/\sigma$ then gives

$$P(a \leq X \leq b) = \Phi\!\left(\tfrac{b-\mu}{\sigma}\right) - \Phi\!\left(\tfrac{a-\mu}{\sigma}\right).$$

Tabulated values of $\Phi$ make this formula the standard computational tool for all normal probability calculations.

Worked Example

Suppose exam scores follow $X \sim \mathcal{N}(72, 100)$ (mean 72, standard deviation 10). Find the probability that a randomly selected student scores between 60 and 85.

Step 1. Standardize the endpoints:

$$z_1 = \frac{60 - 72}{10} = -1.2, \qquad z_2 = \frac{85 - 72}{10} = 1.3.$$

Step 2. Apply the CDF:

$$P(60 \leq X \leq 85) = \Phi(1.3) - \Phi(-1.2) \approx 0.9032 - 0.1151 = 0.7881.$$

Approximately 78.8% of students score in this range.

Key Theorem

Symmetry of $\Phi$. For all $z \in \mathbb{R}$,

$$\Phi(-z) = 1 - \Phi(z).$$

Proof sketch. The standard normal density $\phi(t) = (2\pi)^{-1/2}e^{-t^2/2}$ is even. Splitting the integral at zero and substituting $t \mapsto -t$ yields $\Phi(-z) + \Phi(z) = 1$, which is the stated identity. $\square$

This identity halves table lookups: one need only tabulate $\Phi(z)$ for $z \geq 0$.

Lab Cell (SymPy)

from sympy import sqrt, Rational, erf

mu, sigma = 72, 10

# Phi(z) expressed via the error function: Phi(z) = (1 + erf(z/sqrt(2))) / 2
def Phi(z):
    return Rational(1, 2) * (1 + erf(z / sqrt(2)))

z1 = (60 - mu) / sigma   # -1.2
z2 = (85 - mu) / sigma   #  1.3

prob = Phi(z2) - Phi(z1)
print(float(prob))        # ≈ 0.7881

Running this cell confirms $P(60 \leq X \leq 85) \approx 0.7881$. SymPy evaluates $\Phi$ symbolically using the error function, and float() converts the result to a decimal for comparison with the table value above.
