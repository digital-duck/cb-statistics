Cumulative Distribution Function

Definition. Let $X$ be a real-valued random variable defined on a probability space $(\Omega, \mathcal{F}, P)$. The cumulative distribution function (CDF) of $X$ is the function $F_X : \mathbb{R} \to [0,1]$ defined by

$$F_X(x) = P(X \leq x), \quad x \in \mathbb{R}.$$

Every CDF satisfies three fundamental properties: (i) monotonicity — $F_X$ is non-decreasing; (ii) right-continuity — $F_X(x) = \lim_{t \to x^+} F_X(t)$ for all $x$; and (iii) boundary conditions — $\lim_{x \to -\infty} F_X(x) = 0$ and $\lim_{x \to +\infty} F_X(x) = 1$. Conversely, any function satisfying these three properties is the CDF of some random variable.

Worked Example. Let $X \sim \mathrm{Uniform}(0,1)$, so its probability density function is $f_X(x) = 1$ for $x \in [0,1]$ and zero otherwise. The CDF is obtained by integration:

$$F_X(x) = \int_{-\infty}^{x} f_X(t)\, dt = \begin{cases} 0, & x < 0, \\ x, & 0 \leq x \leq 1, \\ 1, & x > 1. \end{cases}$$

One may verify directly that $P(0.25 \leq X \leq 0.75) = F_X(0.75) - F_X(0.25) = 0.75 - 0.25 = 0.50$, confirming that exactly half the probability mass lies in the central interval.

Key Theorem (Probability via CDF). For any random variable $X$ with CDF $F_X$,

$$P(a < X \leq b) = F_X(b) - F_X(a), \quad a < b.$$

Proof sketch. The events $\{X \leq a\}$ and $\{a < X \leq b\}$ are disjoint with union $\{X \leq b\}$. Additivity of $P$ then gives $P(X \leq b) = P(X \leq a) + P(a < X \leq b)$, and rearranging yields the result. $\square$

This theorem is the workhorse of probability calculations: any interval probability reduces to two CDF evaluations, regardless of whether $X$ is discrete, continuous, or mixed.

Lab Cell.

from sympy import symbols, Piecewise, integrate, Rational, plot

x = symbols('x', real=True)
f = Piecewise((1, (x >= 0) & (x <= 1)), (0, True))
F = integrate(f, (x, -float('inf'), x))

# Verify P(0.25 <= X <= 0.75)
prob = F.subs(x, Rational(3,4)) - F.subs(x, Rational(1,4))
print(prob)   # Expected: 1/2
plot(F, (x, -0.5, 1.5), title='CDF of Uniform(0,1)')
