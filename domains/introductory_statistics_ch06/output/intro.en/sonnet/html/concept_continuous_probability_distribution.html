Continuous Probability Distribution

Definition. A random variable $X$ is continuous if there exists a non-negative function $f : \mathbb{R} \to [0, \infty)$, called the probability density function (PDF), such that for every interval $[a, b] \subseteq \mathbb{R}$,

$$P(a \le X \le b) = \int_a^b f(x)\, dx.$$

Two conditions must hold: $f(x) \ge 0$ for all $x$, and $\int_{-\infty}^{\infty} f(x)\, dx = 1$. Unlike the discrete case, $P(X = x) = 0$ for any single point; probability is carried by intervals, not atoms. The cumulative distribution function (CDF) is defined as

$$F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)\, dt,$$

so $F$ is non-decreasing, right-continuous, $\lim_{x \to -\infty} F(x) = 0$, and $\lim_{x \to \infty} F(x) = 1$. Where $F$ is differentiable, $f(x) = F'(x)$.

Worked Example. Let $X \sim \text{Uniform}(0, 2)$, so $f(x) = \tfrac{1}{2}$ on $[0,2]$ and $0$ elsewhere. To find $P(0.5 \le X \le 1.5)$:

$$P(0.5 \le X \le 1.5) = \int_{0.5}^{1.5} \frac{1}{2}\, dx = \frac{1}{2}(1.5 - 0.5) = \frac{1}{2}.$$

The corresponding CDF is $F(x) = x/2$ for $x \in [0,2]$, confirming $F'(x) = 1/2 = f(x)$.

Key Theorem (Expectation and Variance). For a continuous random variable $X$ with PDF $f$, provided the integrals converge absolutely,

$$\mu = E[X] = \int_{-\infty}^{\infty} x\, f(x)\, dx, \qquad \sigma^2 = \text{Var}(X) = \int_{-\infty}^{\infty} (x - \mu)^2 f(x)\, dx.$$

Equivalently, $\sigma^2 = E[X^2] - \mu^2$. These are the continuous analogues of the weighted sums used in the discrete case, with integration replacing summation.

Lab Cell.

from sympy import symbols, integrate, oo, Rational, simplify

x = symbols('x')
f = Rational(1, 2)                          # Uniform(0,2) PDF

prob = integrate(f, (x, Rational(1,2), Rational(3,2)))
mu   = integrate(x * f, (x, 0, 2))
var  = integrate((x - mu)**2 * f, (x, 0, 2))

print("P(0.5 ≤ X ≤ 1.5) =", prob)          # 1/2
print("E[X] =", mu)                          # 1
print("Var(X) =", simplify(var))             # 1/3
