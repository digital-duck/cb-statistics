Concept Book: Normal Probability Calculation

Introductory Statistics Ch06 · Generated by SPL

Payoff

Normal probability calculation is the operation of evaluating, for a normally distributed random variable $X \sim \mathcal{N}(\mu, \sigma^2)$, the probability that $X$ falls within a specified interval. Formally, for $a < b$,

$$P(a \leq X \leq b) = \int_a^b \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) dx = \Phi\!\left(\frac{b-\mu}{\sigma}\right) - \Phi\!\left(\frac{a-\mu}{\sigma}\right),$$

where $\Phi(z) = \frac{1}{2}\!\left[1 + \operatorname{erf}\!\left(\frac{z}{\sqrt{2}}\right)\right]$ is the standard normal cumulative distribution function. Because the Gaussian integral has no closed form in elementary functions, $\Phi$ is defined analytically and approximated numerically; every tool we have built in this book — standardization, the error function, numerical quadrature — was assembled precisely to make this final step computable.

Worked example. Suppose the breaking strength of a steel cable is $X \sim \mathcal{N}(500, 25^2)$ kN. A structure is safe when $X \geq 450$ kN. Then

$$P(X \geq 450) = 1 - \Phi\!\left(\frac{450 - 500}{25}\right) = 1 - \Phi(-2) = \Phi(2) \approx 0.9772.$$

There is roughly a $97.7\%$ probability the cable meets specification — a concrete, decision-relevant number that emerges directly from the calculation.

Key theorem (Central Limit Theorem, informal). Let $X_1, X_2, \ldots, X_n$ be independent and identically distributed with mean $\mu$ and finite variance $\sigma^2$. Then the standardized sample mean

$$Z_n = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1) \quad \text{as } n \to \infty.$$

This theorem is the reason normal probability calculation matters far beyond problems that start Gaussian: sums of measurements, averages of test scores, and aggregate financial returns all converge in distribution to the normal, making $\Phi$ the universal currency of probability approximation.

Lab cell.

from sympy import symbols, erf, sqrt, Rational, N

def normal_cdf(x, mu, sigma):
    z = (x - mu) / (sigma * sqrt(2))
    return Rational(1, 2) * (1 + erf(z))

mu, sigma = 500, 25
prob = normal_cdf(500 + 2*25, mu, sigma) - normal_cdf(450, mu, sigma)
print(N(normal_cdf(500, mu, sigma) - normal_cdf(450, mu, sigma), 6))

With the machinery of normal probability calculation in hand, an entire landscape of quantitative reasoning becomes accessible — from quality-control tolerance bands and clinical trial power analysis to financial risk measurement and signal-detection theory. Each domain inherits the same arithmetic: standardize, evaluate $\Phi$, interpret. As an invitation to go deeper, consider turning next to hypothesis testing, where this single calculation decides whether an observed result could plausibly have arisen by chance — and, when it could not, licenses a scientific conclusion.
