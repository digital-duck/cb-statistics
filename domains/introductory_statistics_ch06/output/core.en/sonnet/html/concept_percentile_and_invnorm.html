Percentile And Invnorm

Definition. Let $X$ be a continuous random variable with cumulative distribution function $F(x) = P(X \leq x)$. The $p$-th percentile of $X$, denoted $x_p$, is the value satisfying

$$F(x_p) = p, \qquad 0 < p < 1.$$

Equivalently, $x_p = F^{-1}(p)$, the quantile function (or inverse CDF). For the standard normal distribution $Z \sim \mathcal{N}(0,1)$, this inverse is written $z_p = \Phi^{-1}(p)$ and is called the inverse normal or invnorm. For a general normal $X \sim \mathcal{N}(\mu, \sigma^2)$, the percentile converts via the standardisation identity:

$$x_p = \mu + \sigma\,\Phi^{-1}(p).$$

Worked Example. Adult resting heart rates are approximately normally distributed with mean $\mu = 70$ bpm and standard deviation $\sigma = 10$ bpm. Find the 90th percentile.

We need $x_{0.90} = 70 + 10\,\Phi^{-1}(0.90)$. From standard tables (or a CAS), $\Phi^{-1}(0.90) \approx 1.2816$. Therefore

$$x_{0.90} = 70 + 10(1.2816) = 70 + 12.816 \approx 82.8 \text{ bpm}.$$

Interpretation: 90% of adults have a resting heart rate at or below approximately 83 bpm.

Key Theorem (Symmetry of the Standard Normal Percentile). Because $\Phi$ is symmetric about zero, its inverse satisfies

$$\Phi^{-1}(1 - p) = -\Phi^{-1}(p), \qquad 0 < p < 1.$$

Proof sketch. By the reflection symmetry $\Phi(-z) = 1 - \Phi(z)$, setting $z = \Phi^{-1}(p)$ gives $\Phi(-\Phi^{-1}(p)) = 1 - p$, so $-\Phi^{-1}(p)$ is the value whose CDF equals $1-p$, which is exactly $\Phi^{-1}(1-p)$. $\square$

A direct consequence is that upper and lower percentiles are paired: for example, $\Phi^{-1}(0.90) = -\Phi^{-1}(0.10) \approx 1.2816$, halving the table lookups needed in practice.

Lab Cell.

from scipy.stats import norm
import sympy as sp

mu, sigma = 70, 10

# 90th percentile numerically
p90 = norm.ppf(0.90, loc=mu, scale=sigma)
print(f"90th percentile: {p90:.2f} bpm")

# Verify: P(X <= p90) should equal 0.90
print(f"CDF check: {norm.cdf(p90, loc=mu, scale=sigma):.4f}")

# Symbolic inverse CDF via SymPy (standard normal)
p = sp.Symbol('p', positive=True)
# Phi^{-1}(p) = sqrt(2)*erfinv(2p - 1)
invnorm_expr = sp.sqrt(2) * sp.erfinv(2*p - 1)
print(sp.simplify(invnorm_expr.subs(p, sp.Rational(1,2))))  # => 0

# Confirm symmetry: Phi^{-1}(0.90) == -Phi^{-1}(0.10)
print(f"Phi^{{-1}}(0.90) = {norm.ppf(0.90):.4f}")
print(f"-Phi^{{-1}}(0.10) = {-norm.ppf(0.10):.4f}")

Running this cell confirms $x_{0.90} \approx 82.82$ bpm, that $\Phi^{-1}(0.5) = 0$ by symmetry, and that $\Phi^{-1}(0.90) = -\Phi^{-1}(0.10)$ to four decimal places.
