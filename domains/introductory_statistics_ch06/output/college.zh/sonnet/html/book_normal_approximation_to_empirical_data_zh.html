正态近似的本质与意义

经过本书前几章对概率分布、大数定律与中心极限定理的系统论述，我们终于抵达核心目的地：用正态分布近似经验数据。所谓经验数据的正态近似，是指对于来自未知总体的独立同分布样本 $X_1, X_2, \ldots, X_n$，当 $n$ 足够大时，样本均值 $\bar{X}_n$ 的分布可被如下正态分布精确刻画：

$$\bar{X}_n \xrightarrow{d} \mathcal{N}\!\left(\mu,\, \frac{\sigma^2}{n}\right), \quad n \to \infty$$

其中 $\mu = \mathbb{E}[X_i]$，$\sigma^2 = \operatorname{Var}(X_i)$。这一结论的深刻之处在于：它对总体分布的形态几乎不作假设，只要均值与方差有限，正态近似便自然涌现。这正是为何正态分布在统计学中占据核心地位，也是为何本书将其视为概念体系的自然终点。

具体示例

设某班级 $n = 50$ 名学生的数学成绩 $X_i$ 服从均值 $\mu = 72$、标准差 $\sigma = 10$ 的未知分布。由中心极限定理，样本均值满足：

$$\bar{X}_{50} \approx \mathcal{N}\!\left(72,\, \frac{100}{50}\right) = \mathcal{N}(72,\, 2)$$

因此，$\bar{X}_{50}$ 落在区间 $[70, 74]$ 的概率为：

$$P(70 \le \bar{X}_{50} \le 74) \approx P\!\left(\frac{70-72}{\sqrt{2}} \le Z \le \frac{74-72}{\sqrt{2}}\right) = P(-\sqrt{2} \le Z \le \sqrt{2}) \approx 0.8427$$

这一计算无需知道成绩的真实分布，正态近似已足够精确。

核心定理

（Berry–Esseen 定理） 若 $\mathbb{E}[|X_i|^3] < \infty$，则存在绝对常数 $C \le 0.4748$，使得：

$$\sup_{x \in \mathbb{R}} \left| F_n(x) - \Phi(x) \right| \le \frac{C \cdot \mathbb{E}[|X_i - \mu|^3]}{\sigma^3 \sqrt{n}}$$

该定理不仅保证了近似的收敛性，更给出了误差的显式上界，为实际应用中样本量的选取提供了理论依据。

SymPy 实验单元

from sympy import symbols, integrate, exp, pi, sqrt, oo, erf
from sympy.stats import Normal, P, E

mu, sigma = 72, sqrt(2)
X = Normal('X', mu, sigma)

# 计算近似概率
prob = P((X >= 70) & (X <= 74))
print("正态近似概率：", prob.evalf())
