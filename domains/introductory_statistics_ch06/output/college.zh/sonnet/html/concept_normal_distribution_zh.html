正态分布

定义。 设连续随机变量 $X$ 的概率密度函数为

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \quad x \in \mathbb{R},$$

其中参数 $\mu \in \mathbb{R}$ 称为均值，$\sigma > 0$ 称为标准差。则称 $X$ 服从正态分布，记作 $X \sim \mathcal{N}(\mu, \sigma^2)$。当 $\mu = 0,\, \sigma = 1$ 时，称之为标准正态分布，其密度函数记为 $\varphi(x)$，累积分布函数记为 $\Phi(x)$。

具体示例。 某大学一年级物理课期末成绩 $X \sim \mathcal{N}(72, 10^2)$，即均值为 $72$ 分，标准差为 $10$ 分。求成绩落在区间 $[62, 82]$ 内的概率。

将端点标准化：

$$Z = \frac{X - 72}{10},$$

则

$$P(62 \leq X \leq 82) = P\!\left(\frac{62-72}{10} \leq Z \leq \frac{82-72}{10}\right) = P(-1 \leq Z \leq 1) = \Phi(1) - \Phi(-1).$$

利用标准正态表知 $\Phi(1) \approx 0.8413$，而对称性给出 $\Phi(-1) = 1 - \Phi(1) \approx 0.1587$，故

$$P(62 \leq X \leq 82) \approx 0.8413 - 0.1587 = 0.6826.$$

这正是著名的68–95–99.7 法则中 $\mu \pm \sigma$ 区间所对应的概率。

关键定理（中心极限定理，Lindeberg–Lévy 版本）。 设 $X_1, X_2, \ldots$ 为独立同分布随机变量序列，均值为 $\mu$，方差为 $\sigma^2 < \infty$。令 $S_n = \sum_{i=1}^n X_i$，则

$$\frac{S_n - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1), \quad n \to \infty.$$

该定理揭示了正态分布在概率论中的核心地位：大量独立随机因素叠加后，无论原始分布形态如何，其标准化和均依分布收敛于标准正态分布。

实验单元（SymPy）。

from sympy import symbols, exp, pi, sqrt, integrate, oo, simplify

x, mu, sigma = symbols('x mu sigma', real=True)
f = (1 / (sigma * sqrt(2 * pi))) * exp(-(x - mu)**2 / (2 * sigma**2))

# 验证归一化：∫_{-∞}^{∞} f dx = 1
norm = integrate(f, (x, -oo, oo))
print(simplify(norm))  # 输出 1

# 计算 P(62 ≤ X ≤ 82)，μ=72，σ=10
from sympy import erf
prob = integrate(f.subs([(mu, 72), (sigma, 10)]), (x, 62, 82))
print(prob.evalf())    # 约 0.6827
