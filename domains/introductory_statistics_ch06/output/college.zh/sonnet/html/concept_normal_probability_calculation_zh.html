Normal Probability Calculation

定义。 设随机变量 $X$ 服从均值为 $\mu$、标准差为 $\sigma > 0$ 的正态分布，记作 $X \sim \mathcal{N}(\mu, \sigma^2)$。其概率密度函数为

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \quad x \in \mathbb{R}.$$

$X$ 落在区间 $(a, b)$ 内的概率定义为

$$P(a < X < b) = \int_a^b f(x)\,dx.$$

由于上述积分不存在初等闭式，实际计算依赖标准正态分布的累积分布函数（CDF）：$\Phi(z) = P(Z \le z)$，其中 $Z \sim \mathcal{N}(0,1)$。通过标准化变换 $Z = (X - \mu)/\sigma$，得

$$P(a < X < b) = \Phi\!\left(\frac{b-\mu}{\sigma}\right) - \Phi\!\left(\frac{a-\mu}{\sigma}\right).$$

例题。 某班级考试成绩 $X \sim \mathcal{N}(70, 10^2)$（单位：分）。求成绩落在 $[60, 85]$ 之间的概率。

将端点标准化：

$$z_1 = \frac{60 - 70}{10} = -1.0, \quad z_2 = \frac{85 - 70}{10} = 1.5.$$

查标准正态表（或利用软件）得 $\Phi(1.5) \approx 0.9332$，$\Phi(-1.0) \approx 0.1587$，故

$$P(60 \le X \le 85) = 0.9332 - 0.1587 = 0.7745.$$

即约 $77.45\%$ 的学生成绩落在该区间内。

关键定理（$68$–$95$–$99.7$ 法则）。 对任意 $X \sim \mathcal{N}(\mu, \sigma^2)$：

$$P(\mu - k\sigma < X < \mu + k\sigma) = \begin{cases} \approx 0.6827, & k=1,\\ \approx 0.9545, & k=2,\\ \approx 0.9973, & k=3. \end{cases}$$

该结论直接由 $\Phi(k) - \Phi(-k) = 2\Phi(k) - 1$ 的对称性导出，是判断离群值的经验基础。

实验单元（SymPy）。

from sympy import symbols, integrate, exp, pi, sqrt, erf, oo, N

x, mu, sigma = symbols('x mu sigma', real=True)
# 标准正态密度
f = exp(-x**2 / 2) / sqrt(2 * pi)
# 计算 P(-1 < Z < 1.5)
prob = integrate(f, (x, -1, 1.5))
print(N(prob, 6))   # 输出约 0.774499

运行上述代码，SymPy 将通过误差函数 $\operatorname{erf}$ 给出精确符号结果，再由 N() 转换为数值，与手算结果一致。
