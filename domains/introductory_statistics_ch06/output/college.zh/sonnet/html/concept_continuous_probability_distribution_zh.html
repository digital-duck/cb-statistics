Continuous Probability Distribution

定义。 设 $X$ 为定义在样本空间 $\Omega$ 上的随机变量。若存在非负函数 $f: \mathbb{R} \to [0, +\infty)$，使得对任意区间 $[a, b] \subseteq \mathbb{R}$，有

$$P(a \leq X \leq b) = \int_a^b f(x)\, dx,$$

则称 $X$ 为连续型随机变量，$f(x)$ 为其概率密度函数（probability density function，PDF）。密度函数须满足以下两个条件：

$$f(x) \geq 0, \quad \forall x \in \mathbb{R}; \qquad \int_{-\infty}^{+\infty} f(x)\, dx = 1.$$

对应的累积分布函数（CDF）定义为

$$F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t)\, dt.$$

在 $f$ 连续的点处，$F'(x) = f(x)$，即密度函数是分布函数的导数。

例题。 设随机变量 $X$ 服从均匀分布 $X \sim \text{Uniform}(2, 5)$，其概率密度函数为

$$f(x) = \begin{cases} \dfrac{1}{3}, & 2 \leq x \leq 5, \\ 0, & \text{其他}. \end{cases}$$

求 $P(3 \leq X \leq 4)$。

解：

$$P(3 \leq X \leq 4) = \int_3^4 \frac{1}{3}\, dx = \frac{1}{3} \cdot (4 - 3) = \frac{1}{3}.$$

几何上，概率等于密度曲线下方对应区间内的面积。

定理（全概率归一化）。 若 $f$ 为随机变量 $X$ 的概率密度函数，则

$$\int_{-\infty}^{+\infty} f(x)\, dx = 1, \quad \text{且} \quad \lim_{x \to +\infty} F(x) = 1,\quad \lim_{x \to -\infty} F(x) = 0.$$

证明思路： 由概率公理，$P(\Omega) = P(-\infty < X < +\infty) = 1$；将此事件表示为积分，即得归一化条件。单调性与极限值则由积分区间趋于全实轴时的单调收敛定理保证。$\blacksquare$

实验单元（SymPy）。

from sympy import symbols, integrate, Rational, Piecewise, oo

x = symbols('x')
f = Rational(1, 3)                        # 均匀分布密度（区间 [2,5]）
prob = integrate(f, (x, 3, 4))           # P(3 ≤ X ≤ 4)
normalization = integrate(f, (x, 2, 5))  # 验证归一化

print("P(3 ≤ X ≤ 4) =", prob)           # 输出 1/3
print("归一化验证    =", normalization)  # 输出 1

运行上述代码，可验证概率值与归一化条件均与理论结果完全吻合。
