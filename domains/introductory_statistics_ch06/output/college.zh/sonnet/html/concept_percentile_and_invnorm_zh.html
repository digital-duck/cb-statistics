Percentile And Invnorm

定义。 设连续随机变量 $X$ 具有累积分布函数 $F(x) = P(X \le x)$。给定概率水平 $p \in (0,1)$，$X$ 的第 $p$ 百分位数（percentile）定义为满足

$$F(x_p) = p$$

的实数 $x_p$。等价地，$x_p = F^{-1}(p)$，即累积分布函数的反函数在 $p$ 处的取值。对于标准正态分布 $Z \sim \mathcal{N}(0,1)$，这一反函数通常记作 $\Phi^{-1}(p)$，在统计软件中以 invnorm 或 ppf 的形式出现。对于一般正态分布 $X \sim \mathcal{N}(\mu, \sigma^2)$，其第 $p$ 百分位数为

$$x_p = \mu + \sigma \cdot \Phi^{-1}(p).$$

工作示例。 某高校入学考试成绩服从正态分布，均值 $\mu = 520$，标准差 $\sigma = 80$。求第 $90$ 百分位数，即成绩超过 $90\%$ 考生的分数线。

令 $p = 0.90$。查标准正态表（或使用计算工具）得 $\Phi^{-1}(0.90) \approx 1.2816$。代入公式：

$$x_{0.90} = 520 + 80 \times 1.2816 = 520 + 102.53 \approx 622.5.$$

因此，成绩约为 $622.5$ 分的考生处于第 $90$ 百分位，意味着其成绩高于约 $90\%$ 的参考者。

关键定理。 设 $X \sim \mathcal{N}(\mu, \sigma^2)$，$Z = (X - \mu)/\sigma \sim \mathcal{N}(0,1)$。则对任意 $p \in (0,1)$，

$$P(X \le \mu + \sigma\,\Phi^{-1}(p)) = p.$$

证明要点： 由 $Z$ 的标准化关系，$P(X \le x_p) = P\!\left(Z \le \frac{x_p - \mu}{\sigma}\right) = \Phi\!\left(\Phi^{-1}(p)\right) = p$。$\square$

由此可见，百分位数计算本质上是将概率空间中的水平线 $p$ 映射回数据空间，而 $\Phi^{-1}$ 正是完成这一映射的桥梁。

实验单元（SymPy）。

from scipy.stats import norm
import sympy as sp

mu, sigma, p = 520, 80, 0.90
x_p = norm.ppf(p, loc=mu, scale=sigma)
print(f"第90百分位数: {x_p:.2f}")   # 622.53

# 符号验证
z = sp.Symbol('z')
phi_inv = float(sp.N(sp.erfinv(2*p - 1) * sp.sqrt(2)))
print(f"Φ⁻¹(0.90) ≈ {phi_inv:.4f}")  # 1.2816

运行上述代码可验证 $x_{0.90} \approx 622.53$，并通过误差函数的反函数 $\mathrm{erf}^{-1}$ 从符号层面重现 $\Phi^{-1}$，加深对其数学根源的理解。
