Cumulative Distribution Function

定义。 设 $X$ 为一个随机变量，其累积分布函数（Cumulative Distribution Function，简称 CDF）定义为

$$F_X(x) = P(X \leq x), \quad x \in \mathbb{R}.$$

对于连续型随机变量，若其概率密度函数（PDF）为 $f_X(t)$，则

$$F_X(x) = \int_{-\infty}^{x} f_X(t)\, dt.$$

CDF 具有以下三条基本性质：

  • 单调不减：若 $x_1 < x_2$，则 $F_X(x_1) \leq F_X(x_2)$；
  • 边界条件：$\lim_{x \to -\infty} F_X(x) = 0$，$\lim_{x \to +\infty} F_X(x) = 1$；
  • 右连续性：$\lim_{h \to 0^+} F_X(x+h) = F_X(x)$。

    • 例题。 设 $X \sim \mathcal{N}(0, 1)$（标准正态分布），其 PDF 为

    $$f_X(t) = \frac{1}{\sqrt{2\pi}} e^{-t^2/2}.$$

    求 $P(-1 \leq X \leq 1)$。

    解： 利用 CDF 的定义，

    $$P(-1 \leq X \leq 1) = F_X(1) - F_X(-1) = \Phi(1) - \Phi(-1),$$

    其中 $\Phi$ 为标准正态 CDF。由对称性 $\Phi(-1) = 1 - \Phi(1)$，查表得 $\Phi(1) \approx 0.8413$，从而

    $$P(-1 \leq X \leq 1) \approx 0.8413 - 0.1587 = 0.6826.$$

    这即为著名的"$1\sigma$ 规则"：约 $68.3\%$ 的概率质量落在均值的一个标准差范围内。

    关键定理（微积分基本定理的应用）。 设 $F_X$ 在点 $x$ 处可微，则

    $$f_X(x) = \frac{d}{dx} F_X(x).$$

    证明思路： 由导数定义，

    $$F_X'(x) = \lim_{h \to 0^+} \frac{F_X(x+h) - F_X(x)}{h} = \lim_{h \to 0^+} \frac{P(x < X \leq x+h)}{h}.$$

    当 $h \to 0^+$ 时，右侧趋于 $f_X(x)$，由此得证。此结论说明 PDF 与 CDF 互为微积分意义下的逆运算。

    实验单元（SymPy）

    from sympy import symbols, exp, pi, sqrt, integrate, erf, oo, simplify

t, x = symbols('t x', real=True)

# 标准正态 PDF
f = exp(-t**2 / 2) / sqrt(2 * pi)

# 计算 CDF：F(x) = ∫_{-∞}^{x} f(t) dt
F = integrate(f, (t, -oo, x))
F_simplified = simplify(F)
print("CDF:", F_simplified)          # 输出：erf(sqrt(2)*x/2)/2 + 1/2

# 验证：F(1) - F(-1)
prob = F_simplified.subs(x, 1) - F_simplified.subs(x, -1)
print("P(-1 ≤ X ≤ 1) =", float(prob.evalf()))   # ≈ 0.6827
