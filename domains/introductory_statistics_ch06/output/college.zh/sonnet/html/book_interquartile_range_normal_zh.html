Concept Book: Interquartile Range Normal

Introductory Statistics Ch06 · Generated by SPL

收益

定义回顾。 设随机变量 $X \sim \mathcal{N}(\mu, \sigma^2)$，其第一四分位数与第三四分位数分别为

$$Q_1 = \mu - z_{0.75}\,\sigma, \qquad Q_3 = \mu + z_{0.75}\,\sigma,$$

其中 $z_{0.75} = \Phi^{-1}(0.75) \approx 0.6745$，$\Phi$ 为标准正态累积分布函数。正态四分位距（interquartile range of the normal distribution）定义为

$$\mathrm{IQR} = Q_3 - Q_1 = 2\,z_{0.75}\,\sigma \approx 1.3490\,\sigma.$$

这一精确公式将看似非参数的散布度量与分布参数 $\sigma$ 直接挂钩，是全书概念链的自然终点：我们从中位数出发，理解了分位数，掌握了正态分布的对称性，最终在此将所有线索汇聚为一个可计算、可解释的量。

验证示例。 考虑标准正态分布 $X \sim \mathcal{N}(0,1)$。由上式得 $\mathrm{IQR} = 2 \times 0.6745 \approx 1.3490$。用 SymPy 验证：

from sympy import symbols, N
from sympy.stats import Normal, cdf

X = Normal('X', 0, 1)
Q1 = cdf(X)(0.25).rewrite('erf')
Q3 = cdf(X)(0.75).rewrite('erf')
# 数值近似
print(N(Q3 - Q1, 6))  # 输出：1.34898

结果与理论吻合，表明 $\mathrm{IQR} \approx 1.349\sigma$ 并非近似，而是精确关系的数值体现。

核心定理。 对于正态分布，$\mathrm{IQR}$ 是 $\sigma$ 的线性无偏估计量的基础：令 $\hat{\sigma} = \mathrm{IQR}/1.3490$，则 $\hat{\sigma}$ 对异常值的敏感度远低于样本标准差，同时保持渐近无偏性。这一性质使其在稳健统计中不可或缺。

应用展望。 此公式开启了三个重要方向。其一，稳健描述统计：在金融收益率分析中，异常值频繁出现，$\hat{\sigma}$ 替代样本标准差可避免风险被高估。其二，箱线图与离群点检测：Tukey 规则将超出 $[Q_1 - 1.5\,\mathrm{IQR},\; Q_3 + 1.5\,\mathrm{IQR}]$ 的观测标记为异常，该区间宽度由本节公式直接决定。其三，正态性检验：若样本 $\mathrm{IQR}/\hat{\sigma}$ 显著偏离 $1.349$，则可作为拒绝正态假设的初步证据，与 Shapiro–Wilk 检验形成互补。
