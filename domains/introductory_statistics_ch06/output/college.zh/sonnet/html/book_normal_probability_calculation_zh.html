收益

正态概率计算（normal probability calculation）是本教材的自然终点，它将前述所有工具——极限、积分、级数展开与概率论基础——汇聚于一个可操作的计算框架之中。其核心任务是：对于服从正态分布 $X \sim \mathcal{N}(\mu, \sigma^2)$ 的随机变量，精确求得事件 $a \leq X \leq b$ 的概率

$$P(a \leq X \leq b) = \int_a^b \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) dx.$$

由于上述积分不存在初等反函数，我们引入标准化变换 $Z = (X - \mu)/\sigma$，将问题化归为标准正态分布的累积分布函数

$$\Phi(z) = \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}} e^{-t^2/2}\, dt,$$

从而 $P(a \leq X \leq b) = \Phi\!\left(\tfrac{b-\mu}{\sigma}\right) - \Phi\!\left(\tfrac{a-\mu}{\sigma}\right)$。

具体示例：设某次考试成绩 $X \sim \mathcal{N}(70, 100)$，即均值 $\mu = 70$，标准差 $\sigma = 10$。求得分超过 85 分的概率：令 $z = (85-70)/10 = 1.5$，则 $P(X > 85) = 1 - \Phi(1.5) \approx 1 - 0.9332 = 6.68\%$。

关键定理（中心极限定理）：设 $X_1, X_2, \ldots, X_n$ 为独立同分布随机变量，均值 $\mu$，方差 $\sigma^2 < \infty$，则当 $n \to \infty$ 时，

$$\frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1).$$

此定理揭示了正态分布的普适地位：无论原始数据服从何种分布，样本均值的标准化极限皆为标准正态。这正是正态概率计算成为统计推断基石的深层原因。

# SymPy 实验单元
from sympy import symbols, exp, pi, sqrt, integrate, oo, erf, N

x = symbols('x')
phi = (1/sqrt(2*pi)) * exp(-x**2 / 2)
# 计算 P(Z <= 1.5)
prob = integrate(phi, (x, -oo, 1.5))
print("Φ(1.5) =", N(prob, 6))

至此，我们已掌握从原始数据到精确概率陈述的完整路径。正态概率计算所蕴含的思想——标准化、查表（或数值积分）、置信度量化——是现代数据科学与工程决策的通用语言。诚邀读者选择一个感兴趣的应用领域，以本节方法为起点，深入探索其背后的统计机制与实践价值。
