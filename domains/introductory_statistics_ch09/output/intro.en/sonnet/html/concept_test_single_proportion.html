Test Single Proportion

Definition. Let $X_1, X_2, \ldots, X_n$ be independent Bernoulli random variables with common success probability $p \in (0,1)$. The test for a single proportion evaluates the null hypothesis

$$H_0: p = p_0$$

against one of three alternatives: $H_1: p \neq p_0$ (two-tailed), $H_1: p > p_0$, or $H_1: p < p_0$ (one-tailed). The test statistic is the standardised sample proportion,

$$Z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}},$$

where $\hat{p} = \bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ is the maximum-likelihood estimator of $p$. Under $H_0$, the statistic $Z$ converges in distribution to $\mathcal{N}(0,1)$ as $n \to \infty$, provided the success–failure condition $np_0 \geq 10$ and $n(1-p_0) \geq 10$ holds.

Worked Example. A clinical trial reports that 63 of 200 patients experienced symptom relief after a new treatment. Historical records place the baseline relief rate at $p_0 = 0.25$. Test at the $\alpha = 0.05$ level whether the new treatment differs from baseline.

Compute the sample proportion: $\hat{p} = 63/200 = 0.315$. Check the success–failure condition: $200 \times 0.25 = 50 \geq 10$ and $200 \times 0.75 = 150 \geq 10$. Both conditions are satisfied. The test statistic is

$$Z = \frac{0.315 - 0.25}{\sqrt{0.25 \times 0.75 / 200}} = \frac{0.065}{0.03062} \approx 2.12.$$

For a two-tailed test, the $p$-value is $2\,\Phi(-|Z|) = 2\,\Phi(-2.12) \approx 0.034$. Since $0.034 < 0.05$, we reject $H_0$ and conclude there is statistically significant evidence that the treatment changes the relief rate.

Key Theorem (Normal Approximation to Binomial). If $X \sim \mathrm{Binomial}(n, p_0)$, then by the Central Limit Theorem

$$\frac{X - np_0}{\sqrt{np_0(1-p_0)}} \xrightarrow{d} \mathcal{N}(0,1) \quad \text{as } n \to \infty.$$

Dividing numerator and denominator by $n$ yields the $Z$ statistic above. This justifies using normal critical values ($z_{\alpha/2} = 1.96$ at $\alpha = 0.05$) in place of exact binomial tail probabilities when the sample is sufficiently large.

from sympy.stats import Normal, P, cdf
from sympy import symbols, sqrt, Rational, N

n, p0, x_obs = 200, Rational(1, 4), 63
p_hat = Rational(x_obs, n)
se = sqrt(p0 * (1 - p0) / n)
Z_val = (p_hat - p0) / se

z = symbols('z')
Z = Normal('Z', 0, 1)
p_value = 2 * float(P(Z < -abs(Z_val)))

print(f"p-hat  = {float(p_hat):.4f}")
print(f"Z      = {float(Z_val):.4f}")
print(f"p-value = {p_value:.4f}")
print("Reject H0" if p_value < 0.05 else "Fail to reject H0")
