P 值

定义。 设 $H_0$ 为零假设，$T$ 为检验统计量，$t_{\text{obs}}$ 为由样本数据所得的观测值。P 值定义为：在 $H_0$ 为真的前提下，检验统计量 $T$ 取到不亚于 $t_{\text{obs}}$ 极端程度的概率，即

$$p = P(T \geq t_{\text{obs}} \mid H_0).$$

对于双侧检验，则取

$$p = P(|T| \geq |t_{\text{obs}}| \mid H_0).$$

P 值并非"$H_0$ 为真的概率"，而是衡量观测数据与 $H_0$ 相容程度的指标：$p$ 越小，数据对 $H_0$ 的反驳越强。

具体例子。 某校称其学生平均身高 $\mu_0 = 170\,\text{cm}$。研究者随机抽取 $n = 25$ 名学生，测得样本均值 $\bar{x} = 173\,\text{cm}$，样本标准差 $s = 10\,\text{cm}$。取显著性水平 $\alpha = 0.05$，进行双侧 $t$ 检验。

检验统计量为

$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}} = \frac{173 - 170}{10/\sqrt{25}} = \frac{3}{2} = 1.5.$$

自由度 $\nu = 24$，查 $t$ 分布表或利用计算工具得

$$p = 2\,P(T_{24} \geq 1.5) \approx 0.147.$$

由于 $p = 0.147 > 0.05 = \alpha$，未能在 $\alpha$ 水平上拒绝 $H_0$，即现有证据不足以否认该校学生平均身高为 $170\,\text{cm}$ 的声称。

关键定理（P 值的均匀性）。 若检验统计量 $T$ 在 $H_0$ 下为连续分布，则 P 值 $p$ 在 $H_0$ 下服从 $[0,1]$ 上的均匀分布，即

$$p \mid H_0 \sim \mathrm{Uniform}(0,1).$$

推论： 若拒绝规则为"当 $p \leq \alpha$ 时拒绝 $H_0$"，则犯第一类错误的概率恰好等于 $\alpha$，从而保证了检验的名义显著性水平。

实验室代码（SymPy / SciPy）。

from scipy import stats
import numpy as np

x_bar, mu_0, s, n = 173, 170, 10, 25
t_obs = (x_bar - mu_0) / (s / np.sqrt(n))
p_value = 2 * stats.t.sf(abs(t_obs), df=n - 1)
print(f"t = {t_obs:.4f},  p = {p_value:.4f}")
# 输出：t = 1.5000,  p = 0.1469
