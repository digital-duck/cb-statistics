显著性水平

定义。 在假设检验的框架下，显著性水平（significance level）是研究者事先指定的一个概率阈值，记作 $\alpha \in (0,1)$，表示在原假设 $H_0$ 为真的条件下，检验统计量落入拒绝域的最大可接受概率。形式地，若拒绝域为 $C$，则要求

$$ P\!\left(T(\mathbf{X}) \in C \mid H_0\right) \leq \alpha, $$

其中 $T(\mathbf{X})$ 为基于样本 $\mathbf{X} = (X_1, \ldots, X_n)$ 构造的检验统计量。$\alpha$ 控制第一类错误（弃真错误）的概率上界，常取 $0.05$ 或 $0.01$。

例题。 设某校学生数学成绩服从正态分布，历史均值 $\mu_0 = 70$，标准差 $\sigma = 10$（已知）。随机抽取 $n = 25$ 名学生，样本均值 $\bar{x} = 74$。取显著性水平 $\alpha = 0.05$，检验 $H_0\colon \mu = 70$ 对 $H_1\colon \mu \neq 70$。

在 $H_0$ 成立时，检验统计量

$$ Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} = \frac{\bar{X} - 70}{10/5} \sim N(0,1). $$

双侧拒绝域为 $|Z| > z_{\alpha/2} = z_{0.025} = 1.96$。代入观测值：

$$ z = \frac{74 - 70}{2} = 2.00 > 1.96, $$

故在 $\alpha = 0.05$ 水平下拒绝 $H_0$，有统计显著证据表明均值偏离 $70$。

关键定理（Neyman–Pearson 框架）。 对于简单假设 $H_0\colon \theta = \theta_0$ 与 $H_1\colon \theta = \theta_1$，给定显著性水平 $\alpha$，似然比检验

$$ \Lambda(\mathbf{x}) = \frac{L(\theta_1;\mathbf{x})}{L(\theta_0;\mathbf{x})} \geq k_\alpha $$

是最优势检验（most powerful test），即在所有水平为 $\alpha$ 的检验中，其检验功效 $1 - \beta$ 达到最大。此定理保证了显著性水平约束下第二类错误的最小化。

实验单元（SymPy）。

from sympy import symbols, N
from sympy.stats import Normal, P, cdf

Z = Normal('Z', 0, 1)
alpha = 0.05
z_crit = float(N(-Normal('Z',0,1).quantile(alpha/2), 6))  # 1.95996…

z_obs = (74 - 70) / (10 / 5)  # = 2.0
reject = abs(z_obs) > z_crit
print(f"临界值 z_{{0.025}} = {z_crit:.4f}")
print(f"观测统计量 z = {z_obs}")
print(f"拒绝 H0: {reject}")

运行后输出 拒绝 H0: True，与手算结论一致。调整 $\alpha$ 或样本量 $n$，可观察拒绝域与检验结论的变化规律。
