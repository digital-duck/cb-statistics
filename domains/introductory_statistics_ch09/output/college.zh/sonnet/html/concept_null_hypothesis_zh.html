零假设

定义。 设统计检验的目标是判断某一总体参数 $\theta$ 是否具有特定性质。零假设（null hypothesis），记作 $H_0$，是研究者在检验开始前预设的"无效应"或"无差异"命题。与之对立的命题称为备择假设（alternative hypothesis），记作 $H_1$。形式上，假设检验可表示为：

$$H_0: \theta = \theta_0 \quad \text{对立于} \quad H_1: \theta \neq \theta_0$$

其中 $\theta_0$ 为某一确定值。零假设的核心作用在于提供一个可以计算检验统计量概率分布的参照基准。检验的逻辑是：假定 $H_0$ 为真，若观测数据极为罕见，则以显著性水平 $\alpha$（通常取 $0.05$）拒绝 $H_0$。

具体示例。 某制药公司声称其新药可将患者的收缩压降低均值 $\mu$。研究者对 $n = 40$ 名患者测量降压效果，得样本均值 $\bar{x} = 8.2\ \text{mmHg}$，样本标准差 $s = 3.5\ \text{mmHg}$。设零假设为药物无效：

$$H_0: \mu = 0 \quad \text{对立于} \quad H_1: \mu > 0$$

检验统计量为单样本 $t$ 统计量：

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} = \frac{8.2 - 0}{3.5 / \sqrt{40}} \approx 14.83$$

在自由度 $df = 39$ 的 $t$ 分布下，$p$ 值极小，远小于 $\alpha = 0.05$，故拒绝 $H_0$，认为药物具有显著降压效果。

关键定理（奈曼–皮尔逊引理）。 对于简单假设 $H_0: \theta = \theta_0$ 与 $H_1: \theta = \theta_1$，基于似然比

$$\Lambda = \frac{L(\theta_1 \mid \mathbf{x})}{L(\theta_0 \mid \mathbf{x})}$$

构造的检验是在显著性水平 $\alpha$ 下功效（power）最大的检验，称为最优势检验（uniformly most powerful test）。

实验单元（SymPy）。

from scipy import stats
import numpy as np

x_bar, mu0, s, n = 8.2, 0, 3.5, 40
t_stat = (x_bar - mu0) / (s / np.sqrt(n))
p_value = 1 - stats.t.cdf(t_stat, df=n-1)
print(f"t = {t_stat:.4f}, p 值 = {p_value:.6f}")
# 拒绝 H₀ 当 p 值 < 0.05
