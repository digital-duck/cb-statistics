Significance Level

Definition. Let $H_0$ denote a null hypothesis and $T$ a test statistic whose distribution under $H_0$ is known. The significance level (or size) of a hypothesis test is the pre-specified probability

$$\alpha = P(\text{reject } H_0 \mid H_0 \text{ is true}),$$

representing the maximum tolerable probability of a Type I error — incorrectly rejecting a true null hypothesis. Common choices are $\alpha \in \{0.10,\, 0.05,\, 0.01\}$. The significance level is chosen before observing data; it defines the rejection region $\mathcal{R}$ such that $P(T \in \mathcal{R} \mid H_0) \leq \alpha$.

Worked Example. A quality engineer tests whether the mean fill volume $\mu$ of a bottling line equals 500 mL. She sets $\alpha = 0.05$ and collects a sample of $n = 36$ bottles, obtaining $\bar{x} = 497.2$ mL with known population standard deviation $\sigma = 9$ mL. Under $H_0: \mu = 500$, the test statistic is

$$Z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} = \frac{497.2 - 500}{9/\sqrt{36}} = \frac{-2.8}{1.5} \approx -1.867.$$

For a two-tailed test at $\alpha = 0.05$, the rejection region is $|Z| > z_{0.025} = 1.960$. Since $|-1.867| = 1.867 < 1.960$, she fails to reject $H_0$. Had she chosen $\alpha = 0.10$ instead, the critical value would be $z_{0.05} = 1.645$, and the same data would lead to rejection — illustrating that the choice of $\alpha$ directly controls the decision boundary.

Key Theorem (Neyman–Pearson, 1933). Among all tests of $H_0 : \theta = \theta_0$ against $H_1 : \theta = \theta_1$ with significance level $\alpha$, the likelihood ratio test

$$\Lambda = \frac{L(\theta_1 \mid \mathbf{x})}{L(\theta_0 \mid \mathbf{x})} > k_\alpha$$

is the most powerful test; that is, it minimises the Type II error probability $\beta$ for the given $\alpha$. This result justifies why $\alpha$ is fixed first: power is maximised subject to the Type I error constraint.

Lab Cell.

from scipy import stats

x_bar, mu0, sigma, n = 497.2, 500, 9, 36
alpha = 0.05

z_stat = (x_bar - mu0) / (sigma / n**0.5)
z_crit = stats.norm.ppf(1 - alpha / 2)          # two-tailed critical value
p_value = 2 * (1 - stats.norm.cdf(abs(z_stat)))

print(f"Z = {z_stat:.3f},  z_crit = ±{z_crit:.3f},  p = {p_value:.4f}")
print("Reject H₀" if abs(z_stat) > z_crit else "Fail to reject H₀")
