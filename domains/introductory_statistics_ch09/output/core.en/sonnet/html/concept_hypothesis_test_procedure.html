Hypothesis Test Procedure

Definition. A hypothesis test is a formal decision rule that combines the null hypothesis $H_0$, the alternative hypothesis $H_1$, a test statistic $T$, a significance level $\alpha$, and the resulting $p$-value — all treated as previously established primitives — into a single binary verdict: reject $H_0$ or fail to reject it. Concretely, the procedure partitions the sample space into a rejection region and its complement: $H_0$ is rejected if and only if $p < \alpha$, equivalently if and only if $|T|$ exceeds the critical value determined by $\alpha$ and the sampling distribution of $T$ under $H_0$.

Worked Example. A manufacturer claims that the mean tensile strength of a cable is $\mu_0 = 500\,\text{N}$. A quality-control engineer collects $n = 25$ measurements, obtaining $\bar{x} = 487\,\text{N}$ and sample standard deviation $s = 30\,\text{N}$. Setting $\alpha = 0.05$, the engineer formulates

$$H_0: \mu = 500 \qquad \text{vs.} \qquad H_1: \mu \neq 500.$$

The test statistic under $H_0$ follows a $t$-distribution with $n - 1 = 24$ degrees of freedom:

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} = \frac{487 - 500}{30 / \sqrt{25}} = \frac{-13}{6} \approx -2.167.$$

The two-sided critical value is $t_{0.025,\,24} \approx 2.064$. Since $|{-2.167}| > 2.064$, the engineer rejects $H_0$ and concludes there is statistically significant evidence that the true mean differs from $500\,\text{N}$.

Key Theorem (Neyman–Pearson Lemma). Among all tests of $H_0: \theta = \theta_0$ versus a simple alternative $H_1: \theta = \theta_1$ at level $\alpha$, the likelihood-ratio test — rejecting when $\Lambda = \mathcal{L}(\theta_1)/\mathcal{L}(\theta_0) > k_\alpha$ — maximizes power $1 - \beta$, where $\beta = P(\text{fail to reject } H_0 \mid H_1 \text{ true})$. This optimality result underpins the design of every standard test derived from likelihood theory.

Lab Cell (SymPy / SciPy).

from scipy import stats
import numpy as np

x_bar, mu_0, s, n = 487, 500, 30, 25
t_stat = (x_bar - mu_0) / (s / np.sqrt(n))
p_value = 2 * stats.t.sf(abs(t_stat), df=n - 1)
print(f"t = {t_stat:.3f},  p = {p_value:.4f}")
# t = -2.167,  p = 0.0404  → reject H₀ at α = 0.05
