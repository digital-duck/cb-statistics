Rare Event

Definition. Let $(\Omega, \mathcal{F}, \mathbb{P})$ be a probability space. An event $A \in \mathcal{F}$ is called a rare event if its probability satisfies $\mathbb{P}(A) = \varepsilon$ for some $\varepsilon \ll 1$. More precisely, in a parametric family of models indexed by $n$ (often a sample size or intensity parameter), we say $A_n$ is a rare event if $\mathbb{P}(A_n) \to 0$ as $n \to \infty$. The challenge rare events pose is not conceptual but computational: naive Monte Carlo estimation of $\mathbb{P}(A)$ requires on the order of $1/\varepsilon$ samples to observe even a single occurrence, rendering direct simulation prohibitively expensive when $\varepsilon$ is small.

Worked Example. Suppose a communication system transmits $n = 10{,}000$ independent bits, each flipped in error with probability $p = 0.0001$. Let $X \sim \text{Binomial}(n, p)$ be the number of errors. The event $A = \{X \geq 5\}$ represents a packet-level failure threshold. We have $\mu = np = 1$, so by the Poisson limit theorem, $X \approx \text{Poisson}(1)$. Thus

$$\mathbb{P}(A) = 1 - \mathbb{P}(X \leq 4) \approx 1 - e^{-1}\sum_{k=0}^{4} \frac{1}{k!} \approx 1 - 0.9963 = 0.0037.$$

This probability is small but not negligible over millions of daily transmissions, illustrating why rare events matter in reliability engineering.

Key Theorem (Cramér's Large Deviation Theorem). Let $X_1, X_2, \ldots$ be i.i.d. random variables with moment generating function $M(\theta) = \mathbb{E}[e^{\theta X}]$ finite in a neighbourhood of zero, and let $\bar{X}_n = n^{-1}\sum_{i=1}^n X_i$. For $a > \mathbb{E}[X]$,

$$\lim_{n \to \infty} \frac{1}{n} \log \mathbb{P}(\bar{X}_n \geq a) = -I(a),$$

where $I(a) = \sup_{\theta \geq 0}\{\theta a - \log M(\theta)\}$ is the Cramér rate function. This result quantifies the exponential decay of rare-event probabilities and underpins importance sampling methods that reduce simulation variance by tilting the sampling distribution toward the rare region.

from sympy import symbols, exp, log, diff, solve, N

theta, a = symbols('theta a', real=True, positive=True)
mu = 1  # Poisson(1) MGF: M(theta) = exp(exp(theta) - 1)
M = exp(exp(theta) - 1)
log_M = log(M)

# Rate function I(a) = sup_theta { theta*a - log M(theta) }
# First-order condition: a = M'(theta)/M(theta) = exp(theta)
theta_star = log(a)
I_a = theta_star * a - (exp(a) - 1)
print("Rate function I(a) =", I_a)
print("I(5) =", N(I_a.subs(a, 5), 4))  # exponential cost of X >= 5
