Decision Rule

Definition. A decision rule is a function $\delta: \mathcal{X} \to \mathcal{A}$ mapping every observable sample point $x \in \mathcal{X}$ to an action $a \in \mathcal{A}$, where $\mathcal{A}$ is the action space appropriate to the inferential task. In hypothesis testing, $\mathcal{A} = \{H_0, H_1\}$; in point estimation, $\mathcal{A} = \Theta$, the parameter space. The decision rule formalises the statistician's commitment: before data arrive, every possible outcome is assigned a response, leaving no room for post-hoc improvisation.

The quality of a decision rule is measured by its risk function

$$R(\theta, \delta) = \mathbb{E}_\theta\bigl[L(\theta, \delta(X))\bigr] = \int_{\mathcal{X}} L\bigl(\theta, \delta(x)\bigr)\, f(x;\theta)\, dx,$$

where $L(\theta, a)$ is the loss incurred when the true parameter is $\theta$ and action $a$ is taken. A rule $\delta^$ is admissible if no other rule $\delta'$ satisfies $R(\theta, \delta') \leq R(\theta, \delta^)$ for all $\theta$ with strict inequality for some $\theta$.

Worked Example. Suppose $X \sim \mathrm{Bernoulli}(\theta)$ and we observe a single realisation. Consider testing $H_0: \theta = 0.3$ against $H_1: \theta = 0.7$ under 0–1 loss ($L = 0$ for a correct decision, $L = 1$ for an error). The likelihood ratio is

$$\Lambda(x) = \frac{f(x; 0.7)}{f(x; 0.3)} = \left(\frac{7}{3}\right)^x \left(\frac{3}{7}\right)^{1-x}.$$

The Neyman–Pearson decision rule rejects $H_0$ when $\Lambda(x) > 1$, giving $\delta^(1) = H_1$ and $\delta^(0) = H_0$. The risk under $H_0$ is $R(0.3, \delta^) = P(X=1;\, 0.3) = 0.3$ (type-I error), and under $H_1$ it is $R(0.7, \delta^) = P(X=0;\, 0.7) = 0.3$ (type-II error).

Key Theorem (Neyman–Pearson Lemma). Among all decision rules with type-I error probability at most $\alpha$, the likelihood-ratio rule $\delta^ = \mathbf{1}\{\Lambda(x) > k_\alpha\}$ maximises the power $1 - \beta$. Consequently $\delta^$ is the uniformly most powerful test at level $\alpha$ for simple hypotheses.

Lab Cell.

from sympy import symbols, Rational, simplify

theta0, theta1, x = Rational(3,10), Rational(7,10), symbols('x', nonneg=True)
likelihood_ratio = (theta1**x * (1-theta1)**(1-x)) / (theta0**x * (1-theta0)**(1-x))
for val in [0, 1]:
    ratio = simplify(likelihood_ratio.subs(x, val))
    decision = "Reject H0" if ratio > 1 else "Fail to reject H0"
    print(f"x={val}: Λ={ratio}, Decision: {decision}")
