Tailed Tests

Definition. A tailed test specifies the direction of the alternative hypothesis in a statistical hypothesis test. Given a null hypothesis $H_0: \mu = \mu_0$, the analyst must choose among three formulations for the alternative:

  • Two-tailed: $H_1: \mu \neq \mu_0$ — deviations in either direction are of interest.
  • Left-tailed (lower-tailed): $H_1: \mu < \mu_0$ — only downward departures from $\mu_0$ are of interest.
  • Right-tailed (upper-tailed): $H_1: \mu > \mu_0$ — only upward departures are of interest.

    • The choice determines how the rejection region is allocated within the sampling distribution. For significance level $\alpha$, a two-tailed test places $\alpha/2$ in each tail, whereas a one-tailed test concentrates the full $\alpha$ in a single tail. The $p$-value is computed accordingly: for a test statistic $T$ with observed value $t_{\text{obs}}$, a right-tailed $p$-value is $P(T \geq t_{\text{obs}} \mid H_0)$, while the two-tailed $p$-value is $2\,P(T \geq |t_{\text{obs}}| \mid H_0)$ under a symmetric null distribution.

    Worked Example. A manufacturer claims that the mean tensile strength of a wire is $\mu_0 = 500\,\text{N}$. A quality-control engineer suspects the process has degraded, so she sets $H_1: \mu < 500$. From a sample of $n = 36$ wires she observes $\bar{x} = 492\,\text{N}$ with known population standard deviation $\sigma = 24\,\text{N}$. The test statistic is

    $$z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} = \frac{492 - 500}{24/\sqrt{36}} = \frac{-8}{4} = -2.00.$$

    For a left-tailed test at $\alpha = 0.05$, the critical value is $z_{0.05} = -1.645$. Since $-2.00 < -1.645$, the engineer rejects $H_0$ and concludes that mean strength has significantly decreased.

    Key Theorem (Tail Concentration). For fixed $\alpha$, a correctly directed one-tailed test yields a strictly smaller $p$-value than the corresponding two-tailed test whenever the observed departure aligns with $H_1$. Formally, if $t_{\text{obs}} < 0$ and $H_1: \mu < \mu_0$, then $p_{\text{left}} = p_{\text{two}}/2$. This follows because the one-tailed critical region concentrates the entire $\alpha$ in the direction of departure, whereas the two-tailed test allocates half of $\alpha$ to the non-informative tail, requiring a more extreme observation to achieve the same $p$-value.

    Lab Cell.

    from sympy.stats import Normal, P
from sympy import sqrt, N as Neval

mu0, xbar, sigma, n = 500, 492, 24, 36
se = sigma / sqrt(n)
Z = Normal('Z', 0, 1)
z_obs = (xbar - mu0) / se          # -2.0

p_left = Neval(P(Z <= z_obs))      # left-tailed p-value
p_two  = Neval(2 * P(Z <= z_obs))  # two-tailed p-value
print(f"z = {z_obs}, p (left) = {p_left:.4f}, p (two) = {p_two:.4f}")

    Running this cell confirms $p_{\text{left}} \approx 0.0228$ and $p_{\text{two}} \approx 0.0455$, both below $0.05$, with $p_{\text{left}}$ exactly half of $p_{\text{two}}$ — illustrating how tail selection directly governs evidential stringency.
