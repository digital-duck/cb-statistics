Cluster Sampling

Definition. Let a finite population $U = \{1, 2, \ldots, N\}$ be partitioned into $M$ mutually exclusive and exhaustive groups called clusters, $C_1, C_2, \ldots, C_M$, where cluster $C_i$ contains $N_i$ units and $\sum_{i=1}^{M} N_i = N$. In cluster sampling, a simple random sample of $m$ clusters is selected from the $M$ available clusters, and every unit within each selected cluster is observed. The sampling unit is therefore the cluster, not the individual element.

This design is distinguished from stratified sampling: in stratification, units are drawn from every stratum; in cluster sampling, only sampled clusters contribute observations.

Worked Example. A city has 200 census blocks (clusters). Each block contains approximately 50 households. A researcher cannot list all 10 000 households individually, so instead draws $m = 20$ blocks at random and surveys all households within those blocks, yielding roughly 1 000 observations. The per-interview travel cost falls sharply because interviewers work within a compact geographic area rather than crisscrossing the city.

Estimator and Variance. Let $y_i$ denote the total of the response variable over cluster $i$, and let $\bar{y}_c = \frac{1}{m}\sum_{i \in s} y_i$ be the sample mean of cluster totals. An unbiased estimator of the population total $Y = \sum_{i=1}^{M} y_i$ is

$$\hat{Y}_{\text{cl}} = M\bar{y}_c = \frac{M}{m}\sum_{i \in s} y_i.$$

Key Theorem (Variance of the Cluster Estimator). Under simple random sampling of clusters without replacement,

$$\operatorname{Var}(\hat{Y}_{\text{cl}}) = M^2 \left(1 - \frac{m}{M}\right) \frac{S_c^2}{m},$$

where $S_c^2 = \frac{1}{M-1}\sum_{i=1}^{M}(y_i - \bar{Y}_c)^2$ is the between-cluster variance of totals. The factor $(1 - m/M)$ is the finite-population correction. Efficiency relative to simple random sampling of individuals depends critically on the intraclass correlation coefficient $\rho$: when units within a cluster are homogeneous ($\rho \approx 1$), cluster sampling is far less precise than element sampling of the same size.

import numpy as np
from sympy import symbols, Rational, simplify

# Simulate cluster sampling
rng = np.random.default_rng(42)
M, m, cluster_size = 200, 20, 50
cluster_totals = rng.normal(loc=500, scale=80, size=M)   # y_i for each cluster
sampled = rng.choice(M, size=m, replace=False)

Y_hat = M * cluster_totals[sampled].mean()
S_c2  = cluster_totals.var(ddof=1)
var_hat = M**2 * (1 - m/M) * S_c2 / m

print(f"Estimated total : {Y_hat:,.1f}")
print(f"True total      : {cluster_totals.sum():,.1f}")
print(f"Estimated SE    : {var_hat**0.5:,.1f}")
