Systematic Sampling

Definition. Let $U = \{u_1, u_2, \ldots, u_N\}$ be a finite population of size $N$, and let $n$ be the desired sample size. Define the sampling interval $k = \lfloor N/n \rfloor$. A systematic sample is obtained by selecting a random start $r$ uniformly from $\{1, 2, \ldots, k\}$ and then drawing every $k$-th unit thereafter. The resulting sample is

$$S = \{u_r,\, u_{r+k},\, u_{r+2k},\, \ldots,\, u_{r+(n-1)k}\}.$$

Each element of $U$ belongs to exactly one of the $k$ possible equally spaced arrangements, and the probability that any given unit is selected equals $1/k = n/N$, matching the inclusion probability of simple random sampling without replacement.

Worked Example. A quality-control engineer inspects a production line that outputs $N = 100$ components per shift. She wishes to sample $n = 10$ components. The interval is $k = \lfloor 100/10 \rfloor = 10$. She draws $r \sim \text{Uniform}\{1,\ldots,10\}$ and obtains $r = 4$. The sample is therefore components numbered $4, 14, 24, 34, 44, 54, 64, 74, 84, 94$ — exactly $10$ units spread evenly across the shift.

Key Theorem (Unbiasedness). Let $y_i$ denote the value of the survey variable for unit $u_i$. The sample mean $\bar{y}_s = \frac{1}{n}\sum_{i \in S} y_i$ is an unbiased estimator of the population mean $\bar{Y} = \frac{1}{N}\sum_{i=1}^{N} y_i$:

$$\mathbb{E}[\bar{y}_s] = \frac{1}{k}\sum_{r=1}^{k} \bar{y}_{(r)} = \bar{Y},$$

where $\bar{y}_{(r)}$ is the mean of the sample arising from start $r$. Proof sketch: each of the $k$ equally likely starts contributes its sample mean with probability $1/k$; summing these $k$ means and dividing by $k$ recovers the arithmetic mean over all $N$ units. $\square$

Caution. Efficiency relative to simple random sampling depends on how variable the selected units are relative to the full population. If the population has a periodic trend with period $k$, systematic sampling can be severely biased because every selected unit falls on the same phase of the cycle.

# Lab cell — draw a systematic sample with SymPy / Python
import random
from sympy import Rational

N, n = 100, 10
k = N // n
r = random.randint(1, k)          # random start in {1,...,k}
sample_indices = [r + j * k for j in range(n)]

# Verify inclusion probability equals n/N
inclusion_prob = Rational(1, k)
assert inclusion_prob == Rational(n, N)

print(f"Random start r = {r}")
print(f"Sample indices : {sample_indices}")
print(f"Inclusion probability : {inclusion_prob} = {float(inclusion_prob):.2f}")
