Concept Book: Frequency Table

Introductory Statistics Ch01 · Generated by SPL

Payoff

A frequency table is the first act of making data speak. Given a finite collection of observations $x_1, x_2, \ldots, x_n$ drawn from a categorical or discretized domain $\mathcal{X}$, the frequency table records, for each distinct value $v \in \mathcal{X}$, the absolute count $f(v) = |\{i : x_i = v\}|$ and the relative frequency $\hat{p}(v) = f(v)/n$. Together these entries constitute an empirical probability mass function: a complete, lossless summary of which values appeared and how often. No information about category membership is discarded; the table is, in a precise sense, a sufficient statistic for any inference about the categorical distribution that generated the data.

Worked example. Suppose a teaching assistant records the letter grades of 40 students: A appears 8 times, B appears 14 times, C appears 12 times, D appears 4 times, and F appears 2 times. The relative frequencies are $\hat{p}(\text{A}) = 0.20$, $\hat{p}(\text{B}) = 0.35$, $\hat{p}(\text{C}) = 0.30$, $\hat{p}(\text{D}) = 0.10$, $\hat{p}(\text{F}) = 0.05$. Observe that $\sum_{v} \hat{p}(v) = 1$, confirming the normalization axiom. The mode is B, the empirical median falls in C, and one may immediately read off that the upper two grades account for $55\%$ of the cohort — facts invisible in the raw list.

Key theorem (Glivenko–Cantelli, categorical form). Let $X_1, X_2, \ldots$ be i.i.d. with true distribution $p$ on a finite alphabet $\mathcal{X}$. Define $\hat{p}_n(v) = n^{-1}\sum_{i=1}^n \mathbf{1}[X_i = v]$. Then $\max_{v \in \mathcal{X}} |\hat{p}_n(v) - p(v)| \xrightarrow{\text{a.s.}} 0$ as $n \to \infty$. The frequency table converges uniformly to the true distribution; it is not merely descriptive but asymptotically faithful.

import sympy as sp
from sympy.stats import DiscreteUniform, density, sample

# Simulate and tabulate
import random
grades = random.choices(['A','B','C','D','F'], weights=[8,14,12,4,2], k=40)
counts = {g: grades.count(g) for g in ['A','B','C','D','F']}
rel    = {g: sp.Rational(counts[g], 40) for g in counts}
print(counts)   # absolute frequencies
print(rel)      # exact rational relative frequencies

This is why the frequency table is the natural endpoint of categorical data analysis: it transforms an unstructured list into a normalized, computationally tractable representation from which every downstream quantity — entropy, chi-squared statistics, bar charts, Bayesian priors — is a deterministic function.

Connection to data collection design. The moment you commit to measuring a variable, you implicitly commit to the frequency table you will build from it. The choice of categories determines the table's rows; the sample size $n$ governs the precision of each $\hat{p}(v)$ via the standard error $\sqrt{\hat{p}(v)(1-\hat{p}(v))/n}$. Designing a data-collection instrument — a survey, a sensor log, a clinical intake form — therefore means pre-specifying the frequency table's structure before a single observation is recorded. Category granularity, response scale, and stratification strategy are all decisions about the table you intend to fill. Seen this way, data collection design is the inverse problem: given the frequency table you need, what instrument produces it with minimum cost and maximum statistical power?

The frequency table thus stands at the intersection of description and design. If you wish to go deeper, consider the application of data collection design in full: how power analysis, stratified sampling, and instrument validation conspire to guarantee that the table you observe is the table you planned for — and what goes wrong when they do not.
