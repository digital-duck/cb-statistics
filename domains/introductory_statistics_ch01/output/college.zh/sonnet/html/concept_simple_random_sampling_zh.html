Simple Random Sampling

定义

设总体 $\mathcal{U}$ 由 $N$ 个可区分的个体组成，记为 $\mathcal{U} = \{u_1, u_2, \ldots, u_N\}$。简单随机抽样（Simple Random Sampling，SRS）是指从 $\mathcal{U}$ 中抽取大小为 $n$ 的子集 $\mathcal{S}$，使得 $\mathcal{U}$ 的每一个大小为 $n$ 的子集被选中的概率相等，即

$$ P(\mathcal{S}) = \frac{1}{\dbinom{N}{n}}, \quad \forall\, \mathcal{S} \subseteq \mathcal{U},\; |\mathcal{S}| = n. $$

该定义等价于：每个个体被纳入样本的（边际）概率为 $\pi_i = n/N$，且任意两个个体同时入样的概率为 $\pi_{ij} = n(n-1)/[N(N-1)]$。

具体示例

设某班级共有 $N = 50$ 名学生，期末成绩记为 $y_1, y_2, \ldots, y_{50}$。现用简单随机抽样（不放回）抽取 $n = 5$ 名学生进行访谈。

总体均值的无偏估计量为样本均值

$$ \bar{y} = \frac{1}{n}\sum_{i \in \mathcal{S}} y_i. $$

若抽得成绩为 $\{72, 85, 90, 68, 79\}$，则 $\bar{y} = (72+85+90+68+79)/5 = 78.8$，即对总体平均分的估计值为 $78.8$ 分。

核心定理

定理（Horvitz–Thompson 估计量的无偏性） 在简单随机抽样下，$\bar{y}$ 是总体均值 $\mu = N^{-1}\sum_{i=1}^N y_i$ 的无偏估计量，且其方差为

$$ \operatorname{Var}(\bar{y}) = \frac{S^2}{n}\left(1 - \frac{n}{N}\right), $$

其中 $S^2 = \frac{1}{N-1}\sum_{i=1}^{N}(y_i - \mu)^2$ 为总体方差，因子 $(1 - n/N)$ 称为有限总体修正（Finite Population Correction，FPC）。

证明思路：利用指示变量 $I_i \in \{0,1\}$ 表示个体 $i$ 是否入样，由 $E[I_i]=\pi_i = n/N$ 直接得到无偏性；方差计算则借助 $\operatorname{Cov}(I_i, I_j) = \pi_{ij} - \pi_i\pi_j$ 展开后化简。$\blacksquare$

实验：SymPy 模拟

import random, statistics

N = 50
population = list(range(60, 101))[:N]          # 构造总体
n = 5
sample = random.sample(population, n)          # 简单随机抽样（不放回）

y_bar = statistics.mean(sample)
mu    = statistics.mean(population)
S2    = statistics.variance(population)
var_ybar = (S2 / n) * (1 - n / N)

print(f"样本均值 ȳ = {y_bar:.2f}")
print(f"总体均值 μ = {mu:.2f}")
print(f"理论方差 Var(ȳ) = {var_ybar:.4f}")

运行上述单元格，可直观验证 $\bar{y}$ 在重复抽样中集中于 $\mu$ 附近，且采样方差随 $n$ 增大而收缩，有限总体修正在 $n/N$ 较大时不可忽略。
