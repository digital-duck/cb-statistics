频率分布表

定义。 设 $X$ 为一个离散随机变量，其样本空间为 $\Omega = \{x_1, x_2, \ldots, x_k\}$。给定容量为 $n$ 的观测样本 $\{x^{(1)}, x^{(2)}, \ldots, x^{(n)}\}$，定义第 $i$ 个取值的绝对频数为

$$ f_i = \#\{j : x^{(j)} = x_i\}, \quad i = 1, 2, \ldots, k, $$

相应的相对频率（归一化频率）为

$$ \hat{p}_i = \frac{f_i}{n}. $$

频率分布表是将所有取值 $x_i$、对应绝对频数 $f_i$ 及相对频率 $\hat{p}_i$ 排列成表格的统计工具，满足约束条件 $\sum_{i=1}^{k} f_i = n$ 以及 $\sum_{i=1}^{k} \hat{p}_i = 1$。

例题。 某班 $20$ 名学生期末成绩等级如下：

$$ \text{A, B, B, C, A, B, C, A, D, B, C, B, A, C, B, A, B, C, D, B} $$

逐一统计各等级出现次数，得到下表：

| 等级 $x_i$ | 频数 $f_i$ | 相对频率 $\hat{p}_i$ | |:-----------:|:----------:|:--------------------:| | A | 5 | $0.25$ | | B | 8 | $0.40$ | | C | 5 | $0.25$ | | D | 2 | $0.10$ | | 合计 | 20 | 1.00 |

由表可见，等级 B 的相对频率最高，为 $0.40$，因此 B 为该样本的众数（mode）。

基本定理（大数定律的频率解释）。 设 $X$ 服从分布律 $P(X = x_i) = p_i$。当样本容量 $n \to \infty$ 时，相对频率依概率收敛于真实概率：

$$ \hat{p}_i \xrightarrow{\,P\,} p_i, \quad \forall\, i. $$

此定理保证了以频率分布表估计总体概率分布的合理性——样本量越大，估计越精确。

实验单元（SymPy）。

from sympy import *
from collections import Counter

grades = ['A','B','B','C','A','B','C','A','D','B',
          'C','B','A','C','B','A','B','C','D','B']

n = len(grades)
counts = Counter(grades)

print(f"{'等级':^6} {'频数':^6} {'相对频率':^10}")
for g in sorted(counts):
    fi = counts[g]
    pi = Rational(fi, n)          # 精确有理数
    print(f"{g:^6} {fi:^6} {pi!s:^10}")

运行输出将以精确有理数（如 $\tfrac{2}{5}$）呈现相对频率，避免浮点舍入误差，体现符号计算的优势。
