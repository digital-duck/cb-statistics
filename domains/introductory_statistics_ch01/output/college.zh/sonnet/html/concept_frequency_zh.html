频率

定义

设随机试验 $E$ 在相同条件下重复进行 $n$ 次，事件 $A$ 发生的次数称为频数，记为 $n(A)$。比值

$$f_n\!\left(\bigcup_{i=1}^{k} A_i\right) = \sum_{i=1}^{k} f_n(A_i).$$ $$f_{1000}(A) = \frac{513}{1000} = 0.513.$$ $$\lim_{n \to \infty} P\!\left(\left|f_n(A) - p\right| \ge \varepsilon\right) = 0.$$ $$P\!\left(\left|f_n(A) - p\right| \ge \varepsilon\right) \le \frac{p(1-p)}{n\varepsilon^2} \xrightarrow{n\to\infty} 0.$$ 
import random, sympy as sp

def freq_simulation(p, n):
    count = sum(1 for _ in range(n) if random.random() < p)
    return sp.Rational(count, n)

# 投掷硬币 p=1/2，观察频率随 n 增大趋近 1/2
for n in [10, 100, 1000, 10000]:
    print(f"n={n:>6},  频率 = {float(freq_simulation(0.5, n)):.4f}")
