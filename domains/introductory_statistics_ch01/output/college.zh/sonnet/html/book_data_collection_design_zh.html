数据收集设计（data collection design）是本教材所有先修概念的自然汇聚点。在此之前，我们学习了随机变量、期望与方差、概率分布、假设检验，以及估计理论——这些工具各自解决局部问题。数据收集设计则将它们统一为一个决策框架：在实验开始之前，以数学方式确定"收集什么数据、用多少样本、按何种结构安排"，从而使后续推断在统计效力与资源约束之间达到最优平衡。

核心定义：设待估参数为 $\theta$，估计量 $\hat{\theta}$ 的均方误差为

$$\mathrm{MSE}(\hat{\theta}) = \mathrm{Var}(\hat{\theta}) + \bigl(\mathrm{Bias}(\hat{\theta})\bigr)^2.$$

数据收集设计的目标是，在样本规模 $n \leq N_{\max}$ 与预算 $C \leq C_{\max}$ 的双重约束下，选择抽样方案 $\mathcal{D}^*$ 使 $\mathrm{MSE}(\hat{\theta})$ 最小。

具体例子：某教育机构希望估计全市高一学生的平均数学成绩 $\mu$。若采用简单随机抽样，方差为 $\sigma^2/n$；若改用按学校规模加权的分层抽样，方差降至 $\sum_h (W_h^2 \sigma_h^2 / n_h)$，其中 $W_h$ 为第 $h$ 层权重。通过最优分配公式 $n_h \propto W_h \sigma_h$，在相同样本量下估计精度可提升 $30\%$ 以上。这一收益不来自事后统计技巧，而来自事前的结构设计。

关键定理（Neyman 最优分配）：在分层抽样中，令各层样本量满足

$$n_h = n \cdot \frac{W_h \sigma_h}{\sum_{k} W_k \sigma_k},$$

则分层估计量的方差在固定总样本量 $n$ 下达到全局最小值。

SymPy 实验单元：

from sympy import symbols, Rational, sqrt, simplify

W1, W2, s1, s2, n = symbols('W1 W2 sigma1 sigma2 n', positive=True)
# Neyman 分配下的分层方差
n1 = n * W1*s1 / (W1*s1 + W2*s2)
n2 = n * W2*s2 / (W1*s1 + W2*s2)
V_strat = simplify(W1**2 * s1**2 / n1 + W2**2 * s2**2 / n2)
print(V_strat)  # 验证化简结果

数据收集设计并非终点，而是通向具体领域的入口：它为临床试验的伦理约束提供样本量依据，为社会调查的代表性提供层次保证，为工业质检的抽样频率提供理论支撑。
