分层抽样

定义． 设总体 $\Omega$ 可划分为 $k$ 个互不相交的子集（称为层）$\Omega_1, \Omega_2, \ldots, \Omega_k$，满足

$$\Omega = \bigcup_{i=1}^{k} \Omega_i, \qquad \Omega_i \cap \Omega_j = \emptyset \; (i \neq j).$$

若第 $i$ 层的规模为 $N_i$，总体规模为 $N = \sum_{i=1}^{k} N_i$，则比例分层抽样要求从第 $i$ 层抽取

$$n_i = n \cdot \frac{N_i}{N}$$

个样本，其中 $n = \sum_{i=1}^{k} n_i$ 为总样本量。总体均值的无偏估计量为

$$\hat{\mu}_{\text{st}} = \sum_{i=1}^{k} W_i \bar{X}_i, \qquad W_i = \frac{N_i}{N},$$

其中 $\bar{X}_i$ 为第 $i$ 层的样本均值。

例题． 某校共有学生 $N = 1000$ 人，分为三个年级：一年级 $N_1 = 400$，二年级 $N_2 = 350$，三年级 $N_3 = 250$。现需抽取 $n = 100$ 人调查每周学习时长。按比例分层，各层应抽取人数为

$$n_1 = 100 \times \frac{400}{1000} = 40, \quad n_2 = 35, \quad n_3 = 25.$$

若三层样本均值分别为 $\bar{X}_1 = 12$、$\bar{X}_2 = 15$、$\bar{X}_3 = 18$（小时/周），则总体均值估计为

$$\hat{\mu}_{\text{st}} = 0.4 \times 12 + 0.35 \times 15 + 0.25 \times 18 = 4.8 + 5.25 + 4.5 = 14.55 \text{ 小时/周}.$$

关键定理（方差缩减）． 设各层内方差为 $\sigma_i^2$，则分层估计量的方差为

$$\operatorname{Var}(\hat{\mu}_{\text{st}}) = \sum_{i=1}^{k} W_i^2 \frac{\sigma_i^2}{n_i}.$$

可以证明，只要各层均值之间存在差异，即 $\bar{X}_i$ 不全相等，则

$$\operatorname{Var}(\hat{\mu}_{\text{st}}) \leq \operatorname{Var}(\hat{\mu}_{\text{SRS}}),$$

其中 $\hat{\mu}_{\text{SRS}}$ 为等规模简单随机抽样的均值估计量。层间差异越大，方差缩减越显著。

实验单元（SymPy）．

from sympy import Rational, symbols, simplify

W1, W2, W3 = Rational(4,10), Rational(35,100), Rational(25,100)
mu1, mu2, mu3 = 12, 15, 18

mu_st = W1*mu1 + W2*mu2 + W3*mu3
print("总体均值估计：", mu_st)   # 输出 14.55

sig1, sig2, sig3 = 4, 3, 5      # 各层标准差（假设）
n1, n2, n3 = 40, 35, 25
var_st = W1**2*(sig1**2/n1) + W2**2*(sig2**2/n2) + W3**2*(sig3**2/n3)
print("分层抽样方差：", float(var_st))
