Concept Book: Randomized Experiment

Introductory Statistics Ch01 · Generated by SPL

收益

随机化实验（Randomized Experiment）是统计推断体系的自然终点。在整个概念链条中，我们从基本概率空间出发，历经期望值、方差、假设检验与因果推断，最终抵达这一方法论核心：通过将处理（Treatment）随机分配给研究单元，系统地切断混淆变量（Confounders）对因果估计的干扰，从而使观测到的差异能够被合理归因于处理本身。

定义：设总体单元集合为 $\mathcal{U} = \{u_1, u_2, \ldots, u_N\}$，处理变量 $T \in \{0, 1\}$。若分配机制满足

$$\Pr(T_i = 1 \mid X_1, X_2, \ldots, X_N) = \pi \in (0,1), \quad \forall\, i,$$

其中 $X_i$ 为任意预处理协变量，则称此分配为完全随机化。由此，平均处理效应（ATE）的无偏估计量为

$$\hat{\tau} = \bar{Y}^{(1)} - \bar{Y}^{(0)},$$

其中 $\bar{Y}^{(1)},\,\bar{Y}^{(0)}$ 分别为处理组与对照组的样本均值。

实例：某教育研究将 $n=200$ 名学生以等概率随机分配至两组——实验组接受新型互动教学法，对照组延续传统讲授。期末成绩显示实验组均值 $\bar{Y}^{(1)} = 82.4$，对照组 $\bar{Y}^{(0)} = 76.1$，则 $\hat{\tau} = 6.3$ 分。由于随机化保证了两组在智力水平、家庭背景等变量上的期望可比性，此差值可被解读为教学法本身的因果效应，而非选择偏差（Selection Bias）的产物。

关键定理（随机化无偏性）：在完全随机化设计下，$\mathbb{E}[\hat{\tau}] = \tau$，即 $\hat{\tau}$ 为 ATE 的无偏估计量，证明仅需条件期望的可交换性与独立性，无须对潜在结果分布作任何参数假设。

实验室单元（SymPy 验证）：

import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
scores_treat = rng.normal(82.4, 10, 100)
scores_ctrl  = rng.normal(76.1, 10, 100)
tau_hat = scores_treat.mean() - scores_ctrl.mean()
t_stat, p_val = stats.ttest_ind(scores_treat, scores_ctrl)
print(f"τ̂ = {tau_hat:.2f}, p = {p_val:.4f}")

通往研究伦理与机构审查委员会（IRB）：随机化实验的威力使其成为医学、心理学与社会科学的黄金标准，而正是这种威力本身催生了严格的伦理约束。机构审查委员会（Institutional Review Board，IRB）的存在，正是为了在科学效力与研究对象权益之间维持平衡。每一项随机化实验在启动之前，都必须通过知情同意、最小化伤害、公平受益分配三重伦理审核。理解随机化实验的统计逻辑，是理解为何这些约束不可或缺的前提。
