Concept Book: Frequency Table

Introductory Statistics Ch01 · Generated by SPL

Payoff

Throughout this chapter we have built, layer by layer, the machinery required to summarize a categorical or discretized dataset: we counted occurrences, normalized those counts into relative frequencies, and organized the results into a structured tabular form. The frequency table is the natural endpoint of this construction because it is the minimal lossless summary of a finite sample with respect to category membership. More precisely, given a sample $x_1, x_2, \ldots, x_n$ drawn from a finite alphabet $\mathcal{A} = \{a_1, \ldots, a_k\}$, the frequency table is the function

$$f : \mathcal{A} \to \mathbb{Z}_{\geq 0}, \quad f(a_j) = \left|\{i : x_i = a_j\}\right|,$$

together with its normalization $\hat{p}(a_j) = f(a_j)/n$, which serves as the empirical estimator of the true probability $P(X = a_j)$. No further compression of the original sample is possible without discarding information about how often each category appears; no richer object is needed to answer any question that depends only on marginal counts.

Worked example. Suppose $n = 40$ survey respondents are asked to choose a preferred study time: Morning (M), Afternoon (A), or Evening (E). The raw sequence contains 12 M's, 18 A's, and 10 E's. The frequency table records $f(\text{M}) = 12$, $f(\text{A}) = 18$, $f(\text{E}) = 10$, with relative frequencies $\hat{p}(\text{M}) = 0.30$, $\hat{p}(\text{A}) = 0.45$, $\hat{p}(\text{E}) = 0.25$. From this table alone one can compute the sample mode (Afternoon), test goodness-of-fit against a uniform prior, or estimate the probability that a randomly selected future respondent prefers mornings.

Key theorem (Glivenko–Cantelli, finite alphabet). Let $\hat{p}_n$ be the empirical distribution derived from $n$ i.i.d. draws from distribution $P$ over $\mathcal{A}$. Then

$$\max_{a \in \mathcal{A}} \left|\hat{p}_n(a) - P(a)\right| \xrightarrow{\text{a.s.}} 0 \quad \text{as } n \to \infty.$$

This guarantees that the frequency table converges uniformly to the true distribution, making it a statistically principled foundation for inference.

Connection to data collection design. The frequency table does more than summarize data already in hand — it dictates how data should be gathered in the first place. Knowing the target categories and their expected relative frequencies allows a designer to compute the minimum sample size $n$ required to achieve a desired margin of error $\varepsilon$ at confidence level $1 - \alpha$, via

$$n \geq \frac{z_{\alpha/2}^2 \, \hat{p}(1-\hat{p})}{\varepsilon^2},$$

where $\hat{p}$ denotes the most conservative or pilot-estimated proportion. Without a frequency table as a target object, the notion of "enough data" lacks formal meaning.

from sympy import *
p, n, eps, z = symbols('p n epsilon z', positive=True)
n_min = ceiling(z**2 * p * (1 - p) / eps**2)
display(n_min.subs({z: 1.96, p: Rational(1,2), eps: Rational(1,20)}))

You now hold every piece needed to design a rigorous study from scratch. The natural next step is to follow the frequency table into the full discipline of data collection design — where you will choose stratification schemes, set sample-size budgets, and guard against systematic bias — and see how the humble count becomes the backbone of reproducible empirical science.
