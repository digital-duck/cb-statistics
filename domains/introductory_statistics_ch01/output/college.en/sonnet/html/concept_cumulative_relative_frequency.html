Cumulative Relative Frequency

Definition. Let $x_1 < x_2 < \cdots < x_k$ be the distinct values of a discrete dataset of size $n$, with absolute frequency $f_i$ denoting the number of times $x_i$ appears. The relative frequency of $x_i$ is $r_i = f_i / n$. The cumulative relative frequency at $x_j$ is the proportion of observations that are less than or equal to $x_j$:

$$F(x_j) = \sum_{i=1}^{j} r_i = \frac{1}{n}\sum_{i=1}^{j} f_i, \qquad j = 1, 2, \ldots, k.$$

By construction, $F(x_1) = r_1 > 0$ and $F(x_k) = 1$. The function $F$ is a step function that increases at each observed value and provides an empirical approximation to the population cumulative distribution function (CDF).

Worked Example. A quiz graded out of 5 was administered to 20 students, yielding the following score distribution:

| Score $x_i$ | Frequency $f_i$ | Relative freq. $r_i$ | Cumulative rel. freq. $F(x_i)$ | |:-----------:|:---------------:|:--------------------:|:-------------------------------:| | 2 | 2 | 0.10 | 0.10 | | 3 | 5 | 0.25 | 0.35 | | 4 | 8 | 0.40 | 0.75 | | 5 | 5 | 0.25 | 1.00 |

Reading the table: $F(4) = 0.75$ tells us that $75\%$ of students scored at most 4 out of 5. This is an immediately interpretable statement about standing within the distribution.

Key Theorem (Glivenko–Cantelli). Let $F_n$ denote the empirical cumulative relative frequency function built from $n$ independent observations drawn from a population with true CDF $F$. Then

$$\sup_{x \in \mathbb{R}} |F_n(x) - F(x)| \xrightarrow{\text{a.s.}} 0 \quad \text{as } n \to \infty.$$

This result guarantees that the step-function approximation converges uniformly and almost surely to the true CDF, providing the theoretical foundation for using cumulative relative frequencies in inferential statistics.

Lab Cell.

from sympy import Rational, pprint

scores     = [2, 3, 4, 5]
freqs      = [2, 5, 8, 5]
n          = sum(freqs)

rel_freq   = [Rational(f, n) for f in freqs]
cum_rel    = []
running    = Rational(0)
for r in rel_freq:
    running += r
    cum_rel.append(running)

for xi, fi, ri, Fi in zip(scores, freqs, rel_freq, cum_rel):
    print(f"x={xi}  f={fi}  r={ri}  F={Fi}")

Running this cell reproduces the table above with exact rational arithmetic, confirming that $F(5) = 1$ precisely.
