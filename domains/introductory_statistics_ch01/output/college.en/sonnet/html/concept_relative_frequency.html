Relative Frequency

Definition. Let $S$ be a sample space and suppose an experiment is repeated $n$ times under identical conditions. If an event $A$ occurs $k$ times among those $n$ trials, the relative frequency of $A$ is

$$f_n(A) = \frac{k}{n}, \qquad 0 \leq f_n(A) \leq 1.$$

Relative frequency is an empirical quantity: it depends on the specific sequence of outcomes observed, not on any theoretical model. As such, it provides the raw material from which probability estimates are constructed.

Worked Example. A quality-control engineer inspects a batch of 200 microchips and finds 14 defective units. The relative frequency of the event $D = \{\text{chip is defective}\}$ is

$$f_{200}(D) = \frac{14}{200} = 0.07.$$

If a second batch of 500 chips yields 33 defectives, then

$$f_{500}(D) = \frac{33}{500} = 0.066.$$

Neither value is the "true" defect probability; each is an estimate that improves as $n$ grows.

Key Theorem (Law of Large Numbers — informal statement). For any event $A$ with theoretical probability $P(A)$, and for any tolerance $\varepsilon > 0$,

$$\lim_{n \to \infty} P\!\bigl(|f_n(A) - P(A)| > \varepsilon\bigr) = 0.$$

In plain terms: as the number of trials grows without bound, the relative frequency converges in probability to the true probability. This theorem justifies using $f_n(A)$ as a practical estimate of $P(A)$ when theoretical values are unknown, and it underpins the frequentist interpretation of probability itself.

Two properties of relative frequency are immediate from the definition: (i) $f_n(S) = 1$ for every $n$, and (ii) if $A$ and $B$ are mutually exclusive, then $f_n(A \cup B) = f_n(A) + f_n(B)$. These mirror the Kolmogorov axioms, explaining why relative frequency feels like probability even before any limiting argument is invoked.

Lab Cell.

from sympy import Rational, N

trials      = 200          # total trials
occurrences = 14           # event count

rel_freq = Rational(occurrences, trials)
print("Exact relative frequency:", rel_freq)       # 7/100
print("Decimal approximation:   ", N(rel_freq, 6)) # 0.0700000

Running this cell confirms that SymPy preserves exact rational arithmetic, avoiding floating-point rounding errors that can silently distort empirical estimates in larger computations.
