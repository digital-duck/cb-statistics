What the Concept Achieves

A data collection design is a formal specification of the triple $(\Omega, \mathcal{F}, P_\theta)$ together with a sampling protocol $\pi$ that determines which units are observed, when, and under what conditions. Precisely, given a parameter space $\Theta$ and a loss function $L : \Theta \times \mathcal{A} \to \mathbb{R}$, a design $\xi$ is said to be optimal if it minimises the expected posterior risk

$$\xi^* = \arg\min_{\xi \in \Xi} \int_\Theta \int_{\mathcal{X}} L\!\left(\theta, \delta(x)\right) p(x \mid \theta, \xi)\, p(\theta)\, dx\, d\theta,$$

where $\delta : \mathcal{X} \to \mathcal{A}$ is a decision rule and $p(\theta)$ is the prior. The key insight is that the design $\xi$ enters the integral before data are seen: you are purchasing information at a cost, and optimal design theory tells you exactly how to spend that budget.

Worked Example

Suppose a student wishes to estimate the slope $\beta$ in the simple linear model $Y_i = \alpha + \beta x_i + \varepsilon_i$, $\varepsilon_i \sim \mathcal{N}(0, \sigma^2)$, using exactly $n = 10$ observations on $x \in [-1, 1]$. The variance of the ordinary least-squares estimator $\hat{\beta}$ is $\sigma^2 / \sum(x_i - \bar{x})^2$. This quantity is minimised when five observations are placed at $x = -1$ and five at $x = +1$, an instance of the D-optimal design. Any intermediate allocation inflates $\mathrm{Var}(\hat{\beta})$, meaning weaker inference for the same experimental cost.

Key Theorem (Equivalence Theorem, Kiefer–Wolfowitz 1960)

A continuous design measure $\xi^*$ is $D$-optimal for the linear model with information matrix $M(\xi)$ if and only if

$$d(x, \xi^*) = f(x)^\top M(\xi^*)^{-1} f(x) \leq p \quad \forall x \in \mathcal{X},$$

with equality at all support points of $\xi^*$. Here $p$ is the number of parameters and $f(x)$ is the regression vector. The theorem converts a global optimisation problem into a pointwise check, making optimal designs verifiable.

Lab Cell

from sympy import symbols, Matrix, simplify

x = symbols('x')
# Moment matrix for two-point design on {-1, +1} with equal weight
F = Matrix([[1, -1], [1, 1]])
M = (F.T * F) / 2
print("Information matrix M =", M)
print("det(M) =", simplify(M.det()))
print("Variance of beta-hat proportional to", simplify(M.inv()[1, 1]))

Invitation

Data collection design is the natural endpoint of this textbook because every earlier concept—probability spaces, estimators, hypothesis tests, regression—names a quantity that design theory then optimises. The machinery developed here unlocks a remarkable range of consequential problems: choosing sensor placements in a monitoring network, scheduling clinical-trial interim analyses, constructing stratified survey samples, and actively guiding machine-learning data pipelines so that each new label reduces model uncertainty as efficiently as possible. Each application obeys the same underlying principle: information has geometry, and a well-chosen design navigates that geometry deliberately rather than accidentally.

Of these directions, the most immediately accessible—and perhaps the most socially urgent—is survey sample design, where careful stratification and ratio estimation allow a small, affordable sample to speak reliably for a large and heterogeneous population. Turn to the next chapter to see how the tools assembled here combine into a complete survey workflow, from frame construction through variance estimation and public reporting.
