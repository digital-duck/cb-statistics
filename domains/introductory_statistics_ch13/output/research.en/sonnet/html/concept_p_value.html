P Value

Definition. Let $H_0$ be a null hypothesis and let $T$ be a test statistic computed from observed data. The p-value is the probability, assuming $H_0$ is true, of observing a value of $T$ at least as extreme as the value $t_{\text{obs}}$ actually obtained:

$$p = P(T \geq t_{\text{obs}} \mid H_0).$$

For a two-sided test the definition extends symmetrically:

$$p = P(|T| \geq |t_{\text{obs}}| \mid H_0).$$

The p-value is not the probability that $H_0$ is true; it is a measure of the compatibility between the observed data and the null hypothesis. A small p-value signals that the observed result would be unusual if $H_0$ held, not that $H_0$ is false with that probability.

Worked Example. A manufacturing process claims a mean fill volume of $\mu_0 = 500\,\text{mL}$. A quality inspector draws $n = 25$ bottles and records a sample mean $\bar{x} = 497\,\text{mL}$ with known population standard deviation $\sigma = 10\,\text{mL}$. Under $H_0: \mu = 500$, the test statistic is

$$Z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} = \frac{497 - 500}{10/5} = -1.5.$$

For a one-sided lower-tail test the p-value is $p = P(Z \leq -1.5) \approx 0.0668$. At significance level $\alpha = 0.05$ we fail to reject $H_0$, since $0.0668 > 0.05$. Had the sample mean been $495\,\text{mL}$, the statistic would be $Z = -2.5$ and $p \approx 0.0062 < 0.05$, leading to rejection.

Key Theorem (Uniformity under the null). If the distribution of $T$ is continuous and $H_0$ is exactly true, then the p-value $p$ is uniformly distributed on $[0,1]$. Formally, $P(p \leq u \mid H_0) = u$ for all $u \in [0,1]$. This property justifies the threshold rule: under $H_0$, false rejections occur with probability exactly $\alpha$ when the rule $\text{reject if } p \leq \alpha$ is applied, guaranteeing type-I error control.

Lab Cell.

from scipy import stats

mu_0, x_bar, sigma, n = 500, 497, 10, 25
z_stat = (x_bar - mu_0) / (sigma / n**0.5)
p_one  = stats.norm.cdf(z_stat)          # one-sided (lower tail)
p_two  = 2 * stats.norm.cdf(-abs(z_stat))  # two-sided

print(f"Z = {z_stat:.3f}")
print(f"p (one-sided) = {p_one:.4f}")
print(f"p (two-sided) = {p_two:.4f}")

Running this cell reproduces $Z = -1.5$, $p_{\text{one}} \approx 0.0668$, and $p_{\text{two}} \approx 0.1336$, confirming the hand calculation above.
