One Way Anova

单因素方差分析（One-Way ANOVA） 是一种统计方法，用于同时比较三个或更多组的均值是否存在显著差异。与多次使用 $t$ 检验相比，ANOVA 通过单次检验控制整体犯第一类错误的概率，避免因反复比较而虚增显著性。

其核心思想是将数据的总变异分解为两部分：组间变异（由各组均值差异引起）和组内变异（同一组内个体之间的随机误差）。若组间变异远大于组内变异，则说明至少有一对组的均值存在真实差异。

检验统计量为 $F$ 值：

$$F = \frac{MS_{\text{between}}}{MS_{\text{within}}} = \frac{SS_{\text{between}} / (k-1)}{SS_{\text{within}} / (N-k)}$$

其中 $k$ 为组数，$N$ 为总样本量，$SS$ 为平方和，$MS$ 为均方。$F$ 值服从自由度为 $(k-1,\, N-k)$ 的 $F$ 分布；若 $p < 0.05$，则拒绝所有组均值相等的零假设 $H_0: \mu_1 = \mu_2 = \cdots = \mu_k$。

工作示例：某教师想比较三种教学方法（传统讲授、小组讨论、翻转课堂）对期末成绩的影响，各组分别有 10 名学生。收集数据后，计算得到：

  • $SS_{\text{between}} = 420$，自由度 $= 2$，故 $MS_{\text{between}} = 210$
  • $SS_{\text{within}} = 810$，自由度 $= 27$，故 $MS_{\text{within}} = 30$
    • $$F = \frac{210}{30} = 7.0$$

    查 $F$ 分布表（$df_1=2,\, df_2=27$），$p \approx 0.003 < 0.05$，拒绝 $H_0$，说明三种方法的平均成绩存在显著差异。

    解题应用：ANOVA 只告诉我们"至少有两组不同"，但不指明哪两组。此时需进行事后检验（如 Tukey HSD），逐对比较均值。用 Python 实现如下：

    from scipy import stats
import scikit_posthocs as sp

# 三组成绩数据
trad   = [72, 68, 75, 70, 74, 69, 71, 73, 67, 76]
group  = [80, 85, 78, 83, 81, 79, 84, 82, 77, 86]
flip   = [88, 91, 85, 90, 87, 92, 89, 86, 93, 84]

F, p = stats.f_oneway(trad, group, flip)
print(f"F = {F:.2f}, p = {p:.4f}")
# 事后检验
print(sp.posthoc_tukey([trad, group, flip]))

    使用 ANOVA 时须满足三个前提：各组数据近似正态分布、各组方差齐性（可用 Levene 检验验证）、各观测值相互独立。满足这些条件后，ANOVA 是多组比较中最标准、最稳健的工具。
