Empirical Vs Theoretical Distribution Comparison

定义

设 $X_1, X_2, \ldots, X_n$ 为来自某未知总体的独立同分布随机样本。经验分布函数（empirical distribution function，EDF）定义为

$$F_n(x) = \frac{1}{n} \sum_{i=1}^{n} \mathbf{1}[X_i \leq x],$$

其中 $\mathbf{1}[\cdot]$ 为示性函数。$F_n(x)$ 是一个阶梯函数，在每个观测值处跳跃 $1/n$。理论分布函数（theoretical CDF）$F(x)$ 则由参数模型（如正态分布、泊松分布）完全确定。比较 $F_n$ 与 $F$ 是统计推断的核心任务之一。

例题

设观测样本为 $\{1.2,\ 2.4,\ 2.4,\ 3.1,\ 4.0\}$，假设理论模型为 $X \sim \mathcal{N}(\mu, \sigma^2)$，用矩估计得 $\hat{\mu} = 2.62$，$\hat{\sigma} = 1.01$。计算 $x = 2.4$ 处的比较：

$$F_5(2.4) = \frac{3}{5} = 0.60, \qquad F(2.4) = \Phi\!\left(\frac{2.4 - 2.62}{1.01}\right) \approx \Phi(-0.218) \approx 0.414.$$

两者偏差为 $|F_5(2.4) - F(2.4)| \approx 0.186$，提示在该点处经验分布与正态模型存在可观差距。

关键定理：Kolmogorov–Smirnov 统计量

定义 KS 统计量

$$D_n = \sup_{x \in \mathbb{R}} |F_n(x) - F(x)|.$$

Glivenko–Cantelli 定理保证，当 $n \to \infty$ 时，$D_n \xrightarrow{a.s.} 0$，即经验分布函数几乎必然一致收敛于真实 CDF。进一步，Kolmogorov 证明

$$\sqrt{n}\, D_n \xrightarrow{d} K,$$

其中 $K$ 为 Kolmogorov 分布。给定显著性水平 $\alpha$，若 $D_n > c_\alpha / \sqrt{n}$，则拒绝 $H_0: F = F_0$。

实验单元（SymPy / SciPy）

import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
sample = rng.normal(loc=0, scale=1, size=50)

# KS 检验：与标准正态比较
stat, p_value = stats.kstest(sample, 'norm', args=(0, 1))
print(f"D_n = {stat:.4f},  p 值 = {p_value:.4f}")

# 绘制 EDF 与理论 CDF
import matplotlib.pyplot as plt
x = np.linspace(-4, 4, 200)
plt.step(np.sort(sample), np.arange(1, 51)/50, label='$F_n(x)$')
plt.plot(x, stats.norm.cdf(x), label='$F(x)$')
plt.legend(); plt.title('经验分布与理论分布对比'); plt.show()

通过可视化与 KS 检验，学生可直观理解 $F_n$ 随样本量增大逐渐逼近 $F$ 的过程，并掌握假设检验的量化依据。
