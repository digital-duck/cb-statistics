收益

定义。 经验分布与理论分布的比较，是统计推断的核心操作：给定来自未知总体的样本 $x_1, x_2, \ldots, x_n$，我们构造经验累积分布函数

$$\hat{F}_n(t) = \frac{1}{n}\sum_{i=1}^{n} \mathbf{1}[x_i \leq t],$$

并将其与某一假设的理论分布 $F_0(t)$ 进行系统性对比。这一比较揭示数据究竟在多大程度上与理论模型相符，从而为接受、修正或拒绝该模型提供严格依据。

具体例子。 设 $n = 50$ 个观测值来自某未知总体，我们假设其服从标准正态分布 $\mathcal{N}(0,1)$。计算两者之间的最大偏差：

$$D_n = \sup_{t \in \mathbb{R}} \left| \hat{F}_n(t) - \Phi(t) \right|,$$

其中 $\Phi(t)$ 为标准正态累积分布函数。若 $D_{50} = 0.08$，查阅 Kolmogorov–Smirnov 临界值表，在显著性水平 $\alpha = 0.05$ 下临界值约为 $0.192$，因此我们不拒绝正态性假设。反之，若 $D_{50} = 0.25$，则以强有力证据拒绝该假设，提示数据来自重尾或偏斜分布。

核心定理（Glivenko–Cantelli 定理）。 对任意分布 $F$，有

$$\sup_{t} \left| \hat{F}_n(t) - F(t) \right| \xrightarrow{a.s.} 0, \quad n \to \infty.$$

此定理保证经验分布函数以概率一均匀收敛于真实分布，是所有拟合优度检验的理论根基。进一步，Kolmogorov–Smirnov 统计量 $\sqrt{n}\, D_n$ 在零假设成立时依分布收敛于 Kolmogorov 分布，使得 $p$ 值计算具有精确的渐近理论支撑。

实验室单元（SymPy / SciPy）。

import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
sample = rng.normal(loc=0, scale=1, size=50)

stat, p_value = stats.kstest(sample, 'norm', args=(0, 1))
print(f"KS 统计量 D = {stat:.4f}，p 值 = {p_value:.4f}")

这一能力解锁了广泛的应用领域：在金融风险管理中，用于验证收益率是否服从正态或学生 $t$ 分布，进而确定风险价值（VaR）的可靠性；在质量控制中，检验生产过程是否偏离规格分布，触发过程改进；在生物统计中，确认临床试验残差的分布假设，保证推断的有效性；在机器学习中，检测训练集与测试集之间的分布漂移，预警模型性能退化。

每一个领域的背后，都是同一个问题：数据所呈现的世界，与我们假设的模型，究竟相差多远？ 掌握经验分布与理论分布的比较，便掌握了回答这一问题的语言。

若要深入探索，不妨以金融收益率的尾部分布为切入点：真实市场数据的极端事件远比正态分布所预测的频繁，这正是重尾分布理论与极值统计学的起点。
