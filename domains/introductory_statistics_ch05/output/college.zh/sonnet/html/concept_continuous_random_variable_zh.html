Continuous Random Variable

定义。 设 $(\Omega, \mathcal{F}, P)$ 为概率空间。若随机变量 $X: \Omega \to \mathbb{R}$ 存在非负可积函数 $f_X: \mathbb{R} \to [0, +\infty)$，使得对任意 Borel 集 $B \subseteq \mathbb{R}$ 均有

$$P(X \in B) = \int_B f_X(x)\, dx,$$

则称 $X$ 为连续型随机变量，$f_X$ 称为其概率密度函数（probability density function，PDF）。$f_X$ 须满足归一化条件：

$$\int_{-\infty}^{+\infty} f_X(x)\, dx = 1.$$

值得注意的是，对任意单点 $c \in \mathbb{R}$，有 $P(X = c) = 0$，这与离散型随机变量有本质区别。

例题。 设 $X$ 服从区间 $[0, 3]$ 上的均匀分布，即

$$f_X(x) = \begin{cases} \dfrac{1}{3}, & 0 \le x \le 3, \\ 0, & \text{其他.} \end{cases}$$

求 $P(1 \le X \le 2)$。

解。

$$P(1 \le X \le 2) = \int_1^2 \frac{1}{3}\, dx = \frac{1}{3} \cdot (2 - 1) = \frac{1}{3}.$$

核心定理（累积分布函数的可微性）。 设 $X$ 为连续型随机变量，其累积分布函数（CDF）定义为

$$F_X(x) = P(X \le x) = \int_{-\infty}^{x} f_X(t)\, dt.$$

则 $F_X$ 在 $f_X$ 的连续点处可微，且

$$F_X'(x) = f_X(x).$$

证明要点。 由微积分基本定理，当 $f_X$ 在 $x$ 处连续时，

$$\frac{d}{dx} \int_{-\infty}^{x} f_X(t)\, dt = f_X(x). \qquad \square$$

该定理表明，PDF 与 CDF 互为微分–积分对，从而将概率计算转化为标准的定积分运算。

实验单元（SymPy）。

from sympy import symbols, integrate, Rational, Piecewise, oo

x = symbols('x')
f = Rational(1, 3)                         # 均匀分布密度

# 验证归一化
print(integrate(f, (x, 0, 3)))             # 输出 1

# 计算 P(1 ≤ X ≤ 2)
prob = integrate(f, (x, 1, 2))
print(prob)                                # 输出 1/3

# 构造 CDF
F = integrate(f, (x, 0, x))
print(F)                                   # 输出 x/3

运行上述代码，学生可直观验证归一化条件成立，并观察 CDF 在 $[0,3]$ 上以斜率 $\tfrac{1}{3}$ 线性递增至 $1$，加深对密度函数与分布函数关系的理解。
