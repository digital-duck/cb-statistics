Uniform Distribution

Definition. A continuous random variable $X$ is said to follow a uniform distribution on the interval $[a, b]$, written $X \sim \mathrm{Uniform}(a, b)$, if its probability density function (pdf) is constant over that interval:

$$f(x) = \begin{cases} \dfrac{1}{b - a} & a \le x \le b, \\ 0 & \text{otherwise.} \end{cases}$$

The defining characteristic is that every sub-interval of equal length within $[a, b]$ carries equal probability mass. The cumulative distribution function (cdf) is the piecewise linear function

$$F(x) = \begin{cases} 0 & x < a, \\ \dfrac{x - a}{b - a} & a \le x \le b, \\ 1 & x > b. \end{cases}$$

Worked Example. A bus arrives at a stop at a uniformly distributed time $X \sim \mathrm{Uniform}(0, 20)$ minutes past the hour. Find the probability that a passenger arriving exactly at the hour waits between 5 and 12 minutes.

$$P(5 \le X \le 12) = \int_{5}^{12} \frac{1}{20}\,dx = \frac{12 - 5}{20} = \frac{7}{20} = 0.35.$$

The length of the favorable sub-interval divided by the total interval length is the entire computation — a direct consequence of the constant density.

Key Theorem. If $X \sim \mathrm{Uniform}(a, b)$, then

$$\mathrm{E}[X] = \frac{a + b}{2}, \qquad \mathrm{Var}(X) = \frac{(b-a)^{2}}{12}.$$

Proof sketch. Compute $\mathrm{E}[X] = \int_a^b x \cdot \frac{1}{b-a}\,dx = \frac{1}{b-a}\cdot\frac{b^2 - a^2}{2} = \frac{a+b}{2}$. For the variance, evaluate $\mathrm{E}[X^2] = \frac{a^2 + ab + b^2}{3}$ and apply $\mathrm{Var}(X) = \mathrm{E}[X^2] - (\mathrm{E}[X])^2$, yielding $\frac{(b-a)^2}{12}$. $\square$

The uniform distribution also plays a foundational role in simulation: if $U \sim \mathrm{Uniform}(0,1)$, then $X = F^{-1}(U)$ generates a random variable with any target cdf $F$ — the inverse transform method.

Lab Cell (SymPy).

from sympy import symbols, integrate, Rational, simplify

x, a, b = symbols('x a b', real=True)
f = 1 / (b - a)

mean  = simplify(integrate(x * f, (x, a, b)))          # (a + b) / 2
var   = simplify(integrate(x**2 * f, (x, a, b)) - mean**2)  # (b - a)^2 / 12

print("E[X] =", mean)
print("Var(X) =", var)

# Numerical example: Uniform(0, 20), P(5 <= X <= 12)
prob = integrate(Rational(1, 20), (x, 5, 12))
print("P(5 ≤ X ≤ 12) =", prob)
