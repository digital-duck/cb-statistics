Probability Density Function

Definition. Let $X$ be a continuous random variable. A function $f : \mathbb{R} \to \mathbb{R}$ is called a probability density function (PDF) of $X$ if it satisfies two conditions:

  • $f(x) \geq 0$ for all $x \in \mathbb{R}$, and
  • $\displaystyle\int_{-\infty}^{\infty} f(x)\,dx = 1$.

    • The probability that $X$ takes a value in the interval $[a, b]$ is then given by

    $$P(a \leq X \leq b) = \int_a^b f(x)\,dx.$$

    Unlike a discrete probability mass function, $f(x)$ does not represent a probability directly — in particular, $f(x)$ may exceed 1. Rather, $f(x)\,dx$ represents the infinitesimal probability of $X$ falling in the interval $[x, x + dx]$.

    Worked Example. Consider the function

    $$f(x) = \begin{cases} \lambda e^{-\lambda x} & x \geq 0, \\ 0 & x < 0, \end{cases}$$

    where $\lambda > 0$. This is the PDF of the exponential distribution. Verify the normalization condition:

    $$\int_0^{\infty} \lambda e^{-\lambda x}\,dx = \lambda \cdot \left[-\frac{1}{\lambda}e^{-\lambda x}\right]_0^{\infty} = \lambda \cdot \frac{1}{\lambda} = 1. \checkmark$$

    The probability that $X \leq 2$ with $\lambda = 1$ is $\int_0^2 e^{-x}\,dx = 1 - e^{-2} \approx 0.865$.

    Theorem (Existence of the CDF). If $f$ is the PDF of $X$, the cumulative distribution function $F(x) = P(X \leq x)$ is given by

    $$F(x) = \int_{-\infty}^{x} f(t)\,dt.$$

    By the Fundamental Theorem of Calculus, $F$ is differentiable wherever $f$ is continuous, and $F'(x) = f(x)$. This relationship is the bridge between integration and probability: the PDF is the derivative of the CDF.

    Lab Cell.

    from sympy import symbols, exp, integrate, oo, plot

x, lam = symbols('x lambda', positive=True)
f = lam * exp(-lam * x)

# Verify normalization
print(integrate(f, (x, 0, oo)))          # → 1

# Compute P(X <= 2) for lambda = 1
print(integrate(f.subs(lam, 1), (x, 0, 2)))  # → 1 - exp(-2)

plot(f.subs(lam, 1), (x, 0, 6), ylabel='f(x)', title='Exponential PDF (λ=1)')
