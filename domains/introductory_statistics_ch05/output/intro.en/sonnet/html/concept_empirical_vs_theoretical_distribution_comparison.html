Empirical Vs Theoretical Distribution Comparison

Definition. A theoretical distribution is a probability model $F_\theta$ specified by a parametric family and fixed parameters $\theta$; it assigns exact probabilities to outcomes via a closed-form density or mass function. An empirical distribution is the data-driven counterpart: given $n$ independent observations $x_1, x_2, \ldots, x_n$, the empirical cumulative distribution function (ECDF) is

$$\hat{F}_n(x) = \frac{1}{n}\sum_{i=1}^{n} \mathbf{1}[x_i \leq x].$$

The ECDF is a step function that jumps by $1/n$ at each observed value. Comparing $\hat{F}_n$ to a theoretical $F_\theta$ quantifies how well the model captures the data.

Worked Example. Suppose we collect $n = 50$ waiting times (in minutes) at a service counter and hypothesise they follow an exponential distribution with rate $\lambda = 0.5$, so $F_\theta(x) = 1 - e^{-0.5x}$. Plot $\hat{F}_n(x)$ against $F_\theta(x)$ on the same axes. The maximum vertical gap

$$D_n = \sup_{x} |\hat{F}_n(x) - F_\theta(x)|$$

is the Kolmogorov–Smirnov statistic. A small $D_n$ (relative to a critical value) supports the exponential model; a large gap signals misfit. Visual inspection of the ECDF overlay immediately reveals whether the theoretical curve runs through the step-function staircase or systematically departs from it.

Key Theorem (Glivenko–Cantelli). If the observations are i.i.d. with true CDF $F$, then

$$\sup_{x} |\hat{F}_n(x) - F(x)| \xrightarrow{\text{a.s.}} 0 \quad \text{as } n \to \infty.$$

This guarantees that the ECDF converges uniformly to the true distribution; any persistent gap between $\hat{F}_n$ and a candidate $F_\theta$ therefore reflects genuine model misspecification rather than sampling noise.

Lab Cell.

import numpy as np
from scipy import stats
import sympy as sp
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
data = rng.exponential(scale=2.0, size=50)   # true lambda = 0.5

x_grid = np.linspace(0, 15, 500)
ecdf = np.array([(data <= x).mean() for x in x_grid])
theoretical = stats.expon.cdf(x_grid, scale=2.0)

ks_stat, p_value = stats.kstest(data, 'expon', args=(0, 2.0))
print(f"KS statistic D_n = {ks_stat:.4f},  p-value = {p_value:.4f}")

plt.plot(x_grid, ecdf, label=r"$\hat{F}_n(x)$")
plt.plot(x_grid, theoretical, label=r"$F_\theta(x)$", linestyle="--")
plt.legend(); plt.xlabel("x"); plt.title("ECDF vs Theoretical CDF")
plt.show()

A $p$-value above $0.05$ fails to reject the exponential model, while a low $p$-value directs the analyst toward a heavier-tailed alternative such as the Weibull or log-normal family.
