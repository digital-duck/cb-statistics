Continuous Random Variable

Definition. A continuous random variable is a random variable $X$ whose range is an uncountable subset of $\mathbb{R}$ and whose probability distribution is described by a probability density function (PDF) $f_X : \mathbb{R} \to [0, \infty)$ satisfying two conditions:

$$f_X(x) \geq 0 \quad \text{for all } x \in \mathbb{R}, \qquad \int_{-\infty}^{\infty} f_X(x)\, dx = 1.$$

The probability that $X$ takes a value in the interval $[a, b]$ is then

$$P(a \leq X \leq b) = \int_a^b f_X(x)\, dx.$$

A key consequence is that $P(X = c) = 0$ for any single point $c$; probability is carried by intervals, not points.

Worked Example. Suppose the waiting time $X$ (in minutes) at a hospital triage desk follows the PDF

$$f_X(x) = \begin{cases} \tfrac{1}{10} e^{-x/10}, & x \geq 0, \\ 0, & x < 0. \end{cases}$$

This is an exponential distribution with rate $\lambda = 1/10$. The probability of waiting between 5 and 15 minutes is

$$P(5 \leq X \leq 15) = \int_5^{15} \frac{1}{10} e^{-x/10}\, dx = \left[-e^{-x/10}\right]_5^{15} = e^{-1/2} - e^{-3/2} \approx 0.3834.$$

Key Theorem (Expectation and Variance). If $X$ has PDF $f_X$, the expected value and variance are defined by

$$\mu = E[X] = \int_{-\infty}^{\infty} x\, f_X(x)\, dx, \qquad \sigma^2 = \operatorname{Var}(X) = \int_{-\infty}^{\infty} (x - \mu)^2 f_X(x)\, dx,$$

provided these integrals converge absolutely. For the exponential distribution above, $E[X] = 10$ and $\operatorname{Var}(X) = 100$, results derivable by integration by parts.

Lab Cell.

from sympy import symbols, exp, integrate, oo, simplify

x = symbols('x', real=True)
f = exp(-x / 10) / 10          # exponential PDF, lambda = 1/10

# Verify normalization
print(integrate(f, (x, 0, oo)))          # → 1

# P(5 ≤ X ≤ 15)
prob = integrate(f, (x, 5, 15))
print(simplify(prob))                    # → -exp(-3/2) + exp(-1/2)

# Expected value
mu = integrate(x * f, (x, 0, oo))
print(mu)                                # → 10

Running this cell confirms the analytic results and illustrates that SymPy handles improper integrals symbolically, eliminating rounding error in verification.
