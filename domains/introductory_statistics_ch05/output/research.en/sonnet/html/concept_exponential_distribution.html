Exponential Distribution

Definition. Let $X$ be a continuous random variable representing the waiting time between successive events in a Poisson process with constant rate $\lambda > 0$. We say $X$ follows an exponential distribution, written $X \sim \text{Exp}(\lambda)$, if its probability density function (pdf) is

$$f(x;\lambda) = \lambda e^{-\lambda x}, \quad x \geq 0,$$

and $f(x;\lambda) = 0$ for $x < 0$. The corresponding cumulative distribution function (cdf) is

$$F(x;\lambda) = 1 - e^{-\lambda x}, \quad x \geq 0.$$

The mean and variance are $\mathbb{E}[X] = 1/\lambda$ and $\operatorname{Var}(X) = 1/\lambda^2$, respectively.

Worked Example. A customer service center receives calls at an average rate of $\lambda = 4$ calls per hour. Assuming call arrivals follow a Poisson process, the inter-arrival time $X \sim \text{Exp}(4)$ is measured in hours. The probability that fewer than 20 minutes (i.e., $1/3$ hour) elapse between consecutive calls is

$$P\!\left(X < \tfrac{1}{3}\right) = 1 - e^{-4 \cdot (1/3)} = 1 - e^{-4/3} \approx 1 - 0.2636 = 0.7364.$$

Thus there is approximately a 73.6% chance the next call arrives within 20 minutes.

Key Theorem (Memoryless Property). The exponential distribution is the unique continuous distribution satisfying the memoryless property: for all $s, t \geq 0$,

$$P(X > s + t \mid X > s) = P(X > t).$$

Proof sketch. Using the survival function $S(x) = e^{-\lambda x}$, one computes

$$P(X > s + t \mid X > s) = \frac{S(s+t)}{S(s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X > t). \quad \square$$

This property implies that the distribution has no aging: the system probabilistically "forgets" how long it has already waited.

Lab Cell.

import sympy as sp

x, lam = sp.symbols('x lambda', positive=True)

pdf = lam * sp.exp(-lam * x)
cdf = sp.integrate(pdf, (x, 0, x))
mean = sp.integrate(x * pdf, (x, 0, sp.oo))
variance = sp.integrate(x**2 * pdf, (x, 0, sp.oo)) - mean**2

print("CDF    :", sp.simplify(cdf))
print("Mean   :", mean)          # 1/lambda
print("Variance:", sp.simplify(variance))  # 1/lambda**2

# Numerical example: lambda = 4, P(X < 1/3)
prob = cdf.subs([(lam, 4), (x, sp.Rational(1, 3))])
print("P(X < 1/3):", float(prob.evalf()))
