Error Bound Proportion

Definition. Let $\hat{x}$ be an approximation to a true value $x \neq 0$. The absolute error is $\varepsilon_{\text{abs}} = |\hat{x} - x|$, and the relative error is $\varepsilon_{\text{rel}} = \varepsilon_{\text{abs}} / |x|$. An error bound proportion is a constant $\delta \in (0, 1)$ such that

$$\varepsilon_{\text{rel}} = \frac{|\hat{x} - x|}{|x|} \leq \delta.$$

The bound $\delta$ expresses the worst-case fractional deviation of the approximation from the truth, independent of the scale of $x$. This scale-invariance makes $\delta$ the natural language for numerical guarantees: a bound $\delta = 0.01$ certifies accuracy to within $1\%$ regardless of whether $x$ is measured in nanometres or light-years.

Worked Example. Suppose the true value of a physical constant is $x = 6.674 \times 10^{-11}$ N m² kg⁻² (Newton's gravitational constant), and a student's measurement yields $\hat{x} = 6.700 \times 10^{-11}$. Compute the error bound proportion:

$$\varepsilon_{\text{abs}} = |6.700 - 6.674| \times 10^{-11} = 0.026 \times 10^{-11},$$ $$\delta = \frac{0.026 \times 10^{-11}}{6.674 \times 10^{-11}} \approx 0.00390 \approx 0.39\%.$$

The measurement satisfies any stated bound $\delta \geq 0.0039$. Note that comparing raw absolute errors would conflate the quality of measurements taken on very different scales; the proportion $\delta$ avoids this conflation.

Key Theorem (Propagation of Relative Error). If $f(x) = x^n$ and $|\hat{x} - x|/|x| \leq \delta$, then for sufficiently small $\delta$,

$$\frac{|f(\hat{x}) - f(x)|}{|f(x)|} \leq n\,\delta + O(\delta^2).$$

Proof sketch. Write $\hat{x} = x(1 + \eta)$ with $|\eta| \leq \delta$. Then $f(\hat{x}) = x^n (1+\eta)^n = x^n (1 + n\eta + O(\eta^2))$, so the relative error in $f$ is $|n\eta + O(\eta^2)| \leq n\delta + O(\delta^2)$. $\square$

This theorem shows that exponentiation amplifies the error bound proportion by the exponent $n$, a critical consideration in numerical analysis and uncertainty propagation.

Lab Cell.

from sympy import symbols, Rational, Abs, N

x_true = Rational(6674, 100000)   # scaled to avoid large exponents
x_hat  = Rational(6700, 100000)

delta = Abs(x_hat - x_true) / Abs(x_true)
print("Error bound proportion:", N(delta, 4))   # 0.003896
