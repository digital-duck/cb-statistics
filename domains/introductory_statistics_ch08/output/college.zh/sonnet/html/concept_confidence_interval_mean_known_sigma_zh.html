Confidence Interval Mean Known Sigma

定义

设总体 $X$ 服从均值为 $\mu$、标准差为 $\sigma$ 的正态分布，其中 $\sigma$ 已知。从总体中抽取容量为 $n$ 的简单随机样本，样本均值记为 $\bar{X}$。由中心极限定理，统计量

$$Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$$

对于给定置信水平 $1 - \alpha$（如 $0.95$），取标准正态分布的双侧临界值 $z_{\alpha/2}$，满足 $P(-z_{\alpha/2} \le Z \le z_{\alpha/2}) = 1 - \alpha$。由此得到总体均值 $\mu$ 的置信区间：

$$\left(\bar{X} - z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}},\quad \bar{X} + z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}\right)$$

区间半径 $E = z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}$ 称为误差限（margin of error）。

例题

某工厂生产的钢丝绳断裂强度已知标准差 $\sigma = 8\,\text{kN}$，现随机抽取 $n = 36$ 根，测得样本均值 $\bar{x} = 120\,\text{kN}$。求置信水平 $95\%$ 下总体均值 $\mu$ 的置信区间。

解：置信水平 $1-\alpha = 0.95$，故 $\alpha/2 = 0.025$，查标准正态表得 $z_{0.025} = 1.96$。

$$E = 1.96 \times \frac{8}{\sqrt{36}} = 1.96 \times \frac{8}{6} \approx 2.61\,\text{kN}$$

置信区间为 $(120 - 2.61,\ 120 + 2.61) = (117.39,\ 122.61)\,\text{kN}$。

即有 $95\%$ 的把握认为总体均值落在此区间内。

关键定理

区间长度与样本量：置信区间宽度 $2E = 2 z_{\alpha/2} \sigma / \sqrt{n}$。若要将误差限控制在 $E_0$ 以内，所需最小样本量为

$$n \ge \left\lceil \left(\frac{z_{\alpha/2}\,\sigma}{E_0}\right)^2 \right\rceil$$

置信水平越高（$z_{\alpha/2}$ 越大），或总体波动越大（$\sigma$ 越大），区间越宽；增大 $n$ 可有效压缩区间宽度，但收益以 $\sqrt{n}$ 的速度递减。

实验单元（SymPy）

from sympy import symbols, sqrt, Rational, N
from sympy.stats import Normal, cdf

xbar, sigma, n = 120, 8, 36
alpha = Rational(1, 20)          # alpha = 0.05
z = symbols('z', positive=True)
Z = Normal('Z', 0, 1)

# 求临界值 z_{alpha/2}
from sympy import solve, Eq
z_val = float(N(solve(Eq(cdf(Z)(z), 1 - alpha/2), z)[0]))
E = z_val * sigma / sqrt(n)
print(f"z_{{alpha/2}} = {z_val:.4f}")
print(f"置信区间: ({xbar - float(E):.4f}, {xbar + float(E):.4f})")
