Sample Proportion

定义。 设总体由 $N$ 个个体组成，其中具有某一属性（称为"成功"）的个体共有 $M$ 个。从总体中随机抽取 $n$ 个个体，令 $X$ 为样本中具有该属性的个体数，则样本比例定义为

$$\hat{p} = \frac{X}{n}.$$

$\hat{p}$ 是总体比例 $p = M/N$ 的点估计量。当抽样为有放回抽样（或总体足够大使得有限总体校正可忽略）时，$X \sim \mathrm{Binomial}(n, p)$，从而

$$E[\hat{p}] = p, \qquad \mathrm{Var}(\hat{p}) = \frac{p(1-p)}{n}.$$

无偏性意味着 $\hat{p}$ 在重复抽样下平均恰好等于真实参数 $p$；方差随样本量 $n$ 的增大而减小，体现了大样本估计的精确性。

例题。 某校有 1000 名学生，已知其中 40% 拥有自行车（即 $p = 0.4$）。现随机抽取 $n = 100$ 名学生，记录其中拥有自行车的人数 $X$。

  • 计算 $\hat{p}$ 的期望与标准差。
  • 若调查结果为 $X = 38$，给出 $p$ 的点估计。

    • 解：

  • $E[\hat{p}] = 0.4$；$\mathrm{SD}(\hat{p}) = \sqrt{0.4 \times 0.6 / 100} = \sqrt{0.0024} \approx 0.049$。
  • $\hat{p} = 38/100 = 0.38$，与真值 $p = 0.4$ 相差约 0.02，在一个标准差范围内，属正常波动。

    • 定理（中心极限定理在比例估计中的应用）。 当 $np \geq 5$ 且 $n(1-p) \geq 5$ 时，样本比例近似服从正态分布：

    $$\hat{p} \approx \mathcal{N}\!\left(p,\, \frac{p(1-p)}{n}\right).$$

    标准化后得到枢轴量

    $$Z = \frac{\hat{p} - p}{\sqrt{p(1-p)/n}} \xrightarrow{d} \mathcal{N}(0,1),$$

    这是构造比例置信区间与假设检验的理论基础。

    实验室代码（SymPy）。

    from sympy import symbols, sqrt, simplify, N

p, n_sym = symbols('p n', positive=True)

# 方差与标准差的符号表达式
var_phat   = p * (1 - p) / n_sym
std_phat   = sqrt(var_phat)

print("Var(p̂) =", simplify(var_phat))
print("SD(p̂)  =", simplify(std_phat))

# 数值代入：p = 0.4, n = 100
print("数值 SD =", N(std_phat.subs({p: 0.4, n_sym: 100}), 4))

    运行后将输出 $\mathrm{SD}(\hat{p}) \approx 0.04899$，与手算结果一致，验证了公式的正确性。
