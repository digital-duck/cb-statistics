Error Bound Proportion

定义。 设近似值 $\tilde{x}$ 是真实值 $x^*$ 的估计。误差界比例（error bound proportion）定义为绝对误差界与真实值绝对量之比：

$$\rho = \frac{|\tilde{x} - x^*|}{|x^*|}, \quad x^* \neq 0.$$

当 $\rho$ 无法精确计算时，常以可验证的上界 $\hat{\rho}$ 代之，使得 $\rho \leq \hat{\rho}$ 恒成立。误差界比例本质上是相对误差的一种表现形式，其优势在于量纲无关性——无论原始量的单位如何，$\rho$ 始终是一个纯数，便于跨问题比较精度。

例题。 用截断泰勒展开 $\ln(1+x) \approx x - \dfrac{x^2}{2}$ 近似计算 $\ln(1.2)$。

取 $x = 0.2$，得近似值

$$\tilde{v} = 0.2 - \frac{(0.2)^2}{2} = 0.2 - 0.02 = 0.18.$$

真实值为 $v^* = \ln(1.2) \approx 0.18232$。绝对误差为

$$|\tilde{v} - v^*| \approx 0.00232.$$

误差界比例为

$$\rho = \frac{0.00232}{0.18232} \approx 1.27\%.$$

泰勒余项定理给出上界：对 $|x| \leq 0.2$，余项满足 $|R_2(x)| \leq \dfrac{|x|^3}{3(1-|x|)} \leq \dfrac{(0.2)^3}{3 \times 0.8} \approx 0.00333$，故

$$\hat{\rho} = \frac{0.00333}{0.18} \approx 1.85\%.$$

可见 $\rho < \hat{\rho}$，界有效。

关键定理（误差传播界）。 设 $f$ 在 $x^*$ 附近连续可微，$|\delta x| \leq \varepsilon$，则

$$\frac{|f(\tilde{x}) - f(x^*)|}{|f(x^*)|} \leq \frac{|f'(x^*)| \cdot \varepsilon}{|f(x^*)|} + O(\varepsilon^2).$$

该不等式表明，函数值的误差界比例由条件数 $\kappa = \dfrac{|x^ f'(x^)|}{|f(x^*)|}$ 控制：$\hat{\rho}_f \approx \kappa \cdot \hat{\rho}_x$。条件数越大，输入误差被放大越显著。

实验单元（SymPy）。

from sympy import *
x = symbols('x', positive=True)
f = ln(1 + x)
x0 = Rational(1, 5)                      # x* = 0.2
approx = x0 - x0**2 / 2                 # 截断近似
true_val = f.subs(x, x0)
rho = Abs(approx - true_val) / Abs(true_val)
print("误差界比例 ρ =", float(rho.evalf(6)))

kappa = Abs(x0 * diff(f, x).subs(x, x0) / true_val)
print("条件数 κ =", float(kappa.evalf(6)))

运行上述代码，学生可直接验证 $\rho$ 与条件数估计的吻合程度，并通过改变 $x_0$ 观察条件数随输入变化的趋势。
