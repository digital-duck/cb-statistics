置信水平

定义

设总体参数 $\theta$ 未知，统计学家基于样本构造一个随机区间 $[L(\mathbf{X}),\, U(\mathbf{X})]$，使得

$$P\!\bigl(L(\mathbf{X}) \le \theta \le U(\mathbf{X})\bigr) = 1 - \alpha,$$

则称 $1-\alpha$ 为该区间估计的置信水平（confidence level），对应的区间称为置信区间（confidence interval）。其中 $\alpha \in (0,1)$ 为显著性水平，常取 $0.05$ 或 $0.01$，即置信水平分别为 $95\%$ 或 $99\%$。需特别强调：置信水平描述的是区间构造方法在重复抽样中覆盖真值的频率，而非某个具体区间包含 $\theta$ 的概率——一旦样本固定，区间本身是确定的数值，不再涉及概率。

典型例题

设总体 $X \sim N(\mu, \sigma^2)$，$\sigma^2$ 已知，从中抽取容量为 $n$ 的简单随机样本，样本均值为 $\bar{X}$。由于

$$Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0,1),$$

对给定置信水平 $1-\alpha$，查标准正态表得临界值 $z_{\alpha/2}$，使得 $P(-z_{\alpha/2} \le Z \le z_{\alpha/2}) = 1-\alpha$。整理后得 $\mu$ 的置信区间为

$$\left[\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\; \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right].$$

具体数值：设 $\sigma=10$，$n=25$，$\bar{x}=80$，置信水平取 $95\%$，则 $z_{0.025}=1.96$，区间为 $[80-1.96\times 2,\; 80+1.96\times 2] = [76.08,\; 83.92]$。

核心定理

区间长度与置信水平的权衡：在样本量 $n$ 与总体方差 $\sigma^2$ 固定的条件下，置信区间的半宽为 $z_{\alpha/2}\,\sigma/\sqrt{n}$。置信水平 $1-\alpha$ 越高，$z_{\alpha/2}$ 越大，区间越宽，估计精度越低。若要在提高置信水平的同时保持区间宽度不变，唯一途径是增大样本量 $n$。

实验单元（SymPy）

from sympy import symbols, stats, N, Rational
from sympy.stats import Normal, P

# 定义标准正态随机变量
Z = Normal('Z', 0, 1)

# 计算 95% 置信水平对应的临界值
alpha = Rational(5, 100)
z_crit = stats.quantile(Z, 1 - alpha/2)
print("z_{alpha/2} =", N(z_crit, 5))

# 构造置信区间（sigma=10, n=25, x_bar=80）
import sympy as sp
sigma, n, x_bar = 10, 25, 80
half_width = N(z_crit, 5) * sigma / sp.sqrt(n)
print(f"置信区间: [{x_bar - half_width:.4f}, {x_bar + half_width:.4f}]")
