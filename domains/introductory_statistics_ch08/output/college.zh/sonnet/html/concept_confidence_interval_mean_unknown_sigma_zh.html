Confidence Interval Mean Unknown Sigma

定义

设 $X_1, X_2, \ldots, X_n$ 为来自正态总体 $N(\mu, \sigma^2)$ 的简单随机样本，其中总体均值 $\mu$ 与总体标准差 $\sigma$ 均未知。此时，样本均值 $\bar{X}$ 与样本标准差 $S = \sqrt{\dfrac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2}$ 是我们唯一可依赖的信息。由于 $\sigma$ 未知，不能使用标准正态统计量，而需引入学生 $t$ 分布。统计量

$$T = \frac{\bar{X} - \mu}{S/\sqrt{n}}$$

服从自由度为 $\nu = n - 1$ 的 $t$ 分布，记作 $T \sim t(n-1)$。$t$ 分布比标准正态分布具有更厚的尾部，以补偿用样本估计总体标准差所引入的额外不确定性。

置信水平为 $1 - \alpha$ 的 $\mu$ 的置信区间为

$$\left(\bar{X} - t_{\alpha/2,\, n-1}\cdot\frac{S}{\sqrt{n}},\quad \bar{X} + t_{\alpha/2,\, n-1}\cdot\frac{S}{\sqrt{n}}\right)$$

其中 $t_{\alpha/2,\, n-1}$ 为 $t(n-1)$ 分布上侧 $\alpha/2$ 分位数。

例题

某班级随机抽取 $n = 16$ 名学生测量身高（单位：cm），得 $\bar{X} = 170.5$，$S = 6.2$。构造 $\mu$ 的 $95\%$ 置信区间。

自由度 $\nu = 15$，查表得 $t_{0.025,15} = 2.131$。误差限为

$$E = 2.131 \times \frac{6.2}{\sqrt{16}} = 2.131 \times 1.55 \approx 3.30$$

因此 $95\%$ 置信区间为 $(170.5 - 3.30,\ 170.5 + 3.30) = (167.2,\ 173.8)$。

核心定理

定理（Gosset，1908）：若 $X_1,\ldots,X_n \overset{\text{i.i.d.}}{\sim} N(\mu,\sigma^2)$，则 $T = \dfrac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$。

证明要点：$\bar{X}$ 与 $S^2$ 相互独立（Cochran 定理），$\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$，而 $t$ 分布恰由标准正态变量除以独立 $\chi^2$ 变量之方根（除以自由度）构造而成。

实验代码（SymPy / SciPy）

import numpy as np
from scipy import stats

data = [168, 172, 175, 170, 169, 174, 171, 173,
        166, 177, 170, 168, 172, 175, 169, 171]

n    = len(data)
xbar = np.mean(data)
s    = np.std(data, ddof=1)
ci   = stats.t.interval(0.95, df=n-1, loc=xbar, scale=s/np.sqrt(n))
print(f"样本均值: {xbar:.2f}, 95% 置信区间: ({ci[0]:.2f}, {ci[1]:.2f})")

当 $n \to \infty$ 时，$t(n-1) \to N(0,1)$，该区间退化为 $\sigma$ 已知情形，体现了两种方法的内在一致性。
