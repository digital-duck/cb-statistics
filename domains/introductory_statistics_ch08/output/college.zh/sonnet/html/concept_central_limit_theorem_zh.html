Central Limit Theorem

定义。 设 $X_1, X_2, \ldots, X_n$ 为独立同分布的随机变量，其共同期望为 $\mu$，方差为 $\sigma^2 < \infty$。定义样本均值为

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i.$$

中心极限定理断言：当 $n \to \infty$ 时，标准化统计量

$$Z_n = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}}$$

在分布上收敛于标准正态分布 $\mathcal{N}(0,1)$，即对任意 $z \in \mathbb{R}$，

$$\lim_{n \to \infty} P(Z_n \leq z) = \Phi(z) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{z} e^{-t^2/2}\,dt.$$

这一结论的深刻之处在于：无论原始分布的形状如何，只要方差有限，样本均值的分布在大样本下均趋向正态。

证明思路。 标准证明借助特征函数（即矩母函数的复数推广）。令 $Y_i = (X_i - \mu)/\sigma$，则 $Z_n = n^{-1/2}\sum_{i=1}^n Y_i$。$Y_i$ 的特征函数展开为

$$\varphi_{Y}(t) = 1 - \frac{t^2}{2} + o(t^2),\quad t \to 0.$$

于是 $Z_n$ 的特征函数为

$$\varphi_{Z_n}(t) = \left[\varphi_Y\!\left(\frac{t}{\sqrt{n}}\right)\right]^n = \left(1 - \frac{t^2}{2n} + o\!\left(\frac{1}{n}\right)\right)^n \xrightarrow{n\to\infty} e^{-t^2/2},$$

而 $e^{-t^2/2}$ 正是 $\mathcal{N}(0,1)$ 的特征函数。由连续性定理，分布收敛得证。

具体例题。 设 $X_i \sim \text{Uniform}(0,1)$，则 $\mu = 1/2$，$\sigma^2 = 1/12$。取 $n = 50$，求 $P(\bar{X}_{50} > 0.55)$。

标准化：

$$Z = \frac{0.55 - 0.5}{1/\!\sqrt{600}} = 0.05\sqrt{600} \approx 1.225.$$

因此

$$P(\bar{X}_{50} > 0.55) \approx 1 - \Phi(1.225) \approx 1 - 0.8897 = 0.1103.$$

实验单元（SymPy/NumPy）。

import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
n, trials = 50, 100_000
samples = rng.uniform(0, 1, size=(trials, n))
means = samples.mean(axis=1)

# 模拟概率
prob_sim = (means > 0.55).mean()

# 理论概率
mu, sigma = 0.5, 1/np.sqrt(12)
prob_theory = 1 - stats.norm.cdf(0.55, loc=mu, scale=sigma/np.sqrt(n))

print(f"模拟值: {prob_sim:.4f}")
print(f"理论值: {prob_theory:.4f}")

运行结果应显示两值高度吻合，直观验证了中心极限定理的有效性。对较小的 $n$（如 $n=5$），可观察到分布偏态尚未消失，从而体会"大样本"假设的必要性。
