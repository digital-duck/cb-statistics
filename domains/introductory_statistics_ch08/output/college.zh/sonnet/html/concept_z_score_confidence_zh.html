Z Score Confidence

定义

设随机变量 $X$ 服从均值为 $\mu$、标准差为 $\sigma$ 的正态分布，即 $X \sim \mathcal{N}(\mu, \sigma^2)$。Z 分数（Z-score）将任意观测值 $x$ 标准化为：

$$z = \frac{x - \mu}{\sigma}$$

变换后的量 $Z \sim \mathcal{N}(0, 1)$，称为标准正态分布。在实际推断中，我们往往不知道总体参数 $\mu$，而是借助样本均值 $\bar{X}$ 进行估计。当样本量为 $n$ 时，由中心极限定理，

$$Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1)$$

置信度（confidence level）$1 - \alpha$ 表示：若无限次重复抽样，所构造的区间中有比例为 $1-\alpha$ 的区间包含真实参数 $\mu$。对应的临界值 $z_{\alpha/2}$ 满足 $P(-z_{\alpha/2} \leq Z \leq z_{\alpha/2}) = 1 - \alpha$。

计算示例

某工厂生产的零件直径已知总体标准差 $\sigma = 0.5\,\text{mm}$，随机抽取 $n = 25$ 个零件，测得样本均值 $\bar{x} = 10.2\,\text{mm}$。求总体均值 $\mu$ 的 $95\%$ 置信区间。

取置信度 $1 - \alpha = 0.95$，则 $\alpha/2 = 0.025$，查标准正态表得 $z_{0.025} = 1.96$。误差边界为：

$$E = z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}} = 1.96 \times \frac{0.5}{\sqrt{25}} = 1.96 \times 0.1 = 0.196$$

因此 $95\%$ 置信区间为：

$$\mu \in [\,10.2 - 0.196,\; 10.2 + 0.196\,] = [10.004,\; 10.396]\,\text{mm}$$

核心定理

定理（Z 置信区间）：设总体方差 $\sigma^2$ 已知，$\bar{X}$ 为容量 $n$ 的简单随机样本均值，则总体均值 $\mu$ 的 $1-\alpha$ 置信区间为：

$$\left(\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\quad \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right)$$

证明要点：由标准化变换，$P\!\left(|Z| \leq z_{\alpha/2}\right) = 1-\alpha$，将 $Z$ 展开并对 $\mu$ 求解不等式即得区间端点。$\square$

实验单元（SymPy）

from sympy import symbols, sqrt, Rational, N
from sympy.stats import Normal, P, cdf

# 参数设定
x_bar, sigma, n = 10.2, 0.5, 25
z_crit = 1.96                        # z_{0.025}

E = z_crit * sigma / sqrt(n)
lower, upper = x_bar - E, x_bar + E
print(f"95% 置信区间: [{N(lower, 4)}, {N(upper, 4)}] mm")

# 验证临界值
Z = Normal('Z', 0, 1)
prob = P((-z_crit <= Z) & (Z <= z_crit))
print(f"区间覆盖概率: {N(prob, 4)}")
