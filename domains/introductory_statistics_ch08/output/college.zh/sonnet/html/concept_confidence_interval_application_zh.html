置信区间的应用

定义。 设总体参数为 $\theta$（如均值 $\mu$ 或比例 $p$），基于样本容量为 $n$ 的随机样本，置信区间（confidence interval）是一个随机区间 $[L, U]$，满足

$$P(L \leq \theta \leq U) = 1 - \alpha,$$

其中 $1-\alpha$ 称为置信水平（confidence level），常取 $0.95$ 或 $0.99$。需要强调的是，$\theta$ 本身是固定的未知常数，而区间端点 $L$ 与 $U$ 是随机变量；上述概率描述的是在重复抽样中，所构造的区间覆盖真实参数的频率。

具体例题。 某大学对 $n = 64$ 名学生的月均学习时长进行调查，得到样本均值 $\bar{x} = 42$ 小时，样本标准差 $s = 8$ 小时。在总体方差未知、样本量充足的条件下，利用中心极限定理，统计量

$$Z = \frac{\bar{X} - \mu}{s/\sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1).$$

取置信水平 $95\%$，查标准正态分布表得 $z_{0.025} = 1.96$，从而 $\mu$ 的 $95\%$ 置信区间为

$$\bar{x} \pm z_{0.025} \cdot \frac{s}{\sqrt{n}} = 42 \pm 1.96 \times \frac{8}{\sqrt{64}} = 42 \pm 1.96 \in [40.04,\ 43.96].$$

解释：在长期重复抽样中，约有 $95\%$ 的区间将包含真实均值 $\mu$。

关键定理（大样本置信区间）。 设 $X_1, X_2, \ldots, X_n$ 为独立同分布样本，期望为 $\mu$，方差为 $\sigma^2 < \infty$。当 $n \to \infty$ 时，$\mu$ 的近似 $1-\alpha$ 置信区间为

$$\left[\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\ \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right],$$

其中 $z_{\alpha/2}$ 为标准正态分布的上 $\alpha/2$ 分位点。区间宽度 $2z_{\alpha/2}\sigma/\sqrt{n}$ 以 $O(n^{-1/2})$ 速率收缩，体现了样本量对估计精度的根本性制约。

实验单元（SymPy）。

import sympy as sp

x_bar, s, n, z = 42, 8, 64, 1.96
se = s / n**0.5
lower, upper = x_bar - z * se, x_bar + z * se
print(f"95% 置信区间: [{lower:.4f}, {upper:.4f}]")

# 符号推导：区间半宽关于 n 的表达式
n_sym = sp.Symbol('n', positive=True)
half_width = z * s / sp.sqrt(n_sym)
sp.pprint(sp.simplify(half_width))
