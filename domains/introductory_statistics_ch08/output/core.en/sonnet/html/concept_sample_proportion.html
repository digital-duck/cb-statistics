Sample Proportion

Definition. Let $X_1, X_2, \ldots, X_n$ be independent Bernoulli random variables with success probability $p$, drawn from a large population. The sample proportion is the statistic

$$\hat{p} = \frac{1}{n}\sum_{i=1}^{n} X_i = \frac{X}{n},$$

where $X = \sum_{i=1}^{n} X_i \sim \mathrm{Binomial}(n, p)$ counts the number of successes in the sample. Because each $X_i \in \{0, 1\}$, the sample proportion $\hat{p}$ takes values in $\{0, 1/n, 2/n, \ldots, 1\}$ and serves as a natural point estimator of the unknown population proportion $p$.

Worked Example. A quality-control engineer inspects $n = 200$ circuit boards and finds $X = 14$ defective units. The sample proportion of defectives is

$$\hat{p} = \frac{14}{200} = 0.07.$$

This single number estimates the true (unknown) defect rate $p$ of the production line. To assess precision, compute the standard error:

$$\mathrm{SE}(\hat{p}) = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} = \sqrt{\frac{0.07 \times 0.93}{200}} \approx 0.0180.$$

A rough 95 % confidence interval is $0.07 \pm 1.96 \times 0.0180$, giving $(0.035,\, 0.105)$.

Key Theorem (Sampling Distribution of $\hat{p}$). For a random sample of size $n$ from a Bernoulli$(p)$ population:

$$\mathrm{E}[\hat{p}] = p, \qquad \mathrm{Var}(\hat{p}) = \frac{p(1-p)}{n}.$$

Proof sketch. Since $\mathrm{E}[X_i] = p$ and $\mathrm{Var}(X_i) = p(1-p)$, linearity of expectation gives $\mathrm{E}[\hat{p}] = p$, and independence gives $\mathrm{Var}(\hat{p}) = p(1-p)/n$. By the Central Limit Theorem, as $n \to \infty$,

$$\frac{\hat{p} - p}{\sqrt{p(1-p)/n}} \xrightarrow{d} \mathcal{N}(0,1),$$

provided $np \geq 5$ and $n(1-p) \geq 5$ (the standard rule of thumb for normal approximation adequacy). $\square$

Lab Cell (SymPy).

from sympy import *
n, p_val = 200, Rational(14, 200)
se = sqrt(p_val * (1 - p_val) / n)
ci_low  = p_val - Rational(196, 100) * se
ci_high = p_val + Rational(196, 100) * se
print("p-hat =", float(p_val))
print("SE    =", float(se).round(4))
print("95% CI = ({:.4f}, {:.4f})".format(float(ci_low), float(ci_high)))

Running this cell reproduces the numerical results above exactly, confirming that $\hat{p}$ is an unbiased estimator whose precision improves at rate $1/\sqrt{n}$.
