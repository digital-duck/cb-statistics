Concept Book: Confidence Interval Application

Introductory Statistics Ch08 · Generated by SPL

Payoff

Throughout this text we have built, layer by layer, the machinery of statistical inference: probability distributions, sampling theory, the Central Limit Theorem, and point estimation. A confidence interval is the moment all of those layers collapse into a single, actionable statement about an unknown population parameter. Confidence interval application is the practice of constructing, interpreting, and acting upon that statement in a real scientific or engineering context — and it is the natural endpoint of an introductory statistics course precisely because it demands every earlier concept simultaneously.

Definition. Let $\hat{\theta}$ be an estimator of an unknown parameter $\theta$, and let $\sigma_{\hat{\theta}}$ denote its standard error. A $(1-\alpha)$ confidence interval for $\theta$ is the random interval

$$\left[\hat{\theta} - z_{\alpha/2}\,\sigma_{\hat{\theta}},\quad \hat{\theta} + z_{\alpha/2}\,\sigma_{\hat{\theta}}\right],$$

where $z_{\alpha/2}$ is the upper $\alpha/2$ quantile of the standard normal distribution. Before data are collected, this interval contains the true $\theta$ with probability $1-\alpha$; after data are observed it either does or does not — the confidence is in the procedure, not in any single realisation.

Worked example. A quality-control engineer measures the breaking strength (in Newtons) of $n = 64$ cable samples, obtaining $\bar{x} = 412.3$ N and sample standard deviation $s = 18.4$ N. Constructing a 95% interval with $z_{0.025} = 1.96$:

$$\sigma_{\bar{x}} \approx \frac{s}{\sqrt{n}} = \frac{18.4}{8} = 2.30\text{ N},$$ $$\text{CI} = [412.3 - 1.96(2.30),\ 412.3 + 1.96(2.30)] = [407.8,\ 416.8]\text{ N}.$$

The engineer reports, with 95% confidence, that the true mean breaking strength lies between 407.8 N and 416.8 N — a statement narrow enough to inform a safety specification.

Theorem (Coverage guarantee). If the data are i.i.d. with finite variance and $n$ is sufficiently large, the interval above achieves exactly coverage $1-\alpha$ asymptotically, a consequence of the Central Limit Theorem.

Lab cell.

import numpy as np
from scipy import stats

rng  = np.random.default_rng(42)
data = rng.normal(loc=412.3, scale=18.4, size=64)

n, xbar, se = len(data), data.mean(), stats.sem(data)
lo, hi = stats.t.interval(0.95, df=n-1, loc=xbar, scale=se)
print(f"95 % CI: [{lo:.2f}, {hi:.2f}] N")

Run this cell, then vary the sample size and observe how the interval width scales as $n^{-1/2}$ — a clean empirical confirmation of the theory you have just proved. When you are ready to see these ideas applied to a domain you care about, proceed to the next chapter.
