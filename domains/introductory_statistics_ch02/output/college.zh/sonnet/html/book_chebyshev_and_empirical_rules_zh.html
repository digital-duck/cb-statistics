切比雪夫不等式与经验法则：分布无关界与正态近似的统一

至此，本书的核心论题已完整呈现。切比雪夫不等式与经验法则并非两条孤立的结论，而是同一思想的两个面貌：前者以最大的普遍性为代价换取确定性，后者以正态假设为前提换取精确性。将二者并置，读者便掌握了一把双刃工具，可在"分布已知"与"分布未知"两种境地之间自由切换。

定义的统一视角

设随机变量 $X$ 具有有限均值 $\mu$ 与方差 $\sigma^2$。切比雪夫不等式断言，对任意 $k > 0$，

$$P(|X - \mu| \geq k\sigma) \leq \frac{1}{k^2}.$$

这一界对任何分布成立，无需额外假设。当 $X \sim \mathcal{N}(\mu, \sigma^2)$ 时，精确计算给出所谓经验法则：

$$P(|X-\mu| \leq \sigma) \approx 0.6827,\quad P(|X-\mu| \leq 2\sigma) \approx 0.9545,\quad P(|X-\mu| \leq 3\sigma) \approx 0.9973.$$

两个结论的对比揭示了假设的代价：切比雪夫在 $k=2$ 时仅保证至少 $75\%$，而正态分布精确给出 $95.45\%$。差距本身便是信息——它量化了"知道分布形状"究竟值多少。

作为终点的自然性

本书自基本概率公理出发，历经期望、方差、矩不等式，最终在此汇聚。切比雪夫不等式是矩方法的直接结果，而经验法则是中心极限定理的实用化身。二者共同构成统计推断的起点：任何置信区间、任何异常值检测、任何质量控制图，其背后的逻辑均源于此。学生在本章习得的，不只是两条公式，而是"用均值与方差描述集中程度"这一元思想的完整表达。

关键定理：切比雪夫界的不可改进性

定理（界的紧性）：对每个 $k > 1$，存在随机变量 $X$ 使得 $P(|X-\mu| \geq k\sigma) = 1/k^2$ 恰好取等。

证明概要：取三点分布 $P(X = \mu \pm k\sigma) = 1/(2k^2)$，$P(X = \mu) = 1 - 1/k^2$，直接验算即得。这说明在不附加任何分布假设的前提下，切比雪夫界已是最优。

实验室单元（SymPy）

from sympy import symbols, integrate, oo, exp, pi, sqrt, N

x, mu, sigma = symbols('x mu sigma', real=True)
k = 2  # 考察 k=2 的情形

# 切比雪夫界
chebyshev_bound = 1 / k**2
print(f"切比雪夫界（k={k}）：至少 {1 - chebyshev_bound:.2%} 落在 {k}σ 内")

# 正态分布精确值
normal_density = exp(-(x - mu)**2 / (2 * sigma**2)) / (sqrt(2 * pi) * sigma)
prob_exact = integrate(
    normal_density.subs([(mu, 0), (sigma, 1)]),
    (x, -k, k)
)
print(f"正态精确值（k={k}）：{N(prob_exact, 6)}")

通向应用的邀请

上述两条法则在实践中各有用武之地：质量控制中的六西格玛标准、金融风险管理中的在险价值（VaR）、机器学习中的泛化误差界，无不以此为理论支撑。其中，统计质量控制的应用最为直观且影响深远——一条控制图的上下限，正是经验法则与切比雪夫不等式在生产线上的化身。若读者希望见证这一理论如何在真实数据流中守护产品质量，不妨翻开下一章，踏上这段应用之旅。
